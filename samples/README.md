# Sample vault

A tiny, original vault for trying MCQ Tracker without writing notes first.

1. Copy `sample-vault/` somewhere and open it in Obsidian.
2. Install and enable MCQ Tracker (or copy the release's `main.js`, `manifest.json` and `styles.css` into `sample-vault/.obsidian/plugins/mcq-tracker/`).
3. Open **Today** and press **Start 5 minutes**, or open **Practice** and press **Practice all**.

The sample includes four questions, one flashcard and no copyrighted question-bank content. Edit or delete anything; these notes use the same property format as a real vault.
