# AGENTS.md — MCQ Tracker

Read `plan.md` first, especially **Handoff snapshot (Oct 30, 2026)** and **Current focus**. The plan is the product source of truth.

## Project

Obsidian plugin written in dependency-free JavaScript. Source lives in `src/`; `main.js` is generated by `node scripts/build.js` and must never be hand-edited. Settings live in Obsidian's `data.json` and are not committed. Tests use Node's built-in runner.

## Commands

```bash
npm ci --ignore-scripts   # reproducible install from package-lock.json
npm test                  # full test suite
npm run build             # regenerate main.js from src/
npm run check             # verify main.js matches src/
```

The repository is dependency-free, but `package-lock.json` is committed and the release workflow installs with `npm ci` so local and CI builds start from the same locked metadata.

## Rules

- Make the smallest change that meets the request; do not add dependencies.
- Only MIT, BSD, ISC, 0BSD or (permissively, with its NOTICE) Apache-2.0 code may be integrated. GPL, AGPL, MPL, CC BY-NC(-ND), PolyForm, proprietary and unverified sources are ideas-only: check `plan.md` §3.10 before copying anything, and never paste code from a plugin listed there as blocked.
- Update `plan.md` before pushing implementation work.
- Tests are part of the change. Run the affected tests, then `npm test` and `npm run check` before committing.
- Keep generated `main.js` in the commit when source changes.
- Commit only when the work is verified and the tree is intentional.
- Release tags must equal `manifest.json`'s `version`; the release workflow runs the suite and publishes the three Obsidian assets.
