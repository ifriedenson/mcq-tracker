# MCQ Tracker 1.169.3

This patch restores the optional one-click OpenCode setup that 1.169.1 removed.

## One-click OpenCode again

- Pressing **Download and install** downloads OpenCode from its GitHub release, checks the SHA-256 digest, unpacks it into `~/.question-tracker/opencode`, and records the program for the plugin.
- Turning on the OpenCode backend can start the same setup automatically the first time. The confirmation still names the source, version, size and destination before anything is downloaded.
- When you use the AI chat, the plugin starts `opencode serve` on `127.0.0.1` with a random port and password, and stops it when Obsidian closes.
- A copy you already installed still works: enter it under **OpenCode program**, or leave the managed setup off and point the plugin at your own `opencode serve` server.
- No note formats, saved prompts, schedules or existing AI settings are changed. If you prefer your manually started server, turn off **Set up and run OpenCode for me**.

## Obsidian's warning

The optional installer needs desktop filesystem and process access. Obsidian's automated review reports that as:

- direct filesystem access (`fs`), used to unpack OpenCode outside the vault and keep its data and optional provider key under `~/.question-tracker`; and
- shell execution (`child_process`), used to run the fixed archive helpers, start and stop `opencode serve`, and clean up the process.

That warning is expected for this release and is the accepted cost of a true one-click install. Vault notes are still read and written through Obsidian's vault API, not `fs`. If you need a warning-free installation, stay on **1.169.2**, use the Direct API backend, or install and run OpenCode yourself and connect to it by URL.

## Upgrade

Install **1.169.3** with BRAT, the community directory when it updates, or by copying the three release assets into `<your vault>/.obsidian/plugins/mcq-tracker/`. Reload Obsidian, then choose the OpenCode backend and press **Download and install**, or keep using your own server.
