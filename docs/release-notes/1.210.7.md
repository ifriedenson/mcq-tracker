# MCQ Tracker 1.210.7

Adds local voice memos to the **Read aloud** tab.

## What changed

- **Record voice memo** captures the device microphone; **Stop and save**
  writes the recording into the memo folder (`Recordings` by default) and
  appends one line to the day's note when a daily-note folder is set:
  `- 14:32 ![[Recordings/Voice 2026-11-03 14-32-10.webm]] · 1 min 5 s · lecture recap`
- The file name follows the recording time (`Voice YYYY-MM-DD HH-MM-SS.<ext>`),
  so several memos on one day never collide. If a name is already taken, a
  number is added instead of overwriting it.
- The extension follows the recorder: `m4a`, `webm`, `ogg`, `wav` or `mp3`.
- **Memo label** is optional text for that line.
- **Voice memo folder** and **Voice memo daily-note folder** are in Settings,
  Modules, Read aloud. With no daily-note folder the audio is saved and no note
  is touched. A missing day note is created only when a memo is saved.

## Boundaries

- Audio is written only when you press **Stop and save**. Nothing is
  transcribed, uploaded or sent to a model, and there is no speech provider,
  relay, background recorder or new dependency.
- Recording needs a device microphone and `MediaRecorder`; where the device
  offers neither, the card says recording is unavailable instead of failing
  silently.
