# 1.247.0 — Change an existing link

Released Nov 4, 2026.

## What changed

- **Retarget a link in place.** `updateLink` changes the link at a 1-based number in `readLinks`
  without touching its page, its rectangle, its border or its flags: the annotation keeps the exact
  clickable area it was written with and only its destination changes. The old action or page jump is
  deleted first, so a link never carries both, and nothing else on the page moves.
- **Either direction.** An address becomes a page jump and a page jump becomes an address, with the
  same validation `addLink` applies: `http`/`https` only, a 2,000-character limit and a page that is
  actually in the file.
- **The editor row.** **Add content → Links** gains **Change** (a link number) and **Change link**,
  which uses the row's **Kind**, **Address** and **Jump to** fields. It is one undo step, and only
  **Save a copy** writes, so the original PDF and its sidecar stay untouched.
- **Refusals, each with a message and no change:** a file with no links, a number outside 1 to the
  link count, an empty address, every scheme except `http`/`https`, an over-long address, and a page
  outside the file.

## Verification

- Three new real-byte tests, written first and run against the code before `updateLink` existed:
  all three failed with `editor.updateLink is not a function`, and all three pass after it. Retargeting
  an address keeps the saved file at one annotation with the same area; turning a link into a page
  jump removes its `/A` action and reads back as a jump on the page the link lives on; turning it back
  drops the jump; and every refusal leaves the original address in place.
- 64 focused PDF-editor tests pass. Full suite **1894 pass**, `npm run check` clean across
  **297 source files**, `main.js` current across **298 modules** at **4,939,537 bytes**, and
  `git diff --check` clean.

## Limits

- The clickable area is kept, not editable: a link cannot be moved or resized, only retargeted or
  removed. Changing the area means removing that link and adding a new one.
- A link numbered in the summary follows page order, so a file re-read after an edit is renumbered;
  read the summary again before changing another link.
