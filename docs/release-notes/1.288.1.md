# 1.288.1 — Study agent header and narrow-pane alignment

This patch finishes the 1.288.0 Copilot-style Study agent surface. It keeps the
same transcript → **ChatControls** → composer structure and removes the last
places where the surrounding plugin shell or narrow widths broke that model.

## Changes

- Removed the remaining duplicate **Study agent** `h4` and introductory hint
  from `AgentView`. The Obsidian leaf title is now the only pane header, so the
  chat surface starts with content as Copilot's does.
- Centered the empty-state suggestion card and capped it at `32rem`, matching
  Copilot's centered, bounded empty banner instead of leaving the card pinned
  to the top of the transcript. The card still uses the plugin's own
  `qt-agent-suggestion-deck` actions.
- Kept the tutor persona selector visible at 420 px and 320 px. The controls
  strip now shrinks the mode and role selects and tightens icon targets instead
  of hiding the persona.
- Added Obsidian's `markdown-rendered` class to rendered user and assistant
  bodies, so code fences, tables and Obsidian's reader styles use the same
  Markdown container as Copilot's messages. Code-block lines stay unwrapped and
  scroll horizontally rather than wrapping.
- Moved the "nothing is saved without approval" safety copy into the existing
  **How replies work** disclosure instead of restoring a second header above
  the transcript.

The existing controls, composer, streaming, Stop/Retry, sources, reasoning,
review cards, tabs and settings behavior are unchanged. No parallel visual
language or second window was added.
