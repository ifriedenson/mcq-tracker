# 1.290.0 — Searchable settings and Study agent polish

The Settings tab is now organised as **categories → pages → controls**. Six
categories replace the old module tabs: Practice, Cards & memory, Courses &
planning, Notes & tools, Study agent, and App & documents. A page list sits
beside the selected category, the breadcrumb names both levels, and below 540 px
the list becomes one grouped picker. Every existing setting keeps its storage key
and renderer.

**App & documents → PDF++** now owns the PDF++ toggle, status and embedded vendor
settings. The page mounts a second instance of PDF++'s settings tab (its
containers are created in the constructor, so the registered tab cannot be
moved), while the original **Open PDF++ settings tab** action keeps working. An
Obsidian 1.15 Page Preview guard preserves PDF++'s own hover-source fallback.
The embedded vendor page removes its outer gutter and keeps a 16 px inner one;
at the default 900 px window it renders 307 controls with 387 px rows.

The Study agent suggestion deck now grows its grid row with the active card
instead of clipping long titles and details. At a 300 px sidebar the long test
card measures 147 px inside a 161 px deck. Decorative back cards hide their
labels so they cannot paint through the active card in a wide pane, and the
disabled/OpenCode hints point to **Settings → Study agent → AI and the
assistant**.

Both surfaces were checked in real Obsidian 1.15.0 on Linux under Xvfb, in light
and dark, at narrow and wide widths. The one- and zero-card suggestion states
were probed with the real deck renderer because ordinary configuration always
seeds three; they are not configuration states.
