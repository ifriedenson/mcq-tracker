# MCQ Tracker 1.198.0

The first extended-calculator release: a local matrix calculator.

## What changed

- The Reference panel has a new **Matrix** tab. Matrix A and Matrix B are
  editable grids with labelled cells, row/column size controls up to 6×6, and
  a visible dimension count.
- Operations: `A + B`, `A − B`, `A × B`, scalar multiplication of either matrix,
  transpose, determinant, inverse, reduced row-echelon form, and `A x = b`
  using the first column of B. Results show the matrix or a scalar in a polite
  live region.
- Dimension mismatches, singular inverses, inconsistent or underdetermined
  systems, blank cells and non-finite values produce readable errors. The
  matrices remain editable and the last valid state is persisted.
- The arithmetic lives in `src/matrix.js` as pure functions. The Reference tab
  is the only view adapter; there is no network request, no `eval`, and no
  third-party matrix library.

## Verification

- `npm test` passes: **1,473 tests, 0 failures**.
- `npm run check` passes: no dynamic code and `main.js` matches `src/`.
- Focused coverage: arithmetic, transpose, scalar multiplication, 2×2 and 3×3
  determinants, singular inverses, inverse round-trip, RREF pivots and rank,
  unique/no/infinite solutions, dimension validation, stored-state
  normalization, the rendered Matrix tab, operation results and persistence.

## Licence

No dependency was added and no third-party code was copied. The matrix
algorithms are written locally.

Known limitations: the Matrix tab has not had a live Obsidian visual pass, and
the tab is deliberately limited to matrices up to 6×6 in the UI and 8×8 in the
pure module.
