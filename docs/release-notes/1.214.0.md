# MCQ Tracker 1.214.0

## Study agent: close the sidebar-agent gaps

This release finishes the right-sidebar **Study agent** introduced in 1.213.0.
It remains original MIT-licensed code in this repository. No Obsidian Copilot
or other AGPL source was copied.

- **Bot ribbon button.** While AI is enabled, the ribbon gains **Open Study
  agent**, alongside the existing **Study agent: open the sidebar** command.
- **Ask about the active note.** A one-click action turns on current-note
  context for that request and asks about the note you are editing.
- **Automatic vault retrieval.** Before each chat question the agent runs a
  local, read-only Markdown search and adds the best excerpt from each matching
  note to the system context. Replies are instructed to cite paths and lines;
  an empty result is allowed and must not be invented.
- **Insert into the active note.** Every completed reply now has **Insert into
  active note**. It inserts at the editor cursor (or replaces the selection),
  appends when the note is open without an editor, refuses a non-Markdown or
  missing active file, and never rewrites frontmatter.
- **Stop on Direct API too.** The existing OpenCode stop/cancel path is joined
  by a Stop action for Direct API requests. It stops waiting immediately and
  ignores the late reply; the provider may still finish the request.
- **Documented independence.** `docs/sidebar-agent.md` and `NOTICES.md` record
  the MIT licensing, the original implementation, the absence of Copilot source
  and the remaining manual live-provider/device check.
