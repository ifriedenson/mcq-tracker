# MCQ Tracker 1.170.0

This release is a UI quality pass for the non-Practice views. Practice, Calendar and the timed test keep their existing layouts.

## A calmer layout at every width

- Cards, Assignments, Insights, Reference, Study Tools, Study Workspace, Study statistics, Review calendar, Local events and Pomodoro now reflow cleanly at desktop and narrow pane widths.
- Study Workspace keeps its full section rail on desktop and switches to a compact section picker in a narrow pane. All 19 sections remain available, with their first-run panels and populated lists readable in both states.
- Cards, assignment tables, course summaries, reference cards, statistics and the Pomodoro timer no longer squeeze into a single row at 390 px.
- The five Insights summary cards, course health rows, workload totals and study-activity tiles reflow into balanced columns.
- Reference tabs, study-tool tabs, filters and action rows use the available width instead of clipping labels.
- The SAT callout now follows the active Obsidian theme instead of using fixed colours.

## Touch and calendar details

- Narrow-pane search fields, selects and action buttons now meet the 44 px hit-area target. This includes assignment row actions, review-calendar Open buttons and local-event Edit/Delete controls.
- In a very narrow local-events month grid, event titles are replaced by compact colour markers; the selected-day list keeps the full title, time and controls.
- Review calendar and Local events retain their dedicated mobile day-agenda layout when the plugin is running on a phone.

## Verification

The layout was captured in a real Obsidian 1.14.5 vault at 1200 px and 390 px in both light and dark themes, including the Study Workspace rail-to-picker transition and the phone day-agenda branches. The captures were inspected for clipping, overflow, title truncation, alignment and touch-target size.

The full test suite covers the responsive layout contracts, and `npm run check` verifies the generated bundle. The release notes are kept here so the user-facing changes are separated from implementation history.

## Upgrade

Install **1.170.0** with BRAT, the community directory when it updates, or by copying the three release assets into `<your vault>/.obsidian/plugins/mcq-tracker/`. Reload Obsidian. No data migration or settings reset is required.
