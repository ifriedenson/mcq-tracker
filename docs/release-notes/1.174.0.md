# MCQ Tracker 1.174.0

Parameter sliders come to the Reference **Graph** tab.

- A row such as `a = 2` is a parameter, like a Desmos slider. Later rows that use `a` are redrawn as the value moves, so one slider can drive several expressions.
- Each parameter row gets a range control, a live `a = ...` readout, **Play** and **Pause** buttons, and its own min, max and step fields. The default range is -10 to 10 in steps of 0.1.
- Play animates the value and loops at the top of the range; closing the Reference panel stops the animation.
- Reserved names cannot be sliders: `x` and `y` stay variables, and built-in functions and constants such as `sin` and `pi` are rejected with a clear message. A parameter value must be a number, so `a = x + 1` explains what to fix instead of plotting something wrong.
- Definitions, regressions and expressions all see the same parameter value, so `a = 2` plus `y = a x` plus `y ~ a x + b` agree.

The graph still uses the restricted local parser: no `eval`, no `Function`, no new dependency and no network request.
