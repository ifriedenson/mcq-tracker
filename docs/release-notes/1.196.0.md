# MCQ Tracker 1.196.0

Graph-paper settings for the graph.

## What changed

- **Show graph grid** and **Show graph axes** checkboxes hide either layer while
  the expressions and the rest of the scene stay untouched.
- An optional **Grid step** sets a fixed spacing for gridlines and tick labels.
  Leave it empty for automatic spacing. A non-numeric, zero, negative, below
  0.001, above 1000, or too dense-for-this-window step is refused with a
  human-readable message, a Notice and the polite live announcement; the field
  returns to the last valid value and the graph is not changed.
- The paper is painted by the existing canvas scene renderer, so changing any
  setting repaints the screen immediately and the same paper appears in the PNG
  export and the print sheet.
- Settings are saved under `settings.reference.graph.paper`. A graph saved before
  this release loads with the default paper — grid and axes shown, automatic
  step — and paints exactly as it did before. Every control has an accessible
  name and is keyboard-operable.
