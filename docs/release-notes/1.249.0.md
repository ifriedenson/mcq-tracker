# 1.249.0 — Move a link to another page

Released Nov 4, 2026.

## What changed

- **The annotation itself changes page.** `updateLink` takes an optional `page` and moves the same
  link annotation — not a copy, not a delete-and-re-add — from its page's `/Annots` into the chosen
  page's. Its `/Border`, `/F` flags, action or page jump and its identity survive, and the file still
  carries exactly one link.
- **The target page owns the geometry.** A supplied `area` is mapped with the same `displayRect`
  helper `addLink` uses, against the target page's own size and `/Rotate`, and validated against that
  page's box, so a rotated or differently sized destination behaves exactly like adding a link there.
- **No area means the visible place is kept.** With only a page given, the link's current area is read
  off its own page and re-mapped onto the new one, so it stays where it looked like it was.
- **Page, box and destination in one call.** `updateLink({ index, page, area, target, url | to })`
  moves the annotation, sets its box on the new page and retargets it in a single undo step.
- **The editor row.** **Add content → Links** gains **To page** and **Move to page** beside
  **Change** / **Change link** and **Move link**. It is one undo step, and only **Save a copy** writes.
- **Refusals, each with a message and no change:** a file with no links, a number outside 1 to the
  link count, a page outside the document, the page the link already sits on, a non-numeric, missing
  or partial box, a zero or negative width or height, and a rectangle that leaves the target page. All
  validation runs before any mutation, so a refused call leaves the document byte-identical.

## Limits

- The rectangle is still given in percentages of the page box rather than measured points.
- Retargeting stays its own press: **Move to page** carries the box and the page, but changing the
  address is still **Change link**.
- A link's `/Border`, `/H` highlight mode and `/BS` border style are preserved, never edited, and a
  link whose action is neither an `http(s)` URI nor an in-file page jump has no editable target here.
