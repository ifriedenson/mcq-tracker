# 1.302.1 — Multi-PDF imports finish

## What the owner saw
After updating, a multi-PDF import over the OpenCode backend looked broken:
the window sat on "Checking answer 2 of 2..." with a counting timer and never
moved on. The drive below caught the cause live: one blind check's model ran
`ls -la` on the vault instead of answering, then went silent. The silence
allowance is deliberately long for slow thinkers (20 minutes), and a server
that still answers probes earns the same question asked again — so one
wandering check could hold the batch for tens of minutes, and a model that
wanders on every check never lets the batch finish.

## What changed
- The blind check prompt now forbids tool use ("Do not use any tools. Answer
  from the question alone.") in `src/answer-verification.js`. A check is a
  pure question-and-answer task; the model no longer has any business listing
  files or running shell commands mid-check.
- The prompt's example answers were literal values a lazy model could echo
  (`"B"`, `"A, C"`, `"42"`). They are neutral placeholders now (`"<letter>"`,
  `"<letters>"`, `"<number>"`), so an echoed example can never verify a note.
- `send()` in `src/opencode-client.js` aborts the server session when the
  silence allowance expires, before reporting the silence. A retry therefore
  starts clean instead of stacking onto a zombie run that is still "thinking".
- Unchanged and still true: a check that fails is marked `verification:
  error` with `needs_review: true` — the note is kept, never dropped — and
  the batch continues to its per-file completion summary.

## Evidence
- Reproduced in headless Obsidian 1.15.1 with the managed OpenCode server and
  a free inference model: 3 real PDFs, attended batch, agent-written notes.
  Before the fix, check 6 of 6 ran shell tools and stalled the batch; after
  the fix, the same 3 files imported 6 notes with 6/6 checks matching in
  about five minutes, ending on the "Import complete" summary.
- New regression tests: the check prompt forbids tools and shows no echoable
  example (`tests/answer-verification.test.js`); an idle `send()` aborts its
  session (`tests/opencode-compat.test.js`).
- Full suite: **2,864 pass, 0 fail** across 4 shards; `npm run check` clean.
