# 1.299.2 — Hotkey audit

The new **Hotkey audit** command lists any MCQ Tracker shortcut that shares a
key with an Obsidian core command, using the shortcuts currently assigned on
this device.

## What changed

- **One command, a clear list.** Run **Hotkey audit: find conflicts with
  Obsidian shortcuts** from the command palette. Each row names the MCQ
  Tracker command, the shared shortcut, and every Obsidian core command using
  the same keys.
- **Current assignments only.** Custom hotkeys replace defaults, and an
  explicitly empty custom list stays empty. Other community plugins are left
  out, so the report stays focused on Obsidian core instead of flagging every
  installed plugin.
- **Read-only and local.** The audit never changes a binding and makes no
  network request. It reads Obsidian's own hotkey tables in the current
  window.
- **Platform-aware.** `Mod` is compared as Ctrl on Windows/Linux and Cmd on
  macOS, matching how Obsidian actually resolves the binding.
- **No data changes.** Notes, cards, review history, settings and all existing
  shortcuts are untouched.

core default, core custom overrides replacing defaults, empty custom bindings,
other community plugins being excluded, platform-aware `Mod` comparison,
