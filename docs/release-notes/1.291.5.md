# 1.291.5 — Quiz generation shows its cost before sending

The Quiz Generator's **Generate draft** action used to send the request
immediately. It now prepares the exact system and user prompt, resolves the
generation model, estimates the input tokens and the clamped reply budget, and
prices them from the local model table. The estimate is shown on a
confirmation step with the source-note count, passage count and token counts;
**Send request** sends that prepared payload through the existing generation
and blind-verification pass. No request is made while the estimate is on screen,
and a model without a local price still shows the token estimate.

This release also closes the remaining code-review residuals:

- Repeated question and card reads use a snapshot cache, invalidated by vault
  changes, reviews, imports, pending-attempt flushes and error-type edits.
  Plain-card folder events are filtered before the existing 300 ms debounce.
- `src/util.js` now owns the shared clamp, text, path, HTML-escape and
  unique-path helpers used across the PDF, graph, course, review, workspace
  and import modules; the duplicate local implementations are removed.
- Loopback HTTP is restricted to exact `localhost`, `::1` and valid
  `127.0.0.0/8` addresses, so lookalike hostnames cannot pass the HTTPS
  exception.
- The Study agent suggestion detail is no longer clamped to three lines; the
  card grows and the full suggested action remains readable.

No note schema, dependency, provider, network or storage behaviour changed.

Verification: `node --test` → **2,463 pass, 0 fail**; `npm run check` clean
across **344 source files**; `main.js` is **6,904,962 bytes** from **347
modules**.
