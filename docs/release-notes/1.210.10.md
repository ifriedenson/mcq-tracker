# MCQ Tracker 1.210.10

The last two local ideas from the academic-plugin backlog: a read-only writing
count, and one glossary that reaches every definition the plugin already knows.

## Writing session (read-only)

The Study Flow tab gains a **Writing session (read-only)** disclosure.

- **Count words** reports the active note's words, sentences and estimated
  reading time (200 words per minute, one-minute minimum).
- **Start session** records the note path and its current word count.
  **Finish session** then stores one local row with the start, end and number
  of words added; **Cancel** discards the running session without recording it.
- A shorter note never reports negative words, a second start is refused while
  a session runs, and at most 200 finished sessions are kept.
- The disclosure shows the smoothed session totals for the newest five rows.
- The note is only read — from the open editor, or its cached file. Nothing is
  written to it, nothing is indexed in the background, and no vault-wide word
  count is built.

## One glossary for notes, lectures and vocabulary

**Build glossary** in the Vocabulary tab now fills the same read-only index from
three places:

- `Term: definition` lines and two-column tables in Markdown notes, as before.
- The saved **vocabulary** list, marked `source: vocabulary`.
- Lecture-note vocabulary tables (`| Term | Definition | Lecture |`), which the
  same parser already reads; the extra column is ignored.

A note definition wins over a duplicate vocabulary word, duplicates are counted
rather than merged, and the lookup still ranks exact, prefix, inside-term and
inside-definition matches. Vocabulary rows say `Vocabulary list` instead of
linking to a note, and the index line reports how many came from the dictionary.

## Boundaries

- No note is edited or created by either feature, and both write only their own
  slice of plugin data.
- No dependency, provider, network request, new module switch or new top-level
  surface was added; both live inside existing, already opt-in tabs.
- §5.22.12's subject colours and event tags remain behind the owner gate, and
  the generic template builder and import-only attachment routing stay unranked.
