# MCQ Tracker 1.171.0

The Reference **Graph** tab now works like a short Desmos expression list instead of a single box.

## Several expressions at once

- Every row can hold an expression in `x`, an explicit equation such as `y = 2x + 1`, a reusable definition such as `f(x) = x^2`, or an implicit relation such as `y^2 = 2x + 1`.
- Rows below a definition can use it by name, so `f(x) = x^2` followed by `g(x) = f(x) + 1` and `y = g(x)` plots the composed function.
- Implicit relations do not need to be solved for `y`. Circles, sideways parabolas and ellipses such as `x^2 + y^2 = 9` and `x = y^2` are traced directly.
- Each row has its own colour and a dot that hides or shows it without deleting the text.
- **Add expression** appends a row, the row's × button removes it, and Backspace in an empty row removes that row too.
- The window has separate minimum and maximum fields for `x` and `y`, with labelled grid ticks. The default window is `-10` to `10` on both axes.
- A row that cannot be plotted shows its own message beneath the field, and the other rows keep drawing. Nothing is rejected silently.

## Still local

The parser and plotter accept the same restricted language as before: `x`, `y`, `pi`, `e`, the listed trig, log and root functions, and `+ - * / ^`. There is no `eval`, no `Function`, no network request, no calculator service and no Desmos key or code. An unknown name, a pasted script or an unsupported character is rejected with a message instead of being evaluated.

## Verification

**1,380 tests pass / 0 fail**; `npm run check` is clean across **230 modules**; `main.js` is rebuilt from `src/`. Four new tests cover row parsing, shared `f`/`g` definitions, the accuracy of traced implicit curves, per-row errors, and adding, hiding and removing rows in the view.

**Known gate:** the graph is covered by the automated suite and the mounted-DOM view test, not by a hand check in a live Obsidian vault on desktop and phone.

## Upgrade

Install **1.171.0** with BRAT, the community directory when it updates, or by copying the three release assets into `<your vault>/.obsidian/plugins/mcq-tracker/`. Reload Obsidian. No data migration or settings reset is required.
