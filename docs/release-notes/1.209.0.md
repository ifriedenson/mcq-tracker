# MCQ Tracker 1.209.0

Completes the extended calculator roadmap: 3D curves, audio trace, vector fields
and the JSXGraph presentation adapter.

## What changed

- **3D curves:** the Reference 3D tab accepts `(x(t), y(t), z(t))` curves,
  optional `t` bounds, a colour, and Draft / Balanced / High detail. Curves and
  the detail level persist with the surface, box, camera and points. The tab can
  save the complete scene as a PNG and build a printable sheet.
- **Audio trace:** Play audio trace sonifies visible curve samples and points
  with a bounded schedule of Web Audio oscillators. Pitch follows z, pan follows
  x, and gain adds a small y cue. Stop audio releases the graph. No audio file,
  network request or autoplay is used.
- **Vector field:** a new **Vector field** Reference tab evaluates local
  `P(x, y)` and `Q(x, y)` expressions, draws quiver arrows with magnitude scaling
  or normalization, and adds RK4 streamlines. The window, density, arrow scale,
  streamline length and colour persist in `settings.reference.vectorField`.
- **JSXGraph adapter:** Geometry and Vector field tabs can open an interactive
  board using the vendored **JSXGraph 1.14.2** MIT build. The adapter translates
  the local point/segment/circle/polygon and quiver/streamline records into
  JSXGraph elements. It runs locally and never contacts a network.
- The four formerly queued roadmap rows 1.206–1.209 are completed by this one
  consolidated release. Separate 1.206–1.208 tags were not created.

## Licence and limitations

JSXGraph is dual-licensed LGPL/MIT; this release uses the MIT option. The
vendored `vendor/jsxgraph-core.js` is the 1.14.2 distribution with only its
`supportsES6` feature probe replaced by a static true result and no source map.
The copyright and MIT text are in `NOTICES.md` and travel inside `main.js`.

Known limitations: 3D rendering remains intentionally low-resolution, the audio
trace is a study cue rather than a musical instrument, and the JSXGraph board is
a presentation layer over the local geometry/field records. A live Obsidian
visual/audio pass on desktop and phone remains an owner check.
