# MCQ Tracker 1.210.1

Adds an opt-in **Time blocks** planner to Study Workspace and makes it coexist
with the current calendar instead of creating a second schedule.

## What changed

- Day, Week, Grid, Backlog, Routines, Projects/domains and Timeline views cover
  one local planner. Blocks own time; tasks live inside them. Routines are
  offers, projects and domains are optional lenses, and the Backlog reuses open
  study tasks without creating a duplicate task list.
- When the existing Calendar module is on, Day and Week show its classes and
  events as read-only context, including event count, booked minutes and any
  block that overlaps a calendar event. Nothing is written, moved or copied, no
  calendar note is required, and the planner still works with Calendar off.
- **Show calendar events** is on by default and can hide that context.
- **Write day note** exports a readable Markdown file with a `## Schedule`
  section. The planner remains the editable source; this is not two-way sync.
