# 1.286.0 — A Study agent that reads like a chat app

This release rebuilds the Study agent's chat surface so it looks and behaves
like a modern assistant pane, while every behaviour still goes through the
existing send, budget, model, review and queue paths. There are no new
dependencies, providers or network requests.

## What changed

- **Header.** An accent mark, the **Study agent** name, and a live
  `Tutor · <role>` / `Agent · <role>` subtitle sit beside the per-chat model
  picker and the **New chat** / **Save chat** actions.
- **Thread.** Each turn is an avatar row with a speaker name: user messages are
  accent bubbles aligned right, assistant replies are quiet bubbles aligned
  left, and per-message actions (Bookmark, Copy link, Rewind, Fork, Copy, Add to
  My Notes, Regenerate) collapse into a low-contrast row under the bubble.
  While a reply is being prepared the thread shows a three-dot typing row.
- **Empty state.** A centred greeting with three starter prompts — Explain this
  note, Quiz me on it, Plan my next hour — replaces the blank pane; the prompts
  disappear once the conversation has a turn.
- **Composer.** One rounded card holds the context switches, mention and PDF
  chips, the borderless draft box, and a toolbar with mode, role, `@`, **PDF**,
  tutor commands, saved study commands, **Stop** and **Send**, followed by the
  token ring and cost/token footer.
- **Design language.** Every colour, radius and font comes from Obsidian's own
  CSS variables, so community themes, dark mode, compact density and the
  mobile layout keep working. The plugin's `qt-*` naming and its existing chip,
  meter and hint conventions are reused rather than a parallel design system.
- **Clean-room.** Only public layout and interaction ideas were used; no
  AGPL-3.0 code, class names, prompts or stylesheet from Obsidian Copilot were
  copied. This is the same boundary recorded in `plan.md` §5.18.1.

## Limits

This is a DOM-harness verification, not a visual Obsidian pass. The stylesheet
was written against Obsidian's documented variables and the existing `qt-*`
surfaces, but no real Obsidian window, phone or theme was opened here. A human
should open the Study agent once in a light and a dark theme to check spacing.
