# MCQ Tracker 1.210.12

Course health rows can be acted on.

## What was wrong

The **Course health** tab listed each course with its status, lecture and absence
counts and its checks, but every row was text only. A warning such as a missing
grade, low attendance or overdue task told you something was wrong without any
way to get to the course it belonged to.

## What it does now

- Each row keeps its checks and adds how many warnings remain for that course.
- Each row offers **Overview**, which opens the existing course overview modal —
  the same one the Courses tab uses — for that course.
- The tab stays read-only: no check is recalculated differently, and no grade,
  task, note or schedule is changed.

## Boundaries

- No new modal, query, setting, dependency or write path. The action reuses
  `plugin.openCourseOverview`.
- The four course-health checks and their thresholds are unchanged.
