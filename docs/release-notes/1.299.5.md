# 1.299.5 — Dialogs announce themselves

Every modal, picker and dialog overlay now has an accessible name that matches
what the surface shows or what it is for.

## What changed

- **One naming layer.** `src/a11y.js` adds `describeDialog()`, `QtModal` and
  `QtFuzzySuggestModal`. When a dialog opens, the container points at its
  visible `h1`–`h4` through `aria-labelledby`, with a stable generated id, and
  gains `role="dialog"` plus `aria-modal="true"`.
- **All 65 dialog classes converted.** The 60 `Modal` subclasses and 5 fuzzy
  pickers across 54 files now extend the shared bases; the card-archive and
  course-template surfaces that built a raw `Modal` use `QtModal` too. The
  visible heading is associated, never moved or reworded.
- **Pickers state their purpose.** Fuzzy pickers have no heading, so each
  supplies a written label: `Choose a PDF`, `Choose a PDF to add pages`,
  `Choose an image`, `Choose a question folder` and `Find a question`.
  `PdfAttachModal` uses `Attach a PDF`; `EpubReaderModal` uses `EPUB reader`.
- **Custom overlays are covered.** The question-actions, question-menu and
  review-actions sheets already carried `aria-label` (and the two sheets
  `aria-modal`); the audit now enforces that.
- **No behaviour change.** No note format, review schedule, setting, data path,
  command or network request changed.

## Verification

`tests/helpers/a11y-audit.js` now parses every `class … extends Modal` and
`extends FuzzySuggestModal`, every `new Modal(...)`, every dialog file's heading
or purpose label, and every `role: "dialog"` container. It fails on a raw base
or an unnamed container. `tests/a11y-labels.test.js` drives `describeDialog`
and `QtModal.open()` to prove heading association, the fallback label, and that
reopening reuses the heading id; it also pins representative dialog names.

The guard was proven live: reverting `CardModal` to `extends Modal` made the
suite fail with `CardModal extends Modal instead of the shared dialog base`,
then the file was restored. The full suite passes **2,584 tests**,
`npm run check` is clean across **356 source files**, and `main.js` is
**7,096,529 bytes** from **359 modules**. Naming and the bundle are proven
statically and by the built artifact; no Obsidian window or device was
available, so nothing is claimed about visual or screen-reader output.
