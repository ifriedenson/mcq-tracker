# MCQ Tracker 1.219.0

Two more PDF editor features. Both are ordinary edits: they change the copy in
the window, undo in one step, and are written only when you save.

## Shapes

**Add content** gains a shape row: **Shape** (rectangle, ellipse or line),
**Position** (the same nine text anchors), **Width pt** and **Height pt**,
**Colour**, **Fill**, **Shape page** and **Add shape**.

`addShape` draws into the page content at the anchor, in PDF points:

- a **rectangle** is a stroked box, filled at 18% opacity when a fill colour is
  chosen;
- an **ellipse** is inscribed in the same box, with the same fill rule;
- a **line** is a horizontal rule across the box's width, centred in its height.

It refuses a shape that is not one of the three, a box under 4 by 4 points, a
box over 2,000 points a side, a box larger than the page, a page that is not in
the file, and a rotated page — the same reason images and watermarks are
refused there, because the points are measured against the page, not the view.

## Page size

A **Paper** row adds **A4**, **Letter** and **Legal** with a **Resize page**
select and **Resize pages**. `resizePages` scales each targeted page by the
smaller of the two ratios, sets its page box and crop box to the target size and
leaves a page that is already that size alone. Content keeps its bottom-left
corner, so a page whose ratio differs leaves the spare room at the top and right
rather than clipping anything.

It refuses a rotated page and a PDF with live form fields: scaling content
without scaling a field's widget rectangle would leave the widget somewhere the
content no longer is, so flatten the form first.
