# MCQ Tracker 1.224.0

The PDF reader can now send the passage you are looking at to the Study agent.
It is the passage-level asking workflow from readers such as Banana Reader,
implemented with this plugin's own chat, citations and privacy guards. No
library, provider, account or network request was added.

## Ask from an annotation

Every sidebar row that has a quote or a note now has **Ask AI**. The row's quote,
note, page, type and tags are composed into one question and sent through the
existing Study agent chat. A highlight with no quote or note does not show the
button because there is nothing to ask about.

The question names its source as a PDF page link, for example
`[[Papers/Exam.pdf#page=2&annotation=ann-1]]`, and asks the model to cite that
source. The quote and note are explicitly labelled as untrusted study material,
not instructions, matching the existing document-import rule. The passage is
trimmed and capped before it reaches the prompt.

## Ask about a page

**Ask AI about this page** is in the reader toolbar. It rebuilds the current
page's text layer in reading order and sends that text with a `[[file.pdf#page=N]]`
source. The button explains when a page has no selectable text, so an image-only
scan points at OCR instead of sending an empty question.

The reply arrives in the normal Study agent panel, so streaming, Stop/Esc,
citations, Copy, Save chat, the conversation library and **Insert into active
note** all work unchanged. If AI is off, the reader says so and sends nothing.
A busy agent or a think-first delay is respected and nothing is queued.

## Tests

`tests/reading-companion.test.js` covers the citation link, quote and note
shaping, the page and note-only forms, the default and custom question, caps,
control-character removal, unsafe paths and page text ordering. The sidebar
tests cover the **Ask AI** row action, the plugin tests cover a cited prompt and
every refusal, and the reader test covers both the row action and a page with
and without text. Existing chat and sidebar tests still pass unchanged.
