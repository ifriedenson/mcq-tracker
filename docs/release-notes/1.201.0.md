# MCQ Tracker 1.201.0

A local geometry drawing surface in the Reference panel.

## What changed

- A new **Geometry** tab creates points by x/y coordinate and then builds
  segments, lines, rays, circles and polygons from those point ids.
- Every object is listed with its measurements: point coordinates, segment
  length/slope/midpoint, line slope, circle radius/circumference/area, and
  polygon vertex count/perimeter/area.
- The canvas draws a grid, axes and all objects. Points, lines, rays, circles
  and filled polygons have distinct labels and colours; the list and coordinate
  fields keep every creation step available without a pointer.
- The drawing is stored in `settings.reference.geometry`. Removing a point also
  removes objects that depend on it. Damaged stored objects are skipped rather
  than breaking the tab.
- The model and canvas painter are pure functions in `src/geometry.js`; a small
  `src/geometry-panel.js` attaches the tab's event and paint methods to the
  existing Reference view. No network request or eval is involved.

## Verification

- `npm test` passes: **1,485 tests, 0 failures**.
- `npm run check` passes: no dynamic code and `main.js` matches `src/`.
- Focused coverage: distances, slopes, midpoints, circle and polygon
  measurements, invalid primitives, dependent removal, stored-state
  normalization, the rendered tab, point/segment creation and persistence.

## Licence

No dependency was added and no third-party code was copied. The geometry model
and painter are written locally.

Known limitations: the viewport is fixed at -10..10, and the tab has not had a
live Obsidian visual pass.
