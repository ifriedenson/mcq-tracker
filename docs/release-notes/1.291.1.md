# 1.291.1 — PDF++ Customize links scroll to their setting

PDF++'s embedded settings tab is mounted inside MCQ Tracker's own page, where its `.vertical-tab-content` grows to the full 40,646 px content height and has no scroll range. Its `scrollToSetting` therefore did nothing in a real Obsidian settings window. The embedded copy now scrolls the addressed setting into Obsidian's actual settings pane, so PDF++'s **Customize...** links and `obsidian://pdf-plus?setting=...` links open **Settings → App & documents → PDF++** and land on the named control.

Real Obsidian 1.15.0 check: `openFromObsidianUrl({ setting: "colors" })` moved the outer settings scroller from 0 to **3,122 px** and placed the **Highlight colors** setting at y=46. The page still showed **307** vendor controls, the plugin-tab list contained no `mcq-tracker-pdf-plus`, the standalone PDF++ plugin was absent and `pdfPlusError` was empty. The Study agent suggestion deck rendered its three cards at 218 px in the 300 px pane with zero horizontal overflow.

Verification: `node --test` → **2,432 pass, 0 fail**; `npm run check` clean across **339 source files**; `main.js` is **6,848,417 bytes** from **342 modules**. No schema, dependency, provider or PDF++ vendor code changed.
