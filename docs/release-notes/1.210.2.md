# MCQ Tracker 1.210.2

Adds a one-way daily-note bridge to the opt-in **Time blocks** planner.

## What changed

- A new **Daily-note folder** setting points at vault notes named
  `YYYY-MM-DD.md`.
- **Preview daily note** reads that day's note without changing it, extracts
  `HH:MM Title` and `HH:MM - HH:MM Title` lines, and shows what is new versus
  what is already planned.
- **Add blocks** creates only the new local blocks. The daily note is never
  written; **Open daily note** opens the source for editing.
- Existing blocks are matched by start, end and title, so previewing or
  importing twice does not duplicate work.
