# 1.305.0 — Tasks grow up: mirror, repeats, priorities

## What was asked
Implement the four task-plugin capabilities judged worth having: tasks
that live in notes (one-way mirror), narrow recurrence, fuller natural
language, and priority flags. Everything else (two-way sync, scheduling
grammar, query language, outside integrations, board views) stays
deliberately unbuilt.

## What changed
- **Mirror.** `src/task-mirror.js` renders study tasks as
  Tasks-compatible lines (`- [ ] Title 📅 2026-11-20 ⏫ 🔁 every week
  #tag · Course`), open first (high priority, then due) with completed
  work under `## Done` and a footer naming the one-way rule.
  `plugin.syncStudyTasksToNote()` creates or rewrites the note
  (default `Study tasks.md`, folders created), exposed through the
  **Tasks: mirror study tasks to a note** command, a Task list header
  button and a workspace queue button, plus a Mirror note setting on
  the Tasks page.
- **Repeats.** `every day`, `daily`, `every week`, `weekly` and `every
  <weekday>` in a title set daily/weekly (`extractTaskRepeat`, wired
  into `addStudyTask` beside the due parser). Completing a repeating
  task spawns its next instance from its due date, or from today when
  overdue (`repeatFollowUp`); reopening never spawns. Sidebar rows
  cycle off/daily/weekly with badges everywhere.
- **Priorities.** High-priority stars sort above due dates in the Task
  list, the workspace queue, the summary and the mirror; every sidebar
  row toggles with an accessible name.
- **Dates.** `in N months` parses to calendar months, and `every
  Tuesday` keeps Tuesday for the due parser, so the task lands on the
  weekday and repeats weekly. Times of day are still never read: a
  task keeps no time, only a due date.
