# 1.299.1 — Ctrl/Cmd+P stays the command palette

Pressing `Ctrl/Cmd+P` now opens Obsidian's command palette only. An older
install can carry a custom hotkey that assigns the same chord to **Open
cards**; when the Cards module is off, that command's module guard opens
Settings to turn Cards on. Both actions then appeared at once.

## What changed

- **One startup repair.** `src/hotkey-cleanup.js` checks the custom hotkeys on
  `mcq-tracker:open-cards` and removes an exact `Ctrl/Cmd+P` binding. It does
  not touch Obsidian's own command-palette hotkey.
- **Narrow by design.** Only `P` with `Mod`, `Ctrl`, `Cmd` or `Meta` is
  removed. `Shift` and `Alt` variants, other commands and other keys are left
  alone. **Open cards** remains in the command palette, and its ribbon button
  is unchanged whenever Cards is on.
- **Visible only when it matters.** A short notice explains the change when a
  binding is actually removed. A clean install, or one without that custom
  binding, sees no notice and no write.
- **No data or feature changes.** Note formats, cards, review history,
  settings, AI setup and network paths are untouched.
