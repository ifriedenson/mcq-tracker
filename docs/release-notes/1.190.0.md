# MCQ Tracker 1.190.0

Accessibility in the Reference **Graph** tab. This release completes the Desmos parity roadmap recorded in `plan.md` §3.11: every row in that table is now **Shipped**.

## What is new

- **Accessible summary** — a screen-reader-only description that starts with the row count and the window (`Graph with 2 rows. Window x from -10 to 10, y from -10 to 10.`) and then one sentence per row. It carries `aria-live="polite"` and the label `Graph row summaries`, and is hidden with the new `.qt-sr-only` utility rather than `display: none`, so assistive technology still reads it.
- **Data table view** — a `Show graph data table` checkbox renders a native table under the graph with a caption (`Graph data table`), `scope="col"` headers for **Row**, **Expression**, **Kind** and **What is drawn**, and a `scope="row"` row number per row. Rows appear in drawn order.

## What the summary says per row kind

- Curves, polar, parametric and implicit rows report how many sampled points or segments were drawn, and how many points of interest.
- Inequality rows say whether a region is shaded; an empty region says so.
- Point and point-list rows report their marker count; definitions say `a definition, not drawn`; sliders report their value.
- A row that sampled only non-finite values says `no real values in this window`, an erroring row repeats its own message once, a long expression is kept in full, and a non-finite slider value shows `—`.
- An empty graph says `The graph is empty. Add an expression to draw a graph.`

## Interpretation and scope

- The row asks for a per-row text summary and a data-table view of the graph. The table is a table of **rows** — expression, kind and what is drawn — not of every sampled coordinate; the sampled data-bearing table remains the existing x/y data table used by regression.
- Only the accessibility behaviour above was added; row styling, sampling, points of interest, export, statistics and calculus are unchanged.
- An empty graph is refused for the table with `Draw a graph before opening the data table.` in the table area plus a `Notice`; nothing throws.
- No third-party code was copied and no dependency was added; the plan row references Desmos' accessibility guidance as behaviour only.

## Verification limits

- No real screen reader was available in this environment, so the summary and table were checked through the DOM attributes and recorded element tree, not by listening to NVDA, VoiceOver or TalkBack.
- The panel has not been exercised by hand in a live Obsidian vault, on desktop or phone.

## Still limited from earlier releases

- The cursor trace and hit-testing cover explicit and fitted rows only; polar, parametric, implicit, point and inequality rows draw but give no readout.
- The graph tab has no keyboard-only trace readout and no high-contrast or reduced-motion mode; the summary is text, not an interactive exploration tool.
