# 1.287.0 — Study agent UI, finished

The Study agent now reads as one coherent chat surface in the plugin's own
Obsidian theme language.

## Chat pane

- The header gains a **Chats** control. The saved-conversation library opens as
  a drawer and is closed by default, so the transcript is the first thing in
  the pane instead of a search/filter/rename block.
- Provider failures render as an alert card: an error mark, a plain title, the
  provider's message and a **Retry** button. The card announces itself with
  `role="alert"` and `aria-live="assertive"`; **Retry** carries an explicit
  `aria-label`.
- The empty status row is hidden, and the transcript no longer shows a stray
  horizontal scrollbar.
- Bubble, avatar, action-row and composer styling from 1.286.1 is unchanged.

## Settings

Settings → AI is grouped into cards instead of one flat list:

- **Study agent** — enable, tutor role, starter command hint.
- **Commands and skills** — saved commands, skills folder, starter commands,
  per-command models.
- **Session pacing and checks** — think-first timer/delay, answer verification.
- **Context and privacy** — the four aggregate context toggles.
- **Knowledge record** — build/rebuild.
- **AI backend** — OpenCode or Direct API, provider, key, model, connection
  test, edit review.
- **Models and request limits** — local pricing, per-feature models, caps.

Controls and their handlers are unchanged; only the grouping and surface are
new. Every colour, radius and font is an Obsidian variable.
