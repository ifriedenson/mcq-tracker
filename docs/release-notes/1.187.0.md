# MCQ Tracker 1.187.0

A math keypad and an examples gallery in the Reference **Graph** tab.

## What is new

- **Keypad**: a row of buttons above the expression list inserts `x`, `y`, `^`, `sqrt(`, `pi`, `theta`, `sin(`, `cos(`, `tan(`, `ln(`, `log(`, `e`, `(`, `)`, `abs(`, `<=` and `>=` into the expression you are editing, at the caret. Each has an accessible name such as `Insert sine` or `Insert greater than or equal`, so it is focusable and works from the keyboard, and after an insert the expression keeps focus with the caret placed after the inserted text.
- **Examples**: seven ready-made graphs load with one click — Parabola, Sine and cosine, Polar rose, Parametric circle (filled), Inequality region, Point list and Piecewise. Each button is labelled `Load example: …`.

## How the keypad inserts

- The insertion point is the focused expression's caret, and a selection is replaced. With no caret information (for example, a row that was never focused) the token is appended to the first expression.
- Inserting into a row that becomes a slider (`a = 2`, say) updates that row's parameter bookkeeping exactly as typing does, so the slider and every row that uses it pick the value up.
- The row is saved with the rest of the graph state after every insertion. An empty row list reports `Add an expression before using the keypad.` and changes nothing.

## How the examples load

- An example is only a short list of expression rows in the syntax the tab already accepts, so nothing new is evaluated: no third-party code, no network request and no copied Desmos source.
- When every existing row is blank, the example replaces the list. When rows already contain expressions, the example rows are **appended below them**, so a click cannot silently discard typed work. The loaded rows use the normal style defaults and are saved with the viewport, lock and display options.
- Each example draws: a test builds all seven and asserts every row reports no error and produces samples, markers or a shaded region in the default window.

## What is not included

- The keypad is a token inserter, not a symbolic input field: it does not render two-dimensional fractions, show a live preview or validate syntax as you type, and it has no per-row on-screen keyboard for a phone layout beyond the buttons.
- There is no search, paging or user-defined example, and loading an example does not change the viewport, so an example outside the current window may need **Reset view**.
- The gallery appends rather than asking, and offers no undo of its own; the row list and its × buttons are the way back.
- Neither the keypad nor the gallery has been exercised by hand in a live Obsidian vault, on desktop or phone, and neither has the graph canvas generally. The keypad tests inject a stand-in input element because this environment has no browser.

## Still limited from earlier releases

- The cursor trace and hit-testing cover explicit and fitted rows only; polar, parametric, implicit, point and inequality rows draw but give no readout.
- Row styling and export are unchanged by this release.
