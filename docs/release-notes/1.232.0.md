# MCQ Tracker 1.232.0

This release adds two local study blocks from the installed-plugin review: a
`tally` counter for self-marking a practice run and a `text-timer` for timing a
passage. Both store only their own state in the plugin's local settings; neither
writes a note, attempt, card, history row, streak, review date or schedule.

## `tally`

````markdown
```tally
title: Biology drill
correct: Right
incorrect: Wrong
steps: 1, 2, 5
id: biology-drill
```
````

The block shows side-by-side **Correct** and **Incorrect** buttons with live
counts, a step selector, total, accuracy, CPS and elapsed session time. Clicking
either button adds the selected step. **Reset** clears the counts and starts a
new session; changing the step does not reset the session.

- `title`, `correct`, `incorrect`, `step`, `steps` and `id` are optional.
- Labels are plain text, capped at 40 characters; steps are whole numbers from
  1 to 100, with at most six choices. The defaults are 1, 2 and 5.
- State is keyed by source path plus `id`, or by source path plus block content
  when no id is given. Add an `id` when two identical tally blocks in one note
  should keep separate counters.
- CPS is measured from the first click and needs at least one second of session
  time before it reports a rate. The state survives a reload and is bounded to
  300 sessions and 1,000,000 per counter.
- The tally is a scratchpad only. It is not a graded attempt and does not change
  the question or card scheduler.

## `text-timer`

````markdown
```text-timer
title: Read this
id: passage-1
---
The passage you want to time. The body is shown as plain text.
```
````

**Start** begins a count-up clock, **Pause** freezes it and **Start** resumes;
**Reset** clears the run. The body is deliberately plain text, so a passage
cannot inject markup. A run is capped at 24 hours. State is keyed by source path
plus `id` or block content, survives a reload and is bounded to 300 timers.

This is not a replacement for the separate Focus timer or Tag timers: it does
not log study time or add a history entry.

## Installed-plugin parity

The full audit, including the corrected community IDs for Advanced Tables, Hider
and Markmind, is in
[docs/installed-plugin-parity.md](../installed-plugin-parity.md). It records what
is already covered, what is a deliberate boundary, and what would need an owner
decision.

The short version:

- **Covered or substantially covered already:** Deadline (calendar, Pomodoro,
  tasks), Kairos (local Time blocks), MCQ Tracker (this plugin), Annotator and
  PDF++ (PDF annotations and editor), Desmos (local Reference Graph), Markmind
  (local Study Map), Omnisearch (`vault-search`), Copilot's workflow (the
  original Study agent), WordNet's lookup use (the local glossary), and
  pdf-to-md's OCR/import path (local OCR with explicit consent).
- **Added in 1.232.0:** Tally Counter and Text Block Timer.
- **Not added because the existing plan already rejects the surface:** Advanced
  Tables (reference only), Excalidraw (a separate drawing engine), Folder
  Sty1es, Hider, Minimal Theme Settings, Notebook Navigator and Recent Files
  (UI, theme or navigation rather than study state), and Download Pulse
  (developer download analytics).
- **Not added because of a hard boundary:** Code Runner needs an approved
  execution sandbox and language allow-list; the plan currently prohibits
  in-plugin code execution. Copilot is AGPL-3.0 and Desmos is GPL-3.0, so their
  code cannot be copied into this MIT plugin. No plugin source, styles or data
  were copied for this release.

No dependency, provider, account, telemetry or network request was added.

## Honest limits

- The tally counters are per note and device; they are not shared between
  devices and are not an exam result.
- Two identical tally or text-timer blocks without an `id` share one state key.
  Add an id to separate them.
- Text Block Timer's original plugin attaches a timer to arbitrary editor text.
  This port uses an explicit `text-timer` code block so the passage and its
  state stay portable in Markdown; it does not add an editor toolbar button.
- The rest of the installed-plugin list is not claimed as parity. The matrix in
  `docs/installed-plugin-parity.md` is the authoritative status list.
