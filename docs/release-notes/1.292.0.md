# 1.292.0 — Embedded graphs, maps, Grill sessions, deadlines and Recent Files

This release gives each of the six named plugins a concrete local surface. Deadline
and Web Browser were already implemented; the other four were missing a note or
view entry point.

- **deadlines** — a note block lists open assignment notes in the next N days,
  optionally for one course, with due-state labels and click-to-open. It reads the
  existing assignment notes and settings; it does not create a second task store.
- **desmos-graph** — a note block with `left`, `right`, `bottom`, `top`, `width`,
  `height` and `grid` settings, per-row `color`, `style`, `width` and `hidden`
  controls, common LaTeX normalization, and an SVG drawn by the existing local
  Reference Graph engine. Desmos is GPL-3.0, so no code, styles or service was
  copied. This is a 2D note embed, not the Desmos web app.
- **mindmap** — a visual, collapsible tree from inline Markdown or a Markmind note
  named by `Source:`. It reads the existing Markmind parser and keeps the note as
  the source of truth. It is a reading tree, not a drag-and-drop canvas.
- **grill** — a deterministic, self-graded recall session built from headings,
  definition lines and bold terms in a note or a `Source:` note. It uses no Grill
  code, AI call, embedding index or external service; rerun the block for a fresh
  session.
- **Recent Files** — a local view over Obsidian's own recent order, with a
  vault-mtime fallback, filter, pin/unpin, and click-to-open. Pins live in
  `settings.recentFiles`; there is no second history and no note copy. This
  deliberately reverses the former §5.24 do-not-adopt decision for this view.

The blocks are registered as `deadlines`, `desmos-graph`, `mindmap` and `grill`;
the view opens through **Recent files: open**. New code is in
`src/study-blocks.js`, `src/recent-files.js`, `src/recent-files-view.js` and the
matching registration in `src/plugin.js`; styles are scoped in `styles.css`.

No dependency, provider, network path, note schema, scheduler or storage format
was added. All content is local and the existing assignment, graph and Markdown
parsers remain authoritative.
