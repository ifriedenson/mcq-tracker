# 1.304.2 — Keep typing: task boxes hold the cursor

## What was asked
Typing a task and hitting Enter should leave the cursor in the make-task
box, so the next task can be typed with no mouse — the way Deadline does it.

## What changed
- Every quick-add task box refocuses its fresh input after an add: the
  Task list (`New task`), the Focus day scratchpad (`New quick task`),
  and each Study Workspace time-block input (`New task inside this
  block`). Works whether the task came from Enter or its Add button.
- The per-block input previously ignored Enter entirely (Add-button
  only); it now adds on Enter like the other surfaces.
- The mechanism is a refocus-after-render flag: the add sets it, the
  render rebuilds the form, then focuses the new input and clears the
  flag. Errors (empty title) never focus-steal; they show the message as
  before.

## A real crash found along the way
Rendering any time block with tasks in the Day plan called
`timeBlocks.statusChar(task.status)` for the per-task status button —
but `statusChar` was never exported, so the whole Day view threw. The
new block-task test drives the real Day view and exposed it; the helper
is now exported. The status button renders `[ ]`, `[x]`, `[/]`, `[-]`
as before.
