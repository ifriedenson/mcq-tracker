# 1.303.0 — Focus day: the calendar, the timer and quick tasks in one pane

## What was asked
Read every line of the Deadline plugin (`saydullayev017/deadline`: an
all-in-one Obsidian calendar, Pomodoro timer and task manager) and add each
feature it has that MCQ Tracker lacks.

## The comparison
Deadline's three surfaces were checked against this codebase:

| Deadline feature | MCQ Tracker before this release | Verdict |
| --- | --- | --- |
| Month calendar, prev/next month, today highlight | CalendarView: month grid plus classes, ICS import/export, exams and countdowns, timelines | Covered |
| Click a day to create or open its `YYYY-MM-DD.md` daily note (vault root, starter headers, new tab, transient feedback) | Day cells open event/resource notes; daily-note paths need a configured folder and the planner only previews | **Gap — added** |
| Pomodoro timer: start/pause/reset, animated bar, Ready/Running/Complete status, beep on completion | Pomodoro state machine + view + chime | Covered |
| Customizable work/break lengths | Work/short/long minutes, long-break cadence, autostart settings | Covered in Settings only — **inline editing added** |
| Always auto-start the next session after completion | Opt-in `autoStartBreaks`/`autoStartWork` settings | Covered (opt-in, not forced) |
| Tasks: add via button or Enter, checkbox toggle, per-item delete, empty message, completed styling | Task list: persistent, tagged, due-dated, sorted, with counts | Covered; session-only scratchpad is the complement |
| One combined view + ribbon + command | Three separate views, no combined pane | **Gap — added** |
| Break bar in a different colour | Single-style progress fill | **Gap — added** |

Nothing in Deadline exceeds what is here except the four gaps above. The
implementation is clean-room: no Deadline code, markup or styles were
reused (Deadline is MIT; NOTICES.md unchanged because nothing was taken).

## What changed
- `Open Focus day` command and `FocusDayView` (`src/focus-day-view.js`):
  a mini Monday-first month calendar with prev/next navigation and today
  highlight, the live Pomodoro card (start/pause/resume/reset/skip, counts,
  progress), and a quick task list that is a deliberate session scratchpad —
  it never writes to a note and says so in the pane.
- `plugin.openDailyNote(dateKey)`: validates the date, resolves the Time
  blocks daily-note folder when one is set (else the vault root, never
  escaping `..`), creates the note from a starter template (`# date`,
  `## Schedule`, `## Notes`) when missing, and opens it in a new tab.
- `plugin.setPomodoroDurations()`: clamped 1–180 minute work/short/long
  edits shared by the `Adjust` forms in both timer views; a paused timer
  resets to the new phase length, a running one keeps its remaining time.
- Green `is-break` progress fills in both timer views; theme-aware styles
  plus a narrow-pane layout.

## Evidence
- `tests/focus-day.test.js` (12 tests): Monday-first grid math for November
  2026, year-boundary shifts, date-key validation (including Feb 30),
  root/folder/escape daily-note paths, the template, session task
  add/toggle/delete, create-then-reopen through the fake vault, duration
  clamping and paused-reset vs running-keep, the rendered pane (calendar,
  timer, scratch list, today highlight, empty message, Adjust form, break
  fill), and command registration.
- Existing pins updated deliberately: the Pomodoro secondary controls are
  now Reset/Skip/Adjust, and the inventory counts the two new module groups
  and the new command.
