# MCQ Tracker 1.172.0

This release adds a **Task list** to the sidebar. No data migration or settings reset is required.

## A task list in the sidebar

- The sidebar **Task list** shows your existing tasks — the same local rows as Study Workspace → Tasks — with **open**, **overdue** and **due today** counts.
- Overdue work is labelled with how late it is, today's work says **Due today**, and completed tasks move to the bottom with a strike-through.
- Add a task with an optional due date, tick it to complete it, untick to reopen it, and delete it with the row's **×** button.
- **Open workspace** jumps to the full Tasks tab, where exam tasks and the rest of the workspace live.
- The list opens from the **Open the task list** command and the `list-checks` ribbon button. It uses the right sidebar, falls back to a tab on phones, and closes when the **Tasks** module is turned off. With Tasks off, the view explains where to turn it back on.

## Verification

The full suite covers the new view and its sidebar placement alongside the existing suites. `npm run check` verifies the generated bundle, and the three release assets are published by the release workflow. No note format, scheduler, gradebook or task-data change was made.

## Upgrade

Install **1.172.0** with BRAT, the community directory when it updates, or by copying the three release assets into `<your vault>/.obsidian/plugins/mcq-tracker/`. Reload Obsidian, then run **Open the task list** or use the ribbon button.
