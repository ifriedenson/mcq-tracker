# 1.243.0 — PDF bookmarks

Released Nov 4, 2026.

## What changed

- **Read the document outline.** `readOutline` returns every bookmark of a PDF as a flat list of
  title, page and nesting level, in reading order. It reads the real catalogue tree (`/First`,
  `/Next`, `/Dest` or a `/A /GoTo` action, including destinations stored as indirect objects)
  and caps the walk so a damaged or cyclic file cannot hang it.
- **Write it back.** `setOutline` replaces the whole outline with a real PDF outline tree: root,
  parents, previous/next siblings and counts are all written as indirect objects, and every entry
  points at a page with `/Fit`. An empty list clears the outline. Replacing an outline twice leaves
  only the new one.
- **The editor row.** **Add content → Bookmarks** shows the current bookmarks as text, one
  `Title | page` per line with two spaces of indent per level, and **Save bookmarks** parses it,
  validates it and writes it as one undo step. A malformed line reports its number and writes
  nothing.
- **Refusals, each with a message and no change:** an empty or over-long title, a page that is not
  in the file, an excessively deep level, a nested entry that follows nothing, a first entry that is
  not top level, a non-list argument and more than 200 entries.
- Limits: 200 bookmarks, 120 characters per title and three levels.

  back exactly, the raw tree (root count, an item's descendant count, the sibling chain), replacing
  an outline, clearing it and the catalogue losing `/Outlines`, every refusal, the textarea format
  round-trip, and a link/outline destination stored as an indirect object.
- Full suite **1884 pass**, `npm run check` clean across **297 source files**, `main.js` current
  across **298 modules** at **4,923,635 bytes**, and `git diff --check` clean.

## Limits

- Bookmarks point at a whole page (`/Fit`): no zoom, position or named destinations yet.
- The outline is replaced as a whole rather than edited item by item, and an outline written by
  another tool is read but not preserved field for field.
