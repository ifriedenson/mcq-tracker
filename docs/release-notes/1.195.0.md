# MCQ Tracker 1.195.0

Undo, redo and duplicate in the graph expression list.

## What changed

- **Undo** and **Redo** buttons above the expression list, with correct disabled
  states when there is nothing to restore. Undo restores the real row list, so
  adding, editing, deleting, loading an example, inserting from the keypad and
  duplicating are all reversed as whole states, not as text-field edits.
- **Duplicate expression N** on every expression row copies that row directly
  below it and redraws the graph from the resulting list.
- History is bounded to 50 steps and is session-only, so memory cannot grow
  without limit, a new edit clears the redo stack, and saved settings are
  unchanged. A settings object saved before this release opens with an empty
  history and the same rows as before.
- The actions are labelled buttons, so they are reachable from the keyboard, and
  a focused expression field also accepts Ctrl/Cmd+Z, Shift+Ctrl/Cmd+Z and
  Ctrl/Cmd+Y. Every undo, redo and duplicate change is announced in the existing
  polite live region.

## Licence

No dependency was added and no third-party code was copied. The history buffer
and duplicate logic are written locally.

Known limitations: the graph tab has not had a live Obsidian hand pass, and no
real screen reader was available to hear the announcements. History is
deliberately not persisted, so it starts empty in a new view or after a reload.
