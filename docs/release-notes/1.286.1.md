# 1.286.1 — The Study agent pane, actually rendered

1.286.0 rebuilt the Study agent's chat surface but was verified with DOM
assertions and stylesheet lint only. This release renders the pane's real
markup with `styles.css` and Obsidian's default theme variables in headless
Chrome, at sidebar widths of **320, 420 and 560 px** in **light and dark**,
and fixes every defect that exposed.

## Defects the render found, now fixed

- **The header collapsed at 320 px.** The per-chat model picker plus **New
  chat** / **Save chat** left the title 2 px wide and wrapped "Study agent"
  mid-word. The model picker now lives with the send controls, the title and
  subtitle ellipsis instead of wrapping, and the header stays one row down to
  320 px.
- **The composer covered the thread.** A sticky card inside a scrolling pane
  floated over message text. It is now a pinned footer card with the send
  controls on their own row below 380 px, so **Send** never falls out of the
  card or off the bottom.
- **Action rows were uneven and cramped.** **Add to My Notes** inherited a
  36 px height while Bookmark / Rewind / Fork sat at 22 px. The row is now one
  26 px height (30 px below 380 px, for touch), with the generic save-note rule
  overridden inside the thread.
- **User bubbles failed contrast.** White on Obsidian's default accent is
  3.91:1, below the 4.5:1 small-text threshold, and the action row was dimmed
  further. User messages are now a tinted surface with normal text and an
  accent edge, so both themes pass while the accent still marks the turn.
- **The empty state could disappear on a rebuild.** `build()` emptied the
  panel but left the old `draw()` signature, so the first render after a
  rebuild was skipped. `build()` now resets the signature.
- **Readability:** the empty-state greeting is centred and fills the pane; the
  context disclosure and composer placeholder are shorter; the hint bar no
  longer repeats the command list that the toolbar dropdown already shows.

## Rendered evidence

`docs/render/study-agent/` holds 28 PNGs — `{light,dark}-{320,420,560}-{empty,thread,busy}.png`
(full pane) and the matching `-frame.png` (the 900 px sidebar with the pinned
composer) — plus `metrics.json` with every measured box, overflow flag, tap
target and composited contrast ratio. The final pass reports **0 issues**:
no horizontal overflow, nothing outside the pane, no toolbar control outside
the composer, no overlapping header or toolbar children, no tap target under
24 px, and no failing non-decorative text contrast in either theme.

## Verification

- Focused chat suites (`agent-view`, `think-first`, `chat-panel-mentions`,
  `chat-tabs-queue`, `chat-plan`, `chat-pdf`): **74 pass**.
- `node --test` → **2,379 pass, 0 fail**.
- `npm run check` is clean.

## Limits

The render is headless Chrome with Obsidian's default variable set, not a
real Obsidian window. Community themes, compact density, the mobile WebView
and real device widths are still unrendered; the fonts are Liberation/DejaVu
stand-ins rather than Obsidian's UI font, so exact text metrics will differ
slightly in the app.
