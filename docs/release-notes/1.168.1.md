# MCQ Tracker 1.168.1

This patch completes the dedicated phone practice flow.

## Mobile review

- The post-answer review on a phone now has its own review header, Review | Passage tabs, one review scroller and a bottom action bar.
- **Done** and **Next question** stay in the action bar. **Open question note**, **Known** and **Exclude** live in the More sheet; the flag stays in the header.
- The existing review content is reused inside the phone shell, including choices, explanation, notes and AI review.
- Safe-area padding covers the action bar and the sheet. Review content can shrink and wrap, and the review scroller has no horizontal overflow.
- Desktop and tablet review keep the existing shared split. They receive no `.qt-m-*` classes, and every phone rule remains scoped under `.qt-mobile`.

## Verification

17 focused mobile practice tests pass, including the new review cases. The full suite passes **1,228 tests**, and `npm run check` is clean with `main.js` rebuilt.

The real iOS/Android visual audit remains a manual gate; the automated tests cover the DOM and CSS contract.
