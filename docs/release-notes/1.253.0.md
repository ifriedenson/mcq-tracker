# 1.253.0 — A custom dash keeps its phase

Released Nov 4, 2026.

## What changed

- **The phase is read.** A link whose `/BS /D` is `[phase [lengths]]` now reports `style.phase`
  beside `pattern`, `dash` and `border` — `readLinks` returns `phase: 2` for `/D [2 [5 3]]` and no
  phase key at all for a plain `/D [5 3]`, so a link without a phase reads exactly as it did in
  1.252.0 and an existing pattern is never dropped.
- **And settable or clearable.** `updateLink({ style })` takes an optional `phase`: a number from 0
  to 1000, a numeric string, or `null`/`""` to clear it. The phase survives a width change, a new
  area, a move to another page, a retarget to an address or an in-file jump, a highlight change and
  a removal, because it lives in the same `/BS /D` the editor already rewrites. Choosing `solid`
  drops the phase together with the lengths; the returned style equals what a re-read gives.
- **How it is written.** PDF's annotation border has no phase field of its own: `/BS /D` and
  `/Border` carry dash lengths, and a phase belongs to a content-stream dash operator. The editor
  therefore writes its phase as `[phase [lengths]]` in both places — `/BS << /W 3 /S /D /D [2
  [5 2]] >>` and `/Border [0 0 3 2 [5 2]]` — and writes the plain flat lengths when there is no
  phase, byte-for-byte as 1.252.0 did. A file produced by another editor keeps its flat array and
  reads with no phase.
- **The editor row.** **Add content → Links** gains a **Dash phase** field beside **Dash lengths**:
  a number sets the phase, `none` clears it (leaving the lengths), and an empty field leaves it as
  it is. The hint names it (`Link 1: 1pt dashed border, custom dash 5 3 phase 2, no highlight`) and
  the status reads `with a custom dash (5 2, phase 3)`. One undo step, and only **Save a copy**
  writes.
- **Refusals, each with a message and no byte change:** a phase that is not a single finite number
  from 0 to 1000 (`"two"`, `"1 2"`, `-1`, `2000`, a list), a phase given with a dash that is not
  `custom`, and a phase given when there are no lengths to phase. Every 1.252.0 refusal still
  stands — a border or dash word outside the offered set, `custom` without a pattern, a pattern that
  is not 1–8 numbers above 0 and at most 100, a pattern without the custom dash — as do the five
  deliberate refusals and the unmodelled-action refusal.

## Verification

- Four new tests were written first and run against 1.252.0. Engine:
  `# tests 3 / # pass 0 / # fail 3` — `reads a custom dash phase` reported the pattern as `[2, 0]`
  (the nested array read as two lengths) with no `phase`, and the write and refusal tests failed on
  the same missing key. Window: `# tests 1 / # pass 0 / # fail 1`, reading `['custom', [2, 0]]`
  where `['custom', [5, 3], 2]` was expected. After the change: engine **84 pass / 0 fail**, window
  **23 pass / 0 fail**.
- What they assert: `/D [2 [5 3]]` reads as `dashed`/`custom`, `[5, 3]` and phase 2 while a plain
  link has no phase key; a chosen custom dash `[5, 2]` with phase 2 writes `/BS /D [2 [5 2]]` and
  `/Border [0 0 3 2 [5 2]]` after a width change to 3, keeps the phase through a new area, an
  address retarget and a page-jump retarget, re-reads as `page` with `[5, 2]` and phase 2, and
  `phase: null` clears it back to a flat `/D [5 2]`; every invalid phase and every phase without a
  custom dash is refused with the dash left exactly as it was, while a phase-only change on an
  existing custom dash is a real edit.
- The window test drives the real built `main.js`: it opens a PDF whose link already has `/D [2 [5
  3]]`, checks the hint says `phase 2`, types **Dash phase 4** and presses **Style link**, changes
  the width to 2 with the phase kept, retargets the link with **Change link**, clears the phase by
  typing `none` and styling again, then saves a copy — the source PDF is asserted byte-identical,
  and the copy re-reads as a custom dash `[5, 3]` with width 2 and no phase.
- Full suite **1919 pass**, `npm run check` clean across **297 source files**, `main.js` current
  across **298 modules** at **4,967,616 bytes**, and `git diff --check` clean.

## Limits

- The phase is an editor extension: another PDF tool reading `/BS /D [phase [lengths]]` sees an
  array it did not expect. A link without a phase writes the standard flat array.
- A phase is bounded to 0–1000 points and cannot exceed the pattern by more than the editor checks;
  the lengths themselves stay 1–8 entries above 0 and at most 100.
- Launch, remote go-to and named destinations are still converted rather than rewritten (1.251.0);
  actions this editor does not model are still preserved and refused for retargeting.
