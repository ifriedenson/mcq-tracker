# MCQ Tracker 1.194.0

Background images in the graph, calibrated to the axes.

## What changed

- **Background image** in the graph tab. Enter a vault image path such as
  `Attachments/diagram.png` and press **Insert image**; the image is drawn behind
  the grid, axes and curves, and **Remove image** clears it.
- **Two-point calibration.** Each of the two calibration points pairs an image
  position (0–1 across and down) with graph coordinates. The placement is
  axis-aligned scaling, so the two points can enlarge, shrink, mirror or flip the
  image, and every field is a labelled number input rather than a pointer-only
  drag. An opacity slider keeps the grid and curves legible over the image.
- The image is painted first inside the existing canvas scene, so the on-screen
  graph, the PNG export and the 1.193.0 print sheet all show it without a second
  renderer.
- Calibration changes, load failures, removal and opacity are announced in the
  existing polite live region, and the accessible summary describes the image and
  its two calibration points.
- The image state is saved in `settings.reference.graph.image`; a settings object
  saved before this release loads as an uncalibrated graph.

## Licence

No dependency was added and no third-party code was copied. The calibration
maths and the vault-image painting are written locally.

Known limitations: the graph tab has not had a live Obsidian hand pass, and no
real screen reader was available to hear the announcements. The image load path
is covered with a stand-in image object, not a decoded file in a running vault.
