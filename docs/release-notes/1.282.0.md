# 1.282.0 — A full Study agent workspace, plus Quick Practice links

## The Study agent becomes a workspace

This release turns the Study agent from a single chat panel into a local workspace. Nothing is switched on by default, no provider is added, and every AI action still uses the existing BYOK/OpenCode path.

### Quick Ask and reusable study commands

- **Quick Ask** works from the editor menu or command palette. It offers seven actions — Explain, Simplify, Quiz me, Find gaps, Rewrite clearly, Make cards and Study plan — and sends only the selection or whole note you explicitly chose.
- Answers support follow-ups and **Copy**, **Insert** and **Replace**. Replace refuses if the editor selection changed while the answer was pending.
- **Settings → AI → Study commands** stores up to 40 prompts of 2,000 characters. Run them as `/name` in the Study agent. `{selection}`, `{note}` and `{path}` expand only when that chat already allows the context.

### A conversation you can organise

- **Tabs.** Keep concurrent conversations open with isolated history, model, footer and queue state. Tab order is restored after reload.
- **Queued messages.** A follow-up waits visibly behind the active reply, can be cancelled or edited, and drains exactly once after the reply, Stop or an error.
- **Search, pins and archive.** The saved-conversation library is searchable, pinned rows stay at the top, and archived chats can be restored.
- **Quick Chat.** **Study agent: Quick Chat** opens a compact prompt and submits through the active panel, so model, mentions, context, budget and Stop/error handling are shared.
- **Message bookmarks.** Bookmark any message or copy an `obsidian://mcq-tracker-chat` link. The link reopens that conversation and focuses the message; a deleted target gets a plain Notice.
- **Model control.** Each chat and each slash command can carry its own model override. Resolution is chat override → command override → global chat model, with a visible fallback when a model is unavailable. Status shows which source won.
- **`/compact`.** Fold older Direct API messages into a deterministic local summary under the existing 12,000-token budget, keeping recent turns verbatim. It reports the no-op and impossible-recent cases and never calls a provider.

### Context, memory and reuse

- **`@` note/folder mentions.** Explicit mentions resolve at send time only while the Mentions switch is on, are bounded, and refuse a missing target instead of silently dropping it.
- **Context footer and ring.** The footer shows the model and an estimated 12,000-token budget; the compact ring shows the same state under the composer. Both update after sends and `/compact`, warn before an overrun, and hide when the chat is unused or budget data is unavailable.
- **Vault skills.** Notes in the configurable **Study agent skills** folder are read only while **Include skills** is on. Up to 20 skills of 4,000 characters each are loaded, capped at 8,000 characters in the prompt block and counted inside the same budget. **Study agent: create a skill note** writes a starter note.
- **Local memory.** Up to 50 short facts of 240 characters can be saved on this device and included only while **Include memory** is on. Key-like text is redacted before storage or display, and the editor offers add, edit and remove.
- **Projects.** Group saved conversations into up to 30 local projects of 60 characters, filter the library by project or unassigned, and remove a project without deleting its chats.
- **Markdown export.** Export one conversation as a metadata-headed note in `Study agent chats`, through the Vault adapter. It never overwrites an earlier export and redacts key-like text.
- **Cost estimates.** Enter a local `model | USD per 1M input | USD per 1M output` table under Settings → AI. The footer estimates the next send's input plus maximum reply, and **Study agent: show this chat's cost estimate** estimates the whole stored conversation. No price list is fetched and an unknown model has no cost line.

### Rewind, fork and plan

- **Rewind** removes later turns and returns that question to the composer. **Fork** copies the prefix into a new saved chat named `<title> (fork)` and switches to it, leaving the original untouched. Both work on the local Direct API transcript and refuse the first question.
- **Plan a multi-step task** asks the existing chat for a numbered plan. Every step starts unapproved; approve or skip each one, then **Run approved** sends the approved steps one at a time through the normal send path. Writes still use the review window, and a skipped step, declined write, failure, Stop or reload stops later steps and says so. The plan is stored with the conversation.

### PDFs and diagnostics

- **Attach PDFs to a chat.** Choose up to three vault PDFs and a page range (default 1–20, at most 40 pages each). The text layer is read locally through the existing PDF reader and sent as labelled untrusted study material with `[[file.pdf#page=N]]` citations. A missing, image-only or unreadable PDF refuses the send; paths and ranges persist with the conversation.
- **Local diagnostics.** **Study agent: save diagnostics bundle** writes a redacted report with plugin/platform details, current budget and model state, capability flags and recent local errors. It makes no network request or telemetry call.

The clean-room Copilot feature/UI inventory in `plan.md` §5.18.1 records what is covered, adapted, next or a boundary. No AGPL code, prompt or stylesheet was used.

## Cards: grader accuracy

The Cards view now summarizes the latest grade on each card in the current deck and course: AI-graded, local-graded and self-graded counts, the share of suggested ratings kept, and overrides, with an eight-week agreement trend. A card keeps only its latest grader metadata, so older attempts are not reconstructed, and this is agreement with your own choices — not an exam-accuracy claim.

## Quick Practice from a home-screen shortcut

`obsidian://mcq-tracker-quick` opens the same Quick Practice session as the command:

- `minutes=2`, `5` or `10`
- `count=5`, `10` or `20`
- optional `course=Biology`

Time and count cannot be combined. Unsupported values, a disabled module and a course with no matching questions show a Notice instead of opening a different session. The queue is still saved and resumable.

The sample vault also gains a fifth studyable question, `samples/sample-vault/Questions/math-audit.md`, covering fractions, a matrix, an integral and a simple `\ce{}` chemistry expression. `docs/math-rendering-audit.md` points at it for the visual audit.

## Limits and verification

- **No new dependency, provider or telemetry.** All new data stays in settings or ordinary vault notes. PDFs are read locally; no OCR or upload is added.
- **Bounded by design.** 40 commands, 20 skills, 50 memory facts, 30 projects, 100-card practice queues, 12,000 chat tokens and 40 PDF pages per attachment are the enforced caps.
- **Three owner passes remain open.** The math/chemistry visual check needs a real Obsidian window, the mobile check needs one iOS and one Android device, and the four README screenshots need a real window. None is claimed complete; steps are in `docs/plan-decisions.md`.
