# MCQ Tracker 1.184.0

Graph display settings in the Reference **Graph** tab.

## What is new

- **Minor gridlines** draws a lighter line between each pair of labelled major lines. Minor spacing is exactly a fifth of the major step, so majors and minors always line up, and the count is capped so neither end of the zoom range fills the canvas with lines.
- **Axis labels** draws `x` and `y` at the canvas edges. When it is on, the grid is inset by a 16-pixel gutter at the top and bottom so the labels never sit on the tick text or the border; the sampled curves keep the full canvas and their existing transform.
- **Pi ticks** labels the x axis at multiples of π/2: `-3π/2`, `-π`, `-π/2`, `0`, `π/2`, `π`, `3π/2`, `2π`, `3π`, `4π` and so on, including negative values and multiples beyond 2π. The step is chosen from the window span, so panning or zooming keeps a readable number of labels.
- **Angle mode** switches the x-axis labels between radians and degrees. Degrees mode also chooses angle-friendly steps (15°, 30°, 45°, 90°, 180°, 360°, …) and labels them with a degree sign, such as `90°`, `180°` and `-180°`.

## Defaults and persistence

- All four options are off at first, with radians as the angle mode, so an existing graph renders exactly as it did before this release.
- The choices are saved in `settings.reference.graph.display` beside the stored window and lock, and are restored when the view reopens. They survive panning, zooming, locking and resetting the viewport.

## What these settings do not change

- They are rendering options only. Sampling, roots, extrema, intersections, point markers and the cursor trace are identical with every option off, each option on, and in either angle mode; a test compares the full sampled rows, the points of interest and the trace values across those combinations.
- Pi ticks and degrees apply to the x axis only. Y-axis labels stay decimal, because y values are function values rather than angles.

## Edge cases

- A window too narrow for a readable π step (for example the minimum 0.02-unit span) falls back to decimal ticks instead of drawing one label or none.
- A window too wide for the largest π step (the 20,000-unit maximum) also falls back to decimal ticks.
- Labels for non-multiples of π/2 fall back to decimals rather than printing a misleading fraction.

## Controls

- The three options are labelled checkboxes with accessible names and the angle mode is a labelled select, so all of them are keyboard reachable and sit with the existing graph controls. Canvas keyboard panning and zooming from 1.183.0 is unchanged.

No new dependency, no `eval`, no `Function` and no network request: tick generation and label formatting are local.

## Still limited

- The cursor trace and hit-testing cover explicit and fitted rows only; polar, parametric, implicit, point and inequality rows draw correctly but give no readout.
- These settings have not been exercised by hand in a live Obsidian vault, and neither has the graph canvas generally.
