# MCQ Tracker 1.177.0

Domain and range restrictions plus piecewise definitions in the Reference **Graph** tab.

## Restrictions

- A trailing brace limits a row to part of its domain or range: `y = x^2 {0 < x < 3}`, `y = sqrt(x) {x >= 0}`, `x^2 + y^2 = 9 {x > 0}` and `{0 < y < 1}`.
- Comparisons can be chained (`0 < x < 3`), written with `<`, `>`, `<=`, `>=`, `≤`, `≥` or `=`, and joined with `and` or `or`.
- Two restrictions on one row combine: `y = x {x > 0} {x < 1}` means both must hold.
- Restrictions apply to expressions, implicit equations and inequalities. Nothing is drawn or shaded outside the restriction, and the existing dashed boundary for strict inequalities is unchanged.

## Piecewise definitions

- `y = {x < 0: -x, x >= 0: x}` switches value at each condition. A final case with no condition is the default: `y = {x < 0: x^2, x < 1: x, 2}`.
- Branches are evaluated in order, so the first true condition wins, and a row whose branches meet at a boundary stays continuous there.

## Composition

- Restrictions see parameter sliders, so `a = 2` plus `y = x^2 {x > a}` moves the cut-off with the slider.
- A restriction on a definition, slider or regression row reports a clear inline message instead of being ignored.

No new dependency, no `eval`, no `Function` and no network request: the condition and piecewise grammar extends the existing restricted parser.
