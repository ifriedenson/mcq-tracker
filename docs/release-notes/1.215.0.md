# MCQ Tracker 1.215.0

The PDF annotator is now a real reading tool: four mark styles, text
selection that captures the words, tags, a searchable index and an exportable
digest — still local, still writing only a Markdown sidecar.

## What changed

- **Four mark styles.** Highlight, underline, strike-through and box join the
  pen, highlighter, text box and eraser. Each is drawn from one shared paint
  path, so a mark looks the same on the page, after reload and at any zoom.
- **Select text.** A new **Select text** tool drags across the rendered page,
  reads the text items pdf.js already gives us, and turns the drag into a quote
  annotation with one mark per selected line. The quote and your note are saved
  immediately; the preview in the prompt shows exactly what will be quoted.
- **Tags and links.** Annotations carry up to six bounded, hash-free tags and a
  `[[file.pdf#page=3&annotation=ann-1]]` link that opens the exact annotation.
- **A searchable index.** The PDF annotations tab gains a search field and a
  type filter, shows each row’s note and tag chips, and can copy the exact
  annotation link.
- **Export.** **Export Markdown** writes a digest beside the PDF, grouped by PDF
  and page with quotes, notes, tags and links. A second export is numbered
  rather than overwriting the first.
- **Resume reading.** The reader remembers the last page of each PDF in local
  storage (never in the vault) and reopens there.
- **Reading without the modal.** `plugin.pdfAnnotationRows`, `updatePdfAnnotationNote`,
  `deletePdfAnnotation`, `exportPdfAnnotations` and the **PDF: export annotations
  to Markdown** command expose the same sidecar paths to the rest of the plugin.

## Boundaries

- The source PDF is never modified or copied; everything lives in the
  `.annotations.md` sidecar and is reversible by deleting it.
- No dependency, provider, network request or cloud upload was added. Text
  extraction uses the pdf.js that Obsidian already ships.
- Existing sidecars, page links and the §5.22.12 owner gate are unchanged.

## Verification

`tests/pdf-annotator.test.js` covers mark styles, quote selection, filtering,
counts, links, the Markdown digest, note edits, deletion, numbered exports and
reading position; the older pen, text-box and sidecar contracts still pass.
Full suite and `npm run check` are clean, and the release assets are
byte-identical to the committed files.
