# 1.307.18 — PDF imports read in order

Released November 18, 2026. Obsidian 1.15.1.

## Why

Two text-layer ordering defects scrambled PDF imports. `itemsToGapLines` sorted PDF.js viewport rows
bottom-to-top, so a two-column term/definition table and numbered exam questions arrived reversed, and the
flashcard gap detector subtracted screen coordinates the wrong way round, so its wide-column tab never
fired. Separately, a document written as `Question 1:` … `Question N:` never counted as numbered questions,
so it misclassified away from MCQ, and the document-card extractor could not be dismissed before its
preview appeared.

## What changed

- **Rows read top-to-bottom.** Viewport pieces sort by increasing y, so term/definition columns and
  numbered questions keep document order, with the answer key staying aligned to its questions.
- **Column gaps work in screen coordinates.** The flashcard gap detector uses the matching sign for
  top-to-bottom pixels, so a wide gap between columns becomes a tab again.
- **`Question N:` routes to MCQ.** The classifier's numbered-line pattern accepts the `Question N:`
  form, so those documents count their questions and choices correctly.
- **The extractor is always dismissible.** The document-card modal shows Cancel from the start; the
  Import control appears only when cards exist.
- **Narrow and touch layouts harden.** The home shortcut rows wrap (`qt-home-actions`), and
  coarse-pointer targets cover agent send, task-list star/remove, the calendar header, the task
  checkbox label, agent selects and suggestion dots.
- **Two time-bomb tests fixed.** The "every Tuesday" study-task tests hardcoded 2026-11-17, which
  stopped being the coming Tuesday the next day. Both now derive the coming
  Tuesday from the current date.

## Evidence

- `tests/cards-import.test.js` pins viewport-ordered rows and ordered numbered questions with their
  answer key; `tests/frq-import.test.js` pins prompt-before-rubric line order;
  `tests/document-classify.test.js` pins `Question N:` routing; `tests/document-cards.test.js` pins
  the pre-preview Cancel.
- `node --test`: **3,020 pass, 0 fail**. `npm run check`: clean.

No note format, setting key, review schedule or network default changed.
