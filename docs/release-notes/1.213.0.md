# MCQ Tracker 1.213.0

## Study agent in the right sidebar

Open **Study agent: open the sidebar** to chat with the configured AI provider
without leaving your notes.

- Local cited search: results show the note path and line, and the snippets are
  shared with the next chat question.
- Chat reuses the plugin's existing OpenCode or Direct API provider settings.
- Card creation uses the existing tool review window: proposals are shown before
  anything is written.
- Full-vault file context is opt-in. Local search works with AI turned off.
- The implementation is original MIT-licensed code; no Obsidian Copilot source
  was copied.

## Verification

- Unit tests cover local scored search, citations, opt-in context and the
  no-provider path.
- Full suite and bundle check are run at the release commit.
