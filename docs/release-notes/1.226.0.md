# MCQ Tracker 1.226.0

This release closes the last reader gap from the PDF editor audit: the reader
now scrolls continuously through every page instead of showing one page at a
time. Page navigation, text selection, annotations, the sidebar and read-only
form-field boxes all follow the page the reader is actually showing.

## What changed

- `PdfInkModal` renders every page once, in one vertical stack. Each page has its
  own wrapper, label, image and overlay canvas, so all pages are reachable in one
  scroll flow.
- Scrolling computes the page at the reading line and updates the page field and
  page count. **Previous**, **Next** and the page field scroll the target page
  into view; the page field never claims a page the reader has not reached.
- Text layers and annotation layers are kept per page. Selecting text, copying a
  selection, highlights, underlines, strike-through, boxes, notes, freehand ink,
  text boxes and sidebar selection all use the active page's own data.
- Form fields from the existing pdf-lib form model are drawn as read-only boxes
  on their page. Their PDF rectangles are converted into the rendered page's
  top-left space, including 90/180/270-degree page rotation. Filling remains in
  **Edit pages and forms**, which still owns the writable form.
- **Save** flushes every dirty page in one sidecar update, not just the page that
  happens to be active. Undo/redo stays per page and the editor's page operations
  are unchanged.
- The reader no longer reloads the PDF and sidecar on each page move, so page
  rotation, reorder, insert, delete, extract and merge still reopen to the correct
  page order and annotation page map.

## Honest limits

- The reader renders all pages at open; it does not virtualize very large
  documents. A 2,000-page PDF is bounded by the existing 80 MB/2,000-page load
  limits but can be memory-heavy.
- Form-field boxes in the reader are **read-only**. Fill and flatten them in the
  page/form editor.
- Existing page text cannot be reworded or re-flowed. XFA and encrypted PDFs
  remain unsupported. Annotations stay in the sidecar until burned into a copy.
- Scanning still needs OCR before text selection has a text layer.
