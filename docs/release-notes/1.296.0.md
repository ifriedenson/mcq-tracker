# 1.296.0 — A simpler start and What's New

This release shortens the everyday path: new installs begin with a smaller
settings page, Import questions is at the top of Practice, the less-used
practice actions sit under **More actions**, and an update now opens a short
local **What's new** note inside Obsidian.

## What changed

- **What's new in Obsidian.** After an update, a short note lists the changes in
  that version. It is bundled with the plugin, uses no network, appears once per
  version on each device, and stays quiet on a genuine first run so the Start
  here note owns onboarding. Reopen it with **Show what's new** from the command
  palette or **Settings → Global → About**.
- **Simple settings.** New installs start with Practice, review, the Study agent
  and app settings. A single **Show all settings** switch reveals the full
  specialist tree and remembers the choice. Existing data files keep the full
  tree, and a deep link to an advanced page reveals it instead of being dropped.
- **Import at the top.** Practice puts **Import questions** above presets and
  filters. It stays visible with AI off and opens the existing setup screen
  rather than hiding the entry point.
- **Clearer practice actions.** Skip, mark known, bury, suspend and exclude move
  under **More actions**. Confidence and Submit remain the primary path.
- **Calmer imports.** Course, unit, skill and other note properties wait behind
  **Add details**. Importing into an existing folder adds questions instead of
  stopping, and an import that produced no notes now links directly to the AI
  settings page when the agent may be waiting for file-edit permission.
- **Clearer confidence labels.** The untouched default scale is now **Guessing /
  Probably Right / Confident**; custom labels are left alone. Ribbon buttons also
  carry matching accessible labels.
