# 1.244.0 — Form field maintenance

Released Nov 4, 2026.

## What changed

- **Rename a field.** `renameFormField` writes a new flat name on the field itself, so the value,
  the widget rectangle and the appearance stay exactly where they are and the renamed field stays
  fillable. The name is trimmed to 60 characters and refused when it is empty, unchanged, already
  used by another field, or when the field is a kind this editor does not manage.
- **Delete a field.** `deleteFormField` removes the field from the AcroForm and takes its widget
  annotations off their pages, then reports how many widgets went and how many fields are left. The
  rest of the form stays live and fillable, and nothing else on the page moves.
- **The editor row.** **Add content → Change a form field** has **Field**, **New name**,
  **Rename field** and **Delete field**. Each action is one undo step, and only **Save a copy**
  writes, so the original PDF and its sidecar are untouched.
- **Refusals, each with a message and no change:** no field name chosen, a name that is not in the
  file, an empty new name, the same name, a name another field already uses, and an unsupported
  field kind. An over-long new name is shortened to 60 characters rather than refused.

## Verification

- Three new real-byte tests: a rename keeps the value, the page and the widget, and the renamed
  field fills after a save and reload; a delete removes one widget and leaves the other fields live
  and fillable; and every refusal leaves the form untouched.
- 57 focused PDF-editor tests pass. Full suite **1887 pass**, `npm run check` clean across
  **297 source files**, `main.js` current across **298 modules** at **4,928,612 bytes**, and
  `git diff --check` clean.

## Limits

- Flat field names only: a field with a hierarchical `parent.child` name is renamed by its own
  segment, not restructured.
- Fields of a kind this editor does not manage are reported and refused rather than guessed at, and
  a deleted field's value cannot be recovered except by discarding the copy (or undoing it).
