# 1.288.2 — Study agent narrow-pane polish

This patch ships the fixes found by the current-tree render of the 1.288.1
Study agent. The transcript → **ChatControls** → composer structure and the
Copilot-style surface are unchanged; this is a narrow-width and evidence
release, not a new layout or behaviour.

## Changes

- The mode selector reads **Agent**; its full **Agent (notes)** / **Agent
  (files)** label remains in the title. Tutor roles show **Private**,
  **Socratic** and **Language**, with the full names in option titles and
  Settings, so the selected persona is not clipped behind the arrow at 320 px.
- The per-chat model selector reads **Chat default** and carries the effective
  default in its title, so a long model id does not compete with the composer
  controls.
- The first table column no longer wraps in assistant Markdown; at 320 px
  **Form** stays a word instead of breaking into `For/m`.
- At ≤340 px the five context chips use a 2 px gap, 5 px horizontal padding and
  11 px type, keeping all five on one row with 20 px slack.
- The empty-state suggestion detail is clamped to three lines instead of two,
  so the full description is visible (measured 49 px, with `clientHeight` equal
  to `scrollHeight`).
- `.qt-agent-role` has 84 px at the narrow container breakpoint.

## Evidence

The 16 chat images at 320/420/560 px in light and dark (thread, empty, busy and
error) plus the unchanged settings pair are in
`docs/render/study-agent-ui/`. They are current `ChatPanel.build()`/`draw()`
markup with the current `styles.css` and Obsidian's default light/dark
variables, not mockups. The README records zero horizontal overflow at all
three widths, empty cards of 268/368/480 px with equal margins, five context
chips on one row at 320 px, and the idle **Send** / busy **Stop** swap.
