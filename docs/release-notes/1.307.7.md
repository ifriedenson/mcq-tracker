# 1.307.7 — Every task action undoable and reachable

## Why
1.307.6 audited the task list's look and its add/complete/filter paths. The
remaining controls — star, repeat, tag edit, delete and the date field's
keyboard focus — had never been driven. Driving them on the plugin's own leaf
(19 states per theme, plugin DOM asserted, 1271px wide, Primary light and dark)
found two real defects.

## What was wrong
1. **Delete was final.** The row's × called `removeStudyTask`, which discarded
   the task and returned nothing: no confirmation, no undo, no recovery. One
   stray click cost the task.
2. **The date field's focus was split.** Tab into the native date control and
   Chromium moves focus to the month, day or year segment; those segments draw
   no ring, so the field looked unfocused while it held focus.
3. The notice's Undo control had no hover, focus or touch sizing of its own.

## What changed
- `src/plugin.js`: `removeStudyTask` returns the removed task;
  `restoreStudyTask(task)` puts it back with its id and every field.
- `src/task-list-view.js`: deleting shows `Deleted “Task”.` for 8 seconds with
  an **Undo** button that restores the task, re-renders, and disables itself so
  it cannot restore twice.
- `styles.css`: `.qt-task-list-date:focus-within` draws one ring around the
  whole field and the inner segments are explicitly ringless;
  `.qt-notice-undo` gains hover, pressed, `focus-visible` and a 44px
  coarse-pointer target.
- `tools/ui-audit/jobs-task-list.mjs`: 19 states, with `checks` returning
  `persisted`, `focusState` and `notice`, so each action is proven by what the
  plugin stored.
- Pins: `tests/task-list.test.js` clicks ×, clicks Undo and asserts every
  restored field; `tests/ui-tokens.test.js` asserts the date focus rules, the
  ringless segments and the notice button states.

## Evidence — live, Primary, 1280×900
- **19 states × 2 themes**, plugin DOM asserted, 1271px wide: 0 horizontal
  overflow, 0 sub-AA contrast, 0 sub-32px targets, stable row heights and
  aligned right edges.
- **Star:** one click writes `priority: "high"`, the second clears it.
- **Repeat:** four clicks persist `daily → weekday → weekly → (none)`.
- **Tag save:** tags `bio,exam` become `bio,exam,chem` in stored settings; the
  editor closes.
- **Delete:** the row disappears and the notice reads
  `Deleted “Read chapter 4 #bio”.` with Undo at 58×32; its text measures 4.84
  (light) / 5.63 (dark) and the Undo label 8.37 / 9.08.
- **Undo:** the task returns with its tags, priority, repeat and due date intact.
- **Date focus:** active element is the date input with a solid 2px ring at 2px
  offset across the whole 438×44 field in both themes.
