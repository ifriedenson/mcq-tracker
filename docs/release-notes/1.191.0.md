# MCQ Tracker 1.191.0

Graph expression folders.

## What changed

- The Reference graph's expression list can group rows into collapsible folders,
  Desmos style. **Add folder** inserts a header and a blank expression row; the
  header carries a name field, a live row count, a collapse/expand control and a
  remove button.
- A collapsed folder is not drawn. Its rows are skipped by sampling, the cursor
  trace, points of interest, points of interest crossing checks and the data-table
  view. Removing a folder header only ungroups its rows; it never deletes them.
- Folders and their collapsed state persist with the graph in `data.json`, and
  older saved row lists load unchanged with no migration.
- The 1.190.0 screen-reader summary now reports every folder, how many
  expressions it holds and whether it is collapsed.
- `plan.md` gains §3.12, the remaining Desmos graphing-calculator gap roadmap with
  per-row licence availability, target versions and statuses.

## Verification

- `npm test` passes: **1,455 tests, 0 failures**.
- `npm run check` passes: no dynamic code, and `main.js` matches `src/`.
- Focused coverage: folder grouping and visibility, collapse/expand UI and
  `aria-expanded`, the drawing skipping collapsed rows, the data-table view, the
  accessible summary sentence, the persistence round-trip, and removal keeping
  the grouped rows.

No dependency was added and no third-party code was copied. Desmos' own code and
service are proprietary; the folder interaction was implemented from scratch.

Known limitations: the graph tab has not had a live Obsidian hand pass, and no
real screen reader was available to hear the folder announcement.
