# 1.304.0 — Tasks understand days

## What was asked
Add a natural-language process to the tasks, so typing something like
`Practice 8 ap world questions today` makes the due date today,
`tomorrow` means tomorrow, and `tuesday` means Tuesday. MIT plugins doing
this were to be surveyed, and their code copied only if necessary.

## The survey
| Plugin | License | Approach |
| --- | --- | --- |
| `argenos/nldates-obsidian` | MIT | Natural-language date commands (chrono-style engine) |
| `Amato21/nldates-revived` | MIT | Multilingual date engine with `@`-triggers |
| `CorrectRoadH/obsidian-task-center` | MIT | Quick-add understands "tomorrow", weekdays |
| `nhannht/obsidian-smart-gantt` | MIT | Understands "due next monday", "tomorrow" |
| `kuberrr0/obsidian-integrated-tasks` | MIT | Built-in natural language parsing |

Copying was **not** necessary: every surveyed implementation leans on
chrono or a server-shaped parsing engine, which would break this plugin's
startup bundle budget (`check-startup-budget`: 360 eager modules /
5,500,000 bytes), and the needed expression set for task due dates is a
small closed set. `src/task-dates.js` is dependency-free original code;
no third-party source was copied. Times of day are never read — a task
keeps a due date, never a time.

## What changed
- `parseTaskDate(text, ref)` finds the first date expression: ISO dates;
  `today`/`tonight`/`tomorrow`/`tmr`/`yesterday`/`day after tomorrow`;
  bare and `this`-prefixed weekday names (full and abbreviated) resolve to
  the upcoming day including today; `next <weekday>` jumps a full week;
  `weekend` (Saturday, counting Sat/Sun as still-weekend); `next week`;
  `next month`; `in N days/weeks`; `on <month> <day>` and bare month days
  with year rollover.
- `extractTaskDue(title, ref)` returns the clean title plus the due date:
  the date's words leave the title, including a leading `by`/`on`/`for`/
  `due` ("Read it by Friday" keeps "Read it").
- `plugin.addStudyTask()` parses the title only when no explicit due date
  was picked, so a picked date keeps the title verbatim. This covers the
  Task list and the Study Workspace form with no per-view logic.
- The Focus day scratchpad parses too and chips the result (`Due today`,
  `Due tomorrow · date`, `Overdue · date`, `Due date`); both full surfaces
  hint at the trick under their add forms.

## Evidence
- `tests/task-dates.test.js` (10 tests): the relative/weekday/span/
  month-day/ISO matrix against a fixed Sunday, ordinary words staying
  dateless, title cleaning, explicit-date-wins, the plugin round trip, the
  scratchpad chip, the Task list hint, and chip labels.
- A picked date leaves `tomorrow` in the title; `may need review` parses to
  nothing.
