# MCQ Tracker 1.205.0

Implicit 3D surfaces in the Reference panel.

## What changed

- The **3D** tab now has **Explicit** and **Implicit** modes. Explicit mode
  keeps the existing `z = f(x, y)` surface. Implicit mode accepts an equation
  `F(x, y, z) = 0`, such as `x^2 + y^2 + z^2 = 9`, and renders its zero set.
- Both modes use the same bounded CPU ray-marcher, finite x/y/z box, yaw/pitch/
  distance camera, orbit/tilt/zoom/reset controls and labelled point overlays.
  The image remains 320 by 200 by default, capped at 80,000 pixels and 160 ray
  steps. There is no WebGL, mesh library, network request or `eval`.
- The chosen mode, expression, box, camera and points are saved in
  `settings.reference.threeD`. Settings saved by 1.204.0 load in explicit mode
  with their existing surface unchanged.
- Switching modes keeps the current expression when it is valid in the new mode;
  otherwise it loads a matching example (`z = x^2 + y^2` or
  `x^2 + y^2 + z^2 = 9`) so the canvas is not left blank.
- Implicit input is compiled through the existing restricted parser. A missing
  or extra equals sign, an incomplete expression or an out-of-domain evaluation
  reports a clear inline error and keeps the last valid surface visible.

## Verification

- `npm test` passes: **1,497 tests, 0 failures**.
- `npm run check` passes: no dynamic code and `main.js` matches `src/` across
  **250 modules**.
- Focused coverage: implicit compilation and evaluation, deterministic
  bounded sphere rendering, an empty bounded box, missing/multiple equals
  errors, the implicit/explicit mode switch, mode and expression persistence,
  and malformed implicit input preserving the previous surface.

## Licence

No dependency was added and no third-party code was copied. The implicit
residual, ray-marcher, camera and shading are written locally; both surface
modes use the project's existing safe expression parser.

Known limitations: the renderer is still intentionally low-resolution, and 3D
export, print and a live Obsidian visual pass are not part of this release.
