# 1.289.0 — Bluebook testing tools in the Practice view

Every tool College Board documents for the Bluebook app now has a local
counterpart in Practice. The full set lives in one **Testing tools** drawer,
opened from the question bar (or the phone More sheet), with the keyboard
shortcuts the app documents.

## What the drawer carries

| Tool | What it does here |
| --- | --- |
| **Timer** | Hides the running timer. A Quick Practice countdown brings it back with a five-minute warning. |
| **Option eliminator** | Turns crossing out on. Click a choice to cross it out, click it again to bring it back, or restore every choice from the panel. A crossed-out choice cannot be submitted. |
| **Highlights & notes** | Captures the current selection with four highlight colours or an underline and a per-highlight note, then lists every highlight for the question with a Remove action. |
| **Line reader** | Shadows the panes except for the band that follows the pointer. |
| **Calculator** | Basic and scientific keypads over the existing restricted evaluator. No network request and no `eval`. |
| **Reference sheet** | The standard SAT math formulas, grouped for lookup, with a pointer to the larger Reference module. |
| **Mark for review** | Uses the existing flag, now also shown in the question menu. |
| **Question menu** | Lists the Quick Practice queue, or the questions opened in this view, with answered, flagged and skipped counts; a row jumps back to that question. |
| **Zoom** | 50% to 200% in the same steps, applied to the question panes. |
| **Color contrast** | A high-contrast black-on-white surface using the `Canvas`/`CanvasText` system colours. |
| **Expand passage** | Gives the passage the full width while the question pane steps aside. |
| **Directions & help** | What each tool does and the shortcut table. |

Shortcuts follow the documented Bluebook map (`F1`, `Ctrl/⌘ + Alt + C/R/G/T/V/O`,
`Ctrl/⌘ + L`, `Ctrl/⌘ + H`, `Ctrl/⌘ + Plus/Minus/0`). Plain keys are untouched, so
Space/Enter still submits and Escape still ends the session.

## Where

- `src/practice-tools.js` — the tool catalogue, shortcut matcher, zoom and timer
  rules, option-eliminator state, highlight model and quote anchoring, question
  menu summary, SAT reference sheet and directions. Pure data and state.
- `src/practice-view.js` — the bar buttons, drawer, panels, highlighting paint
  path, line reader, zoom/contrast/expand application, per-question storage and
  the keyboard wiring.
- `styles.css` — drawer, panels, crossed-out choices, highlight marks, line
  reader, calculator, reference, question menu and shortcuts. Theme variables
  and system colours only; no hard-coded colour value.
- `tests/practice-tools.test.js` — 14 tests over the model and the real view.

## Limits

- Eliminations and highlights are kept per question for as long as the view is
  open, like a module in the official app; they are not written to notes or
  `data.json`.
- A highlight is anchored by its selected text. A selection that runs across
  several rendered blocks falls back to the first few words that sit inside one
  text node; the quote, colour and note are always listed in the panel.
- The question menu lists the Quick Practice queue when there is one, otherwise
  the questions opened in this practice session. It is not a fixed module.
- Nothing from College Board or Desmos is bundled: no code, question data,
  images, prompts or styles. The tools are clean-room versions for practice.
- The plugin still has no network request, dependency, account or provider
  change in this release.
