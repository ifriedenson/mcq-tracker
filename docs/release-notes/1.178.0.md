# MCQ Tracker 1.178.0

Polar graphing and a polar grid in the Reference **Graph** tab.

## Accepted polar syntax

- A row whose left side is `r` is a polar curve: `r = 1 + cos(theta)`, `r = 2 sin(3 theta)`, `r = theta`, `r = 3` and `r = sqrt(abs(cos(5 theta)))` all work.
- `theta` and `θ` are the same name; the angle is measured in radians from the positive x-axis and the radius is the distance from the origin.
- The radius expression takes the same grammar as every other row: the functions `sin`, `cos`, `tan`, `asin`, `acos`, `atan`, `sqrt`, `abs`, `ln`, `log`, `exp`, `floor`, `ceil`, the constants `pi` and `e`, the operators `+ - * / ^` and `f`/`g`/`h` definitions from earlier rows. Parameter sliders (`a = 2` then `r = a + cos(theta)`) are read live.
- The sweep always runs `0` to `2π` inclusive, so a closed curve meets exactly at the seam instead of leaving a gap, and `theta` never wraps mid-line to draw a chord across the window.
- A negative radius is plotted on the opposite side of the origin, which is what makes inner loops such as `r = 1 + 2 cos(theta)` come out right.
- A trailing brace restricts the sweep. Both the angle and the radius are in scope: `r = 1 + cos(theta) {theta < pi}`, `r = 1 + cos(theta) {0 < theta < pi}`, and `r = 3 {r > 0}`.
- `{...}` on a definition, slider or regression row is still rejected with an inline message, the same as before.

## Polar grid

- The **polar grid** checkbox in the graph controls draws rings at a round radius step and spokes every 30°, centred on the origin of the current window.
- It is independent of the cartesian grid, so both can be on at once, and it applies to every row type, not only polar ones.

## Errors

- An unsupported name reports inline: `r = 1 + cos(x)` says `Unknown name "x". Use theta, pi, e and the listed functions.` A malformed row (`r =`) reports that both sides need an expression.
- Nothing is silently blank: a row that draws no values says so.

No new dependency, no `eval`, no `Function` and no network request: polar rows reuse the existing restricted parser and sampler, and interpolation stays local.
