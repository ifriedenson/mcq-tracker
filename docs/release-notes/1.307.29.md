# 1.307.29 (Nov 19, 2026)

Tier-1 closes its last open item: `main.js` is under Obsidian Sync's 5 MB
per-file limit, down from 7.7 MB to about 4.3 MB.

**The embedded PDF++ subsystem is removed.** The unmodified upstream bundle,
its stylesheet, the host, the settings adapter and the lifecycle wiring were
the single biggest block in the bundle (over a megabyte), and no amount of
minification or lazy-loading shrinks a file Obsidian Sync measures whole.
The plugin's own PDF surfaces stay: the continuous reader, quote and ink
annotation, annotation sidecars and the sidebar, the searchable annotation
index and digest export, rectangle/selection deep links opened by **PDF: open
a copied deep link**, and the page/form editor on the vendored pdf-lib
(rotate, reorder, insert, duplicate, delete, merge, extract, split, live
forms, links, bookmarks, 20-step undo).

Saved `settings.pdfPlus` data from earlier versions is ignored on load;
nothing else in `data.json` is touched, and there is no migration to run.
`docs/pdf-plus.md` remains as a pointer so old links land somewhere true,
and the licence notice leaves `NOTICES.md` with the code it covered.

The same release finishes the minification pass the bundle now ships with:
`scripts/build.js` strips comments and whitespace after an ASI-safe newline
analysis and renames every module-scoped local (functions, parameters,
locals) to short names, with class names kept because the suite asserts
`constructor.name` on the date-picker and PDF editor modals. Pinned by
`tests/mangle.test.js`, which runs the original and the renamed code
side by side on eight behavioural cases. The startup budget still holds:
356 of 380 modules load eagerly inside the 360-module / 5.6 MB budget.
