# MCQ Tracker 1.210.6

Adds speech options to the local **Read aloud** module.

## What changed

- **Code blocks** chooses between skipping fenced code (the previous
  behaviour, still the default) and reading it as text. The fence markers and
  the language tag are never spoken.
- **Spell out acronyms** reads `NASA` as `N A S A` and `API` as `A P I`. Off by
  default.
- **Skip website URLs** drops bare `http(s)://` and `www.` addresses from the
  spoken text while keeping link labels such as `[the paper](https://…)`. Off
  by default.
- All three are in the Read aloud tab and in Settings, Modules, Read aloud. The
  speech plan, its sentence list and the time estimate all follow them.

## Boundaries

- Reading still uses the device speech-synthesis voice. There is no speech
  provider, API key, voice catalog, MP3 export or upload, and no dependency was
  added.
- Existing saved settings load with the pre-1.210.6 output, so nothing changes
  until an option is switched.
