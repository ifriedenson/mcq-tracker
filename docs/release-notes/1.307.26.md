# 1.307.26 (Nov 19, 2026)

A live-drive patch: the four 1.307.25 surfaces were each driven in a real
Obsidian 1.15.1 window (Xvfb, disposable vault, CDP) and three defects the
headless suite could not see are fixed, with the evidence kept in
`artifacts/ui-quality/runs/1.307.25-live/` (`run.json` plus week raster, dots,
courses, chip-picker and agent-history screenshots).

**Inline chip Clear was a silent no-op.** `applyChipEdit` ignored an empty
`due` value, so the date picker's Clear button closed the modal and changed
nothing. An empty (or null) due now removes the `📅 YYYY-MM-DD` token and
collapses the leftover space; clearing a line with no token changes nothing.
Driven live: the chip opened the picker, Clear removed the token from
`Tasks.md` with a "Due date cleared." notice. Pinned by
`tests/task-chips.test.js`.

**Chip clicks could land on the wrong note line.** Reading-view decoration
strided every list from the section start, so prose between lists drifted each
chip's source line. Each list now re-anchors with its own `getSectionInfo`
line start and falls back to striding only when that is unavailable; decoration
still never breaks reading.

**Course dots missed multi-space names.** The hub looked dots up by a
lowercased name while `courseKeyOf` also collapses whitespace, so a course with
a double space showed no dots. The lookup now collapses whitespace the same
way. Driven live: the empty Biology 101 dot created
`2026-11-19 - Biology 101.md` from the class-note template, and the hub then
showed Biology held and Chemistry empty.

**Agent undo returned two shapes.** The journal-fallback path returned
`{restored, skipped, paths}` while the direct path omitted `skipped`. Both
return `skipped` now (0 on the direct path). Driven live: the history modal
listed the applied review, its Undo restored the note, and
`undoLastAgentEdit()` returned `{restored: 1, skipped: 0, paths}` with the
note restored.

The week export needed no fix: `Calendar: export the current week as a PNG
image` wrote a 123,497-byte raster (grid, both seeded classes, now-line) in
the live window. The 13 gated rows in plan.md §3.9.6 stay gated. Tests:
**3,095 pass, 0 fail**; `npm run check` clean. No note format, setting key,
review schedule or network default changed.
