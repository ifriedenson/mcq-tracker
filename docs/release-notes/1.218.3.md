# MCQ Tracker 1.218.3

Fixes flattening: `flattenForm` baked each field's appearance into the page and
removed the fields, but left every widget annotation in the page's `/Annots`
with no `/Parent`. A flattened copy therefore still carried annotations pointing
at nothing — objects a viewer can draw a second time over the baked text, and
dead weight in every flattened export.

## What changed

`flattenForm` in `src/pdf-editor.js` collects the form's widget references before
it flattens, then removes exactly those entries from each page's `/Annots`. Links
and any other annotations are untouched, and a form with no widgets skips the
cleanup.

## Verification

`tests/pdf-editor.test.js` adds "flattening a form leaves no orphan widget
annotations on the pages": after a successful flatten the field list is empty,
the page's annotation array is empty both in memory and after a save and reload.

**1,687 tests pass / 0 fail**, `npm run check` is clean, `main.js` is rebuilt and
`git diff --check` is clean.
