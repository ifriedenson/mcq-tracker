# MCQ Tracker 1.221.0

The study-agent chat now does the things a heavy chat plugin is expected to do,
using only the plugin's own MIT code: it retrieves a passage instead of one line,
lets you copy, regenerate, retry and save, and keeps the Direct API conversation
across a reload. No dependency, provider, key or network request was added.

## Answers grounded in a passage, not a line

Local retrieval used to keep the single best matching line in each note, so a
long lecture could only ever contribute one sentence. `src/agent-retrieval.js`
now splits a note into passages: a heading starts one, a blank line ends one, and
a passage is capped at six lines and 700 characters. Ranking prefers **term
coverage** over raw repetition, then an exact phrase, then a heading or path
match, and common words such as "the" or "and" are ignored. Each note can supply
up to two passages, and the scan stays bounded at 400 notes and 200,000
characters each.

The agent receives the passage itself, quoted under a citation with its line
range - `[[Biology/Cells.md#L12]] (lines 12-17)` - instead of a single line. The
same passage still appears in the local results list, where clicking it opens the
note.

## Chat controls

- **Copy** appears on every assistant reply.
- **Regenerate** asks the last question again and replaces the previous answer
  instead of adding a second user turn to the Direct API history.
- A failed request now shows **Retry**, which re-sends the same question without
  retyping it; **Stop** still stops waiting for a Direct API reply and ignores the
  late answer.
- **Enter** sends, **Shift+Enter** inserts a new line. Ctrl/Cmd+Enter still sends.
- **Save chat** writes the whole transcript to
  `Study agent chats/Study agent chat YYYY-MM-DD HHMM.md`, with a numeric suffix
  instead of overwriting an existing note. Per-reply **Insert into active note**
  is unchanged.

## Continuity

The Direct API transcript is stored in `settings.ai.studyChat` through
`src/chat-history.js`: roles are normalised to user/assistant, empty turns are
dropped, and the newest 40 messages survive at 8,000 characters each. Reopening
the Study agent restores the conversation; **New chat** clears it. OpenCode
sessions still live on the local OpenCode server.

## Tests

- `tests/agent-retrieval.test.js` covers passages, line numbers, stopwords,

- `tests/chat-history.test.js` covers role normalisation, the 40-message and

- `tests/agent-view.test.js` adds copy, Enter/Shift+Enter, regenerate without a
