# MCQ Tracker 1.197.0

Summation and product notation in graph expressions.

## What changed

- Rows accept `sum(expression, variable, start, end)` and
  `prod(expression, variable, start, end)`, for example
  `sum(n^2, n, 1, 10)` = 385 and `prod(k, k, 1, 5)` = 120. A sum whose term uses
  the plot variable, such as `sum(x^k, k, 1, 3)`, draws as a normal curve. The
  notation goes through the existing parser, canvas scene, PNG export and print
  sheet; there is no second renderer.
- Bounds must be whole numbers, the start must be at most the end, and an
  expression may use at most 10,000 steps. The loop variable must be a single
  name that is not reserved, must appear in the term and must not appear in the
  bounds. Every rejection has a human-readable message, is announced in the
  polite live region, and is not saved, so the last valid expression stays in the
  settings.
- The notation parser, validation and bounded evaluation live in the standalone
  `src/graph-summation.js` module; only the existing expression parser and the
  graph view are wired to it.

## Verification

- `npm test` passes: **1,467 tests, 0 failures**.
- `npm run check` passes: no dynamic code in 243 files, and `main.js` matches
  `src/`.
- Focused coverage: sum/product evaluation and single-step ranges, non-integer
  bounds, reversed bounds, the 10,000-step cap, non-finite terms, argument
  splitting, missing arguments and parentheses, unused and reserved loop
  variables, bounds that mention the loop variable, rewrite preservation,
  expression-level `compileExpression` calls, view-driven sum and product
  results, a function-valued sum, the paint-level canvas change, announcement
  messages, and no persistence of broken expressions.

## Licence

No dependency was added and no third-party code was copied. `mathjs` was the
plan's grammar reference only; the notation parsing, validation and evaluation
are written locally.

Known limitations: the graph tab has not had a live Obsidian hand pass, and no
real screen reader was available to hear the announcements.
