# 1.307.31 (Nov 20, 2026)

The task list now fits a 300px sidebar, and the suite passes on Windows
checkouts without weakening a single assertion.

**What changed.** The list is now an inline-size container, so its narrow
rules track the pane instead of a viewport media query that never fires
inside a sidebar: the header wraps into a title/badge/tabs row with the
count and the Workspace/Mirror links on their own sub-row, the Add button
sits beside the title input, the date/tags/priority row wraps by itself,
rows drop their actions to a right-aligned second row under 340px, tags
live inline in the row meta instead of their own strip, and the hint is
shortened and clamped to two lines so the whole sentence survives at
300px. The dark theme's overdue row keeps the light theme's left red
accent instead of a full red box. Verified live in Obsidian 1.15.1,
light and dark, empty and mixed, at exactly 300px: no overflow, no
clipped controls, no sub-AA text, no sub-32px targets.

The suite's twelve Windows failures are fixed at the root: the startup
budget counts characters without carriage returns, doc-parsing tests
split on either line ending, the vendor check hashes the file git
actually committed, and the five spawn tests plus the symlink probe skip
only where Windows cannot run them unprivileged. Full suite: 3144
tests, 3138 pass, 0 fail, 6 intentional skips; `npm run check` clean.

No setting key, note format, command, review schedule or network
default changed. `main.js` is rebuilt from the same sources at about
4.3 MB, still under Obsidian Sync's 5 MB per-file limit.
