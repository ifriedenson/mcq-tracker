# 1.301.8 — No more silence cutoff on the agent

## What changed
- **Quiet work is never cut off.** The OpenCode agent watchdog no longer
  stops a file for going quiet. A slow model on a long illustrated PDF keeps
  working until it finishes, you stop it (Stop, Undo everything, Discard this
  file), or a 20-minute absolute backstop ends the file.
- **The remaining backstops.** An unreadable server still fails fast with
  `Lost contact with OpenCode`. The 20-minute cap names what the agent was
  last seen doing and the file-edit permission fix, same as before.

## Why
A real import was stopped at `nothing new for 181s` on a dense PDF that was
simply keeping the model thinking silently: the file had too few pages for
1.301.7's page-scaled patience to matter, and no model produces visible
progress on a fixed schedule. Silence is not evidence of a stall, so it no
longer ends a file.

## A note on permissions
You do not need to change OpenCode permissions by hand for the server this
plugin starts: since 1.301.6 it starts with file edits allowed. That only
takes effect when the server (re)starts, so after updating, fully quit and
reopen Obsidian once before importing. A server you run yourself keeps its
own `opencode.json` permissions; there, `permission: { "edit": "allow" }`
(or `"*": "allow"`) is the setting that unblocks note writes.

## Verification
- `tests/import-complete-details.test.js`: a quiet agent is proven to run
  past any silence and stop only at the absolute backstop, with the last-work
  and permission hints intact.
- No note format, setting key, review schedule or network default changed.
