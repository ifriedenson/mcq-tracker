# MCQ Tracker 1.168.0

This release adds a complete local study-review workspace.

## Review

- Docked whole-note review bar with exact next-interval previews, 1–4/0–5 grading, skip, postpone, undo and lapse checkpoints.
- Same-session requeue of missed notes with a configurable limit.
- Selectable grade layout (one row, stacked, or auto by pane width) and a resizable bar.
- Optional local session report notes with counts, button mix and linked items.

## Retention and statistics

- Two-day durable recall tracking.
- Permanent per-day counters that survive restarts and history trimming.
- Study statistics dashboard with maturity retention, memory-now, distributions and medians, weekday rhythm, day detail, leeches, button mix split by maturity, per-deck summaries and a clickable heatmap.

## Planning and focus

- Pomodoro timer with work, short-break and long-break phases, auto-start, ribbon, status-bar clock and commands.
- Review calendar with a seven-day workload estimate.
- Local calendar events with categories, colour tabs and daily/weekly/monthly/yearly recurrence.
