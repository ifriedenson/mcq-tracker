# MCQ Tracker 1.233.0

This release adds the full local **WordNet offline dictionary** the owner chose
after the installed-plugin review. It imports the four standard WordNet data
files from the user's own copy, builds an in-memory index and searches every
sense from the Vocabulary tab. No lexical data is bundled or downloaded, and no
dependency, provider, account or network request was added.

## Offline WordNet lookup

`src/wordnet.js` is a pure parser and index:

- `parseWordNetLine` reads the standard `data.noun`, `data.verb`, `data.adj` and
  `data.adv` synset format: decimal offset, part of speech, hexadecimal word
  count, synonyms, pointer count, pointer quadruples and the gloss after `|`.
  License/header lines are rejected, and adjective satellites share the
  adjective bucket.
- `buildWordNetIndex` stores each synset once by `pos:offset`; every word maps to
  lightweight sense refs, so synonyms do not duplicate the gloss. A second pass
  resolves semantic pointers into labelled relations (hypernym, hyponym,
  antonym, meronym/holonym and the related types). The parser is bounded by
  file and total character limits.
- `lookupWord` returns every sense of an exact word with its part of speech,
  gloss, synonyms and relations. When no exact entry exists it returns prefix
  suggestions; `searchWords` provides the same ranking for the UI.

### Import and reload

The Vocabulary tab gains an opt-in **WordNet offline dictionary** card. Turning
on the module in Settings exposes it; **Import WordNet files** accepts all four
files, checks them, refuses a partial set or an existing target without
overwriting, then writes them to the configured vault folder (`WordNet` by
default) and makes the lookup available. **Load from folder** rebuilds the index
from files already in the vault, which is what happens after an Obsidian
restart. The parsed index lives in plugin memory and is not bloat in `data.json`.

The lookup is read-only: it never edits a note or changes a vocabulary word,
card, question, streak or schedule. Importing writes only the four data files
the user selected. The plugin does not distribute or download WordNet; the data
remains subject to the WordNet License.

Full usage and limits are in [docs/wordnet.md](../wordnet.md).

## Honest limits

The importer supports the four standard WordNet data files, not the optional
WordNet index or morphological files. It does not stem or lemmatize, so an
inflected form needs its own entry or a matching prefix. Parsing a full database
uses memory and may take a moment on a phone; it happens only on import or an
explicit load. The data is not bundled, so the feature is empty until the user
imports it.

No plugin source, styles or data were copied for this release. No provider,
account, telemetry, dependency or network request was added.
