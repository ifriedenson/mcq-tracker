# 1.295.0 — Clearer feedback, tutoring and events

The feedback link now opens the MCQ Tracker feedback form, the Cards deck page
can open AnkiWeb's shared-deck search, local events carry a location, and the
Study agent gains an **Objective coach** tutor role.

## What changed

- **Feedback** defaults to the Tally form. An install that still carries the old
  built-in GitHub issue URL is migrated once on load; a URL you set yourself is
  left alone.
- **Cards → Find a deck on AnkiWeb** (and the matching command) opens AnkiWeb's
  shared-deck search in your browser. Nothing is sent from Obsidian: download
  the `.apkg` there and import it with the existing Anki import.
- **Local events** gain an optional **Location** field (up to 300 characters),
  shown beside the time and category in the day, week and timeline lists. The
  existing notes field is now labelled **Description**.
- **Study agent → Objective coach** joins the tutor roles. It charts a note into
  atomic learning objectives, teaches one at a time through explain, recall and
  apply, keeps recall and transfer separate, and resumes at the objective that
  needs the most work.
