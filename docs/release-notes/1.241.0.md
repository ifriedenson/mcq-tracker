# 1.241.0 — Web browser (opt-in)

Released Nov 4, 2026.

## What ships

A **Web browser** view that embeds pages inside Obsidian and sits beside the study tools:

- **Tabs**, including a private tab whose visits are never written to history; a tab strip with a close button per tab.
- **Address and search bar.** A full `http(s)` URL, a bare host such as `example.com`, `localhost:8080` or a search phrase. Searches go to DuckDuckGo, Google, Bing or Wikipedia (DuckDuckGo by default).
- **Per-tab navigation:** back, forward, reload and home, with the forward entries dropped when you navigate away from a past page.
- **Bookmarks** with a one-click star and a bookmark bar.
- **History** panel with a clear action, capped at 300 visits; **200** bookmarks are kept.
- **Zoom** from 50% to 250% in steps of 10.
- **Open in browser** for a page that refuses to load in a frame.

The view is **off by default**. Turn it on in **Settings → Global → Modules → Web browser**, then run **Web browser: open** from the command palette or the module's **Open Web browser** button.

## Safety and privacy

- Only `http` and `https` addresses open. `javascript:`, `data:`, `file:`, `obsidian:` and every other scheme are refused before a frame is created.
- Each page is a sandboxed frame with `referrerpolicy="no-referrer"`. The plugin never proxies a request, injects a script, reads a page's content or sends a page to a provider.
- Bookmarks and history are stored locally in `data.json` and bounded; a private tab adds nothing.
- No engine, extension, account, download manager, sync, dependency or network request was added. This is not a Gecko/Firefox runtime embedded in Obsidian.

## Limits (honest scope)

"All of Firefox" is not reachable inside an Obsidian plugin: there is no bundled browser engine, no extension API, no download manager, no tab sync and no cross-origin page access. This release provides the browsing surface that the platform allows — tabs, address/search, back/forward, bookmarks, history, zoom and sandboxed frames. Find-in-page, reader mode, downloads, extensions, private-window-wide isolation and per-site permissions are **not** implemented. Many major sites (Google, GitHub, banks) refuse to be embedded; for those the view offers **Open in browser**.
