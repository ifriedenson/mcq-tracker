# MCQ Tracker 1.185.0

Per-row styling in the Reference **Graph** tab.

## What is new

- **Line width** for any row that strokes a curve: explicit expressions, regression fits, implicit relations, inequality boundaries, polar curves and parametric curves. The range is 1 to 8 pixels and the default is 2, which is what every row used before this release.
- **Dashed** for those same rows, using a 6-pixel dash and a 4-pixel gap. Strict inequality boundaries were already dashed, and they stay dashed whether or not the box is ticked; ticking it dashes the other stroked rows.
- **Fill opacity** on a parametric row written with `fill`, from 0 (invisible) to 1 (solid) in 0.05 steps. The default is 0.16, matching the previous fixed fill.
- **Point size** on point and point-list rows, from 2 to 12 pixels; the default radius is 4.5, matching the previous markers. Open markers also use the line width for their ring.

## Where the controls appear

- Controls are shown only on rows where they apply. A definition or a slider row gets none, a point row gets only a point size, and a filled parametric row gets width, dashed and fill opacity. The controls sit under each row beside its existing error and fit lines.
- Each one is a labelled number input or checkbox with an accessible name such as `Line width for expression 1`, so they are focusable and work from the keyboard. Nothing is bound globally, and the canvas keyboard panning and zooming from 1.183.0 is unchanged.

## Defaults and persistence

- A row with no stored style resolves to width 2, no dashes, fill opacity 0.16 and point size 4.5 — exactly the values the canvas used before this release. A test compares an unstyled row's output against those explicit defaults.
- Styles are saved with the row list in `settings.reference.graph.rows`, beside the stored window, lock and display options, and restore exactly when the view reopens. The graph rows themselves are now saved too, so a reopened view keeps its expressions, hide state and styles.

## Rendering only

- Styling never reaches the sampler. Samples, points of interest, roots, extrema, intersections, markers and the cursor trace are identical with default styles and with every style changed; a test compares all of those across maximum width and point size, dashes on, fill opacity 0 and 1.
- Widths and point sizes are in canvas pixels, so they stay visually sane at both zoom extremes instead of scaling with the window. Each painter clears its dash pattern after drawing, so a dashed row cannot leak its pattern onto the next row.

## Still limited

- The cursor trace and hit-testing cover explicit and fitted rows only; polar, parametric, implicit, point and inequality rows draw with their styles but give no readout.
- None of these style controls has been exercised by hand in a live Obsidian vault, and neither has the graph canvas generally.
