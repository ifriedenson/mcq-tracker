# MCQ Tracker 1.209.2

Follow-up patch for the 1.209.1 release review. It closes the progress
dashboard's course-registry scope item and removes the remaining CSS
compatibility warnings.

## What changed

- The Insights Progress and Today mastery pickers now include names from the
  calendar course registry even when no question note has a `course` value.
  Names, codes and aliases resolve to one registry subject; choosing a
  registry subject with no notes shows an honest empty state and keeps the
  picker available.
- Existing question-course scopes behave exactly as before when no registry is
  configured. The progress snapshot key includes the registry so a renamed or
  added course refreshes the dashboard.
- The SAT callout keeps its two-column passage layout with sibling selectors
  instead of `:has`; a small post-processor mirrors the checked first-line
  marked state. Remaining `text-decoration` and `column-gap` declarations were
  replaced with compatible forms.
- The optional OpenCode desktop installer is unchanged.
