# 1.298.0 — Community review fixes

This patch clears the two actionable findings from the Community Plugins
review. It changes metadata and one decorative stylesheet rule only; no plugin
feature, setting, note schema or network path changed.

## What changed

- **Manifest description fixed.** The plugin description no longer contains the
  word "Obsidian". The community directory rejects that word in a description
  as redundant, and this was the review's only blocking failure.
- **Stylesheet warning cleared.** The small red marker on a flagged exam
  question used `clip-path`, which the review reports as only partially
  supported by Obsidian 1.7.4. It is now a supported rounded marker in the
  same top-right position.
- **Regression guard.** The release-hygiene suite now fails if the manifest
  description mentions Obsidian or the stylesheet uses `clip-path` again.
- **No behaviour change.** Practice, imports, the AI connection wizard, review,
  cards, calendar, assignments and every note format are untouched.

## Remaining review warnings

These are intentional and unchanged:

- `main.js` is larger than 5 MB because the plugin bundles the optional
  OpenCode installer and the unmodified MIT-licensed PDF++ bundle. Users on the
  Obsidian Sync Standard plan cannot sync a file that large.
- Direct filesystem access, shell execution and Electron IPC come from that
  optional desktop installer and the vendored PDF++ bundle. They are not used
  on mobile and are documented in `docs/security-inventory.md`.
- Vault enumeration, clipboard access and dynamic code execution are the same
  previously reviewed surfaces.
