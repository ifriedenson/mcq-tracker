# 1.307.4 — Polished for Primary, calm in the dark

## Why
The whole plugin was opened in Obsidian 1.15.1 running the Primary theme and
driven end to end — 242 commands, 20 views, 61 settings pages, practice through
a real session — with the CDP audit harness measuring every surface in Primary
light and dark at 1280 and 390px. Functionally nothing was broken (zero
failures, zero console errors), but the harness caught one overflow and several
contrast misses that only show under Primary. This release fixes exactly those,
pinned by tests, and changes nothing else.

## What changed
**Hub tabs (`src/hub-view.js`, `styles.css`)** — the Today/Plan/Study tab bar
was built off-token (`--radius-m`, `--font-ui-small`, 2px gaps) with a hidden
horizontal scroller under 520px and ~28px tall targets. It now uses
`--qt-radius-md/sm`, `--qt-type-sm`, `--qt-space-1`, always wraps, holds a
32px desktop minimum and the 44pt touch target on phones and coarse pointers,
and carries `type="button"` with Left/Right arrow-key travel between tabs.

**Theme fallbacks (`styles.css`)** — `--qt-danger-soft` and `--qt-success-soft`
read `var(--color-red-rgb)` / `var(--color-green-rgb)` with no fallback, so a
theme without those channels renders the soft surfaces transparent. They now
fall back to Apple system red/green, matching the existing orange fallback.

**Narrow exam surfaces (`styles.css`)** — the Bluebook header is a
`1fr auto 1fr` grid whose ~330px tool row burst out of 390px panes (18 escaping
elements; Reference/More unreachable, Back pushed off-screen), and the
`.qt-exam-foot` grid did the same. Under 520px the header becomes a wrapping
flex row, tools go icon-only (every tool already carries its `aria-label`, so
no accessible name is lost), and the footer wraps too. Phones keep the native
mobile practice path untouched.

**Dim-muted dark ink (`styles.css`)** — Primary dark keeps a dark-brown accent
and a dim secondary ink on a near-black ground: accent links measured 1.33:1,
choice-mark letters, More-actions, hints and counts 4.06:1. In dark only, those
resting states borrow `--text-normal`, and `--qt-link` resolves through a
55%-toward-white accent mix, which stays in the accent family on every theme.
