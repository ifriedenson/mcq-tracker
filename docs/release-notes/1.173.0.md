# MCQ Tracker 1.173.0

Regression comes to the Reference **Graph** tab, so a set of measured points can be fitted and plotted without leaving Obsidian.

- A data table under the expression list holds x and y values. Add and remove points as you go; a half-typed pair is skipped, and a bad cell reports its own message without breaking the rest of the graph.
- Any row with `~` is a regression. `y ~ m x + b`, `y ~ a e^(b x)` and Desmos' table form `y_1 ~ a x_1 + b` all work, and every name that is not `x`, a constant or a function becomes a fitted parameter.
- Fitting runs locally with a Levenberg-Marquardt least-squares solver. The fitted coefficients and R² are shown under the row, the curve is drawn in the row colour, and the data points are drawn over it.
- Fitted values stay in the row while you edit, so the graph does not jump between equally good fits.
- Clear inline errors cover missing data, too few points, an unknown function or a model that cannot produce a number.

The graph still uses the restricted local parser: no `eval`, no `Function`, no new dependency, no network request and no Desmos code or key.

This release also records the full Desmos parity roadmap, with permissively licensed reference sources for each capability and a release number for every feature, in `plan.md` §3.11.
