# MCQ Tracker 1.211.0

This release adds **Distraction-free practice mode** on phones and tablets and
tightens **Adaptive mastery** so practice moves to a similar question instead of
repeating the exact item a learner just missed.

## Distraction-free practice

- A new **Distraction-free practice mode** setting is on by default. While the
  active practice leaf is showing a question or result, Obsidian's top view
  header and bottom mobile navigation bar are hidden.
- The chrome stays hidden through answer submission, the next question, the
  Passage/Question tabs and timer pause/resume.
- Both bars return when the session reaches the idle screen, the view closes,
  the active leaf changes, the plugin unloads or reloads, or the setting is
  turned off. A stale class is cleared on the next plugin load.
- Multiple practice leaves use the active leaf, so closing an inactive practice
  view does not disturb the active session. Desktop is unchanged, and the CSS
  is scoped to `body.is-mobile`. The practice content adds top safe-area
  padding; the existing answer and review bars keep their bottom inset.
- No dependency, network request, note write or scheduler change was added.

## Adaptive mastery

- Weak areas are still ranked from the learner's whole history and the
  properties stored on question notes. The replacement question now needs at
  least two properties shared with the most recent question in the weak area,
  rather than only the weak property itself. If the pool has no such match, a
  same-area question is used instead of ending practice.
- An exact question whose last result was a miss or partial score below 60 is
  held out until its weak area reaches 75% effective accuracy with at least five
  attempts. When every remaining item is still held back, the least recently
  attempted item is used as a last resort so a small pool does not become an
  empty session.
- The selector remains local and read-only. The FSRS due-review path is
  unchanged.
