# MCQ Tracker 1.192.0

Multi-column graph data tables.

## What changed

- The graph data table now has named columns instead of only x and y. Add,
  rename or remove columns (2–8), and give any column an expression such as
  `2 * time` so its cells are computed from the other columns by name.
- Computed columns are evaluated locally by a small recursive-descent parser
  over the other columns, with constants and the usual functions. There is no
  `eval`, no `Function`, no dependency and no network request.
- Regression rows can consume any named column pair. The **regression x** and
  **regression y** selectors choose which columns feed the fit, and the sampled
  curve and data points follow that pair.
- The screen-reader summary announces the column count, every column name,
  which columns are computed and the selected regression pair. Each new control
  is labelled, and computed cells are shown read-only.
- CSV export writes every named column; typed cells are exported exactly as
  typed, and computed cells as their resolved values.
- Tables and the selected regression pair persist in
  `settings.reference.graph`. Older saved tables (the x/y `data` shape) load
  unchanged, and older row lists are unaffected.

- Focused coverage: column normalisation and uniqueness, computed expressions,

interaction is a behaviour reference only; the implementation is local.
