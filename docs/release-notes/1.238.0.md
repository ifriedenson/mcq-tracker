# MCQ Tracker 1.238.0

Released Nov 4, 2026.

## Advanced Tables: stable body-row sorting

The rendered-table toolbar now has twenty actions: the existing eight row/column structure controls, eight formatting and alignment controls, **↑**/**↓** sorting, **Σ** formulas and **CSV** export.

Focus a cell in the column you want to sort, then press **↑** for ascending or **↓** for descending. Sorting targets that column, keeps the header in row 0 and moves only the body rows.

- Numeric-looking cells compare by value, including signed, decimal and comma-grouped forms. Other cells compare as text, case-insensitively.
- In a mixed column, numbers come before text ascending and text before numbers descending.
- Blank cells stay at the end in both directions.
- Equal values keep their original source order, so repeated sorts do not shuffle ties.
- A header-only table, an all-blank selected column, a missing column or an invalid direction is refused with a message and no note change. Pressing a sort button without a focused cell also refuses.

Both directions commit an in-progress cell edit first and then use the same `updateTableBlock` live-editor/`vault.modify` queue as every other table change. The serialized write preserves padded columns, alignment and CRLF. TBLFM comments immediately after the table stay attached; sorting does not recalculate them, so press **Σ** afterwards if the formulas should run on the new order. Merged cells remain rejected.

Sorting changes only body order. It does not promote a data row to the header, merge cells, sort columns, change formulas or add a second editor/write path.
