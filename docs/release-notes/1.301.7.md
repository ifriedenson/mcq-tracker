# 1.301.7 — Long imports get proportional patience

## What changed
- **The agent watchdog scales with the document.** Patience is now
  30 s + 4 s per page, capped at 10 minutes, instead of a flat 3 minutes for
  every file. A short file keeps the old allowance; a 100-page illustrated
  PDF gets over 7 minutes of quiet thinking time before it is stopped.
- The timeout message still reports how long the agent was quiet, what it was
  last seen doing, and the file-permission / Direct AI next steps from 1.301.5.

## Why
A long AP World History PDF stalled the OpenCode agent with `nothing new for
182s`: the model was still working through a large illustrated document when
the flat 3-minute allowance cut it off. Together with 1.301.6 (edits are
always allowed for the managed server), both watchdog stall shapes are
addressed: the agent may write, and a slow agent on a long file may take the
time.

## Verification
- New scaling test in `tests/import-complete-details.test.js`: a tiny file
  keeps the default, a 100-page file scales linearly, the cap holds at
  10 minutes, and an explicitly configured base is respected.
- No note format, setting key, review schedule or network default changed.
