# MCQ Tracker 1.176.0

This release polishes the sidebar **Task list** and adds **tags**. No data migration or settings reset is required: tasks saved before this version simply have no tags.

## Tags on tasks

- Add tags when you create a task (the **#tags** field) or later from any row's **+ tag** control. Commas and spaces both separate tags, a leading `#` is optional, and **Enter** saves while **Escape** cancels.
- Tags are cleaned up for you: at most four per task, 24 characters each, no hash or spaces, and duplicates that differ only in case are dropped.
- Every tag renders as a chip under the task title. Click a chip to filter the list to that tag, click it again or press **Clear** to show everything.

## A better-looking task list

- The header pairs the title with an open/total pill, the **Workspace** link and a counts line for open, overdue and due-today work.
- The add form is a card, with the date and tag fields on their own row beside **Add**.
- Tasks are cards: a red left edge for overdue work, an accent edge for work due today, dimmed and struck-through rows once completed, and course, due and exam-plan details as small pills.
- Delete is still one click on the row's **×** button.

## Verification

The expanded `tests/task-list.test.js` covers tag sanitising, the four-tag cap, adding tags, inline tag editing and filtering alongside the existing view, placement, command and ribbon cases. The full suite passes (1,395 tests), `npm run check` verifies the generated bundle, and the release workflow publishes the three assets. No note format, scheduler or gradebook change was made.

## Upgrade

Install **1.176.0** with BRAT, the community directory when it updates, or by copying the three release assets into `<your vault>/.obsidian/plugins/mcq-tracker/`. Reload Obsidian, then open the task list from the ribbon or **Open the task list**.
