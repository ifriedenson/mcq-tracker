# 1.301.1 — Import a batch from the import window, and practice the result

1.301.0 added multi-file imports and a desktop popout. This patch closes the
gaps between that setup and a complete run: choosing files from the popout,
adding another PDF while the first is importing, keeping the main-window
progress alive after the import window is closed, and making the completion
summary's **Practice these questions** button open the folder the import
actually filled, proven against the real Practice view.

## What changed

### Choosing files from the import window

- The source picker is created when the button is clicked, in the button's own
  document, attached before it is clicked and marked `multiple`. The operating
  system's multi-select dialog therefore opens from the popout instead of from a
  detached input in the main window.
- The two source routes keep explicit labels: **Files from this device** and
  **or a file already in your vault**.

### Adding files during an import

- **Add more files...** on the running screen and on the review screen queues
  another PDF without restarting the import. A single-file import is promoted to
  a batch with the running file first.
- The live notice keeps the true totals: it moves from `Importing 1 of 2` to
  `Importing 2 of 2` as the added file starts, and the review and skip stages are
  reported for the same queue.

### Progress that does not depend on the import window

- Closing the popout detaches only the view. The notice stays in the main
  window's notice area and keeps advancing; running the import command again
  reattaches the same panel, queue, review choices and progress.
- Refocusing the main window does not close the import window, cancel the
  session or hide the notice. The registered `active-leaf-change` and
  `layout-change` handlers leave the import session untouched.

### Completion and Practice

- The larger summary reports the true file and question-note counts and lists
  each file.
- **Practice these questions** calls `practiceFolder(parent, made)`. The
  behavioral test drives the real `PracticeView` through the real `activateView`
  path, asserts Practice is limited to the imported parent folder (`Questions`)
  and that the question actually opened is one of the notes the import just
  wrote, under `Questions/Unit A` or `Questions/Unit B`.

## Verification

- `tests/import-batch-window.test.js` now has 15 tests. The focused run passes
  all 15, including:
  - one PDF imported from the popout, a second added while the first is still
    importing, the live notice reporting `Importing 1 of 2` and then
    `Importing 2 of 2`, the completion popup reporting 2 files and 2 question
    notes, and the real Practice button opening one of the imported notes;
  - a popout batch surviving `active-leaf-change` and `layout-change`, with the
    same session, view, modal and visible notice, and the queue still advancing
    to the added file afterwards;
  - closing the import window (during review and during an in-flight AI request)
    leaving the notice visible and letting the batch finish and summarize.
- Full `node --test`: **2,647 tests, 2,647 pass, 0 fail, 0 skipped**.
- `npm run check` is clean across **360 source files**; `main.js` is
  **7,171,742 bytes** from **363 modules**.
- The native operating-system file dialog is not exercised in the headless test
  environment: the chooser seam is stubbed, while the real button, the JS
  `File` path and the import notification path are driven. It needs one desktop
  click on this attached release.

## On-device check

1. On desktop, with AI ready, run **Import questions from a file** and select at
   least two PDFs. Confirm a separate 780×900 import window opens.
2. Start the import, then use **Add more files...** to add another PDF. Confirm
   the notice reports `Importing 1 of 3` through `Importing 3 of 3`.
3. Click back into the main window and close the import popout. Confirm the
   notice stays visible and keeps advancing. Run the import command again and
   confirm the same panel, queue and review return.
4. Finish the batch. Confirm the summary lists the true file and note counts,
   then click **Practice these questions** and confirm Practice opens on the
   imported parent folder with the imported questions available.
5. Confirm the native picker itself opens from the popout and allows selecting
   several files in one action.

No note format, review schedule, setting key, dependency, provider or default
network path changed. The popout remains desktop-only; mobile keeps the modal.
