# 1.245.0 — Remove PDF links

Released Nov 4, 2026.

## What changed

- **Remove one link.** `removeLinks` deletes the link at a 1-based number in `readLinks`, so the
  numbering the **Links** summary shows is the numbering you type. The annotation is taken off its
  page's `/Annots` from the highest slot down, so the remaining annotations keep their order.
- **Remove every link.** `all: true` deletes every link annotation in the file and reports each page
  it changed. With more than 500 links it refuses instead of doing an unbounded sweep, so a very
  large file is cleaned one link at a time.
- **Only the link goes.** Page content, form widgets, highlights, notes and every other annotation
  kind are untouched, and a page that carried no link is not rewritten.
- **The editor row.** **Add content → Links** gains **Remove** (a link number), **Remove link** and
  **Remove all links**. Each action is one undo step, and only **Save a copy** writes, so the
  original PDF and its sidecar stay untouched.
- **Refusals, each with a message and no change:** a file with no links, a number below 1 or above
  the link count, and a whole-file removal on a PDF with more than 500 links.

## Verification

- Two new real-byte tests. Removing link 1 of 2 by number leaves the page-2 link and its page jump
  intact after a save and reload, and leaves the page content unchanged. Removing all links reports
  both changed pages, saves with no links left, and a second removal refuses as empty. Link number 0
  and a number past the end are refused before any write.
- 59 focused PDF-editor tests pass. Full suite **1889 pass**, `npm run check` clean across
  **297 source files**, `main.js` current across **298 modules** at **4,931,977 bytes**, and
  `git diff --check` clean.

## Limits

- Links are removed, not edited: changing an address or an area means removing that link and adding
  a new one with the same **Add link** row.
- Removal is by the summary's numbering, which follows page order; a file re-read after an edit is
  renumbered, so read the summary again before removing another link.
