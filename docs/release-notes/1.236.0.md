# MCQ Tracker 1.236.0

Released Nov 4, 2026.

## Advanced Tables: cell formatting and column alignment

The rendered-table toolbar now has sixteen actions: the existing eight row and column structure controls plus eight formatting and alignment controls.

- **B**, **I**, **Code** and **S** toggle bold, italic, inline code and strikethrough on the selected cell's Markdown source.
- **L**, **C**, **R** and **Def** set the selected column to left, center, right or default alignment by rewriting its delimiter cell.
- Toggling the same format twice restores the original source text. Formatting the whole cell keeps the cell's escaped pipes intact.
- Formatting an empty cell, a cell with unmatched emphasis markers, a missing column or an invalid alignment is refused with a clear message; the note is not changed.

The toolbar commits an in-progress cell edit before applying a format or alignment. `updateTableFormat` and `updateTableAlignment` share `updateTableBlock` with cell edits and structural actions, so every change uses the live Markdown editor when available or `vault.modify` otherwise, stays behind the same serialized queue, and preserves padded columns, a valid delimiter row, escaped pipes and original CRLF line endings. There is no second editor or parallel write path.

Alignment applies to the selected column, and formatting applies to the selected cell as a whole. Typing into a cell still replaces that cell's inline formatting with plain text; use source mode to style only part of a cell.
