# 1.307.35 (Nov 24, 2026)

The 1.307.34 verification run could only happen after building `whisper-cli` by
hand, because Linux and macOS have no pinned asset in the registry — the
installer said "build it from source" and nothing in the repository said how.
This release ships the recipe, and the script that runs it.

**The page.** `docs/whisper-build-linux.md` is short enough to follow once and
complete enough to repeat: the prerequisites (`git`, CMake, a C++ compiler),
the one command, the same commands typed by hand, where the binary lands, and
what is *not* added to the bundle. It records that the pinned tag comes from the
registry rather than from memory, and points at the verified run in
`docs/whisper-plan.md`.

**The script.** `tools/whisper-build/build-linux.mjs` is the recipe as one
command. It reads the tag from `src/whisper-registry.js`, so the build cannot
drift from the release the installer describes; it refuses a target folder
inside the repository; it clones that tag with `--depth 1`, configures a
`Release` build and builds only the `whisper-cli` target; a second run reuses
the checkout and the binary (`--rebuild` forces a fresh one). `--tag`, `--dir`,
`--jobs` and `--dry-run` are there for scratch folders, small machines and
looking before building. It ends by printing the absolute binary path, the
setting to paste it into (`audioTranscription.binaryPath`), and the tagged
`samples/jfk.wav` that can be transcribed immediately.

**The run.** It was run here on Linux against the pinned tag: the clone, the
configure and the `whisper-cli` build completed, leaving a
998,248-byte `build/bin/whisper-cli` whose `--help` exits 0 and prints its
usage. A second invocation reported the existing build instead of compiling
again, and `git status` in the checkout showed no build artefact — the source
tree, the build folder and the binary all live in the scratch directory.

**Nothing is added to the bundle.** `main.js` is built from `src/` alone, so
this tool and its page change no shipped behaviour: no setting key, note format,
command, model, hash, network default or download rule changed, and the module
count stays at 390. The only source change is the bundled What's New entry;
**Audio: remove local transcription files** still deletes only the plugin's
managed model files and receipt, never a build you made yourself.

**Records.** The README's local-transcription page, `docs/whisper-plan.md` and
`docs/whisper-smoke-test.md` point at the recipe, and the owner sheet's prep now
starts with the Linux/macOS build. Tests: **3,190 pass, 0 fail**;
`npm run check` clean; `main.js` rebuilt at 4,396,010 bytes from 390 modules;
inventory unchanged (474 groups, 3,341 exports, 255 commands).
