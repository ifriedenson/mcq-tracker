# MCQ Tracker 1.175.0

Inequalities come to the Reference **Graph** tab, with the shading Desmos shows for `<`, `>`, `<=`, `>=`, `≤` and `≥`.

- A row such as `y < 2x + 1` or `x^2 + y^2 <= 9` shades the region that satisfies it. Circle and curve regions work the same way because the boundary is traced from the relation rather than solved for `y`.
- Strict comparisons (`<`, `>`) draw a dashed boundary; `<=`, `>=`, `≤` and `≥` draw a solid one.
- Regions are sampled locally on the same window as the rest of the graph, so they follow the x and y range fields and the parameter sliders.
- A row that shades nothing in the current window says so inline instead of failing silently, and one bad row still leaves the other rows plotted.

No new dependency, no `eval`, no `Function` and no network request: the region grid and boundary tracing are written in this repository.
