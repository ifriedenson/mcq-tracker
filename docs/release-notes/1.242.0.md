# 1.242.0 — PDF links

Released Nov 4, 2026.

## What changed

- **Add a link to a page.** The PDF editor's **Add content** panel gains a **Links** row: a link
  annotation over a chosen area of one page or every page, either an `http`/`https` address or a
  jump to another page of the same file. It is a real `/Link` annotation with a zero-width border,
  so nothing is drawn into the page and the page content stays exactly as it was.
- **Read the links back.** `readLinks` lists every link with its page, target, address and visible
  area. The area comes back in the same top-left percentages the editor uses, and it is exact on
  rotated pages because the rectangle is mapped through the page's own `/Rotate`. The row shows a
  read-only summary such as `2 links: p1 → https://example.com, p2 → page 3`.
- **Refusals, each with a message and no change:** an empty address, an address over 2,000
  characters, any scheme other than `http`/`https` (`javascript:`, `data:`, `file:` and
  `obsidian:` are refused before an annotation exists), a page that is not in the file, an area
  with a missing number, a zero or under-0.2% side, an area that leaves the page, and a page index
  outside the file.
- Each link is one undo step in the existing history, appears in the copy being edited, and is
  only written by **Save a copy**. The original PDF and its `.annotations.md` sidecar are never
  changed, and no dependency, network request or new setting was added.
- Limits: 500 links read per document and 2,000 characters per address.

## Verification

- `tests/pdf-editor.test.js` covers a URL link written and read back after a real save, a
  two-page internal jump read back as `[[2, "page", 3], [3, "page", 3]]`, a rotated page whose
  visible area round-trips exactly, every refusal, and a refused link leaving the document with no
  links. A content-stream check proves a link draws no text into the page.
- 50 focused PDF-editor tests pass. Full suite **1,880 pass**, `npm run check` clean across
  **297 source files**, `main.js` current across **298 modules** at **4,911,827 bytes**, and
  `git diff --check` clean.

## Limits

- Links cannot be edited or deleted yet: the editor adds them and reports what is there.
- Internal jumps always use `/Fit`, so they show the whole target page rather than a zoom or a
  position.
- No JavaScript actions, no links from a selection in the reader, and no outline/bookmark entries
  yet. A document's own outline is still left untouched.
