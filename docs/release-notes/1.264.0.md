# 1.264.0

## Advanced Tables parity audited against upstream

The parity claim is now audited against the upstream repository at commit
`1a222399690f1d014d4bc95bf9ccf162ee5d7c75` (tag 0.23.2), with
`@tgrosinger/md-advanced-tables@3.11.0`, rather than against our own table.
Every command, setting, behaviour and user-facing string in that source is
listed in `docs/installed-plugin-parity.md` beside the upstream symbol it
derives from, the code here that implements it, and the test that drives it.
Items that stay unreproduced are explicit owner decisions with reasons.

### Behaviours brought in line with upstream

- **Sorting** (`lib/table-editor.js` `sortRows`): the numeric-versus-text
  decision is made once per column, text cells have `[*~_$]` stripped and
  compare case-sensitively, blanks sort first, and a descending sort reverses
  the ascending body, so ties flip and blanks trail. Previously each cell was
  classified on its own, text compared case-insensitively, and descending
  flipped the comparator.
- **Tab CSV export** (`lib/table-editor.js` `exportCSV`): the tab form is now
  upstream's raw `row.join('\t')`, with no quoting and no injection prefix.
  Comma output keeps RFC quoting and the spreading guard because it is our own
  extension.
- **`-tx-` guard** (`src/obsidian-text-editor.ts` `acceptsTableEdit`): a table
  whose immediately preceding line is `-tx-` is no longer edited; commands do
  not see it, and formatting every table skips it without writing.
- **Insert row from the header** (`lib/table-editor.js` `insertRow`): inserting
  above with the cursor in the header now lands below the header as the first
  body row, instead of becoming the new header.
- **Formulas on the TBLFM line** (`cursorIsInTableFormula`): evaluate-formulas
  now runs with the cursor on the attached formula line, where there is no cell.

### Tests

`tests/advanced-tables-upstream.test.js` reproduces each upstream behaviour
above, including the exact notice strings, and
`tests/advanced-tables-parity.test.js` re-reads the audit table and fails if a
row, an upstream symbol, an implementing function or a cited test disappears.
