# 1.307.16 — The calendar fits the sidebar

Released November 16, 2026. Obsidian 1.15.1.

## Why

The calendar's narrow layout used viewport media queries (`max-width: 520px`), but a right sidebar is a
container: a 300px sidebar in a 1280px window still reports a 1280px viewport. At that width the month title
disappeared, the six header controls ran 24px past the card (clipping the settings gear), and the whole view
scrolled 36px sideways.

## What changed

- **The calendar measures itself.** `.uni-calendar-container` is now an inline-size container, and
  `@container uni-calendar (max-width: 360px)` applies the narrow header rules from the calendar's own
  width, wherever it is mounted.
- **The header stacks cleanly.** The month title keeps a line of its own; the six controls share the next
  line at 44px height and about 32px width, so the settings gear ends inside the card.
- **Chips and rows tighten.** Layer chips use `3px 8px` padding and keep a 32px target; merged-row meta
  truncates at 45%; the month grid keeps seven 32px cells with no horizontal scroll.
- **Wide layouts are unchanged.** The container query only applies below 360px, so the full calendar and
  the 390px phone view keep their existing rules.

## Evidence

- Live at a 300px sidebar: `clientWidth` and `scrollWidth` both 288px, gear right edge 983px against the
  card's 989px edge, month title rendered above the controls, five layer chips on two rows.
- `tests/calendar.test.js` pins the `container: uni-calendar / inline-size` declaration, the 360px
  container query and the full-width header controls.
- `node --test`: **3,006 pass, 0 fail**. `npm run check`: clean.

Screenshot: `artifacts/ui-quality/runs/sidebar-calendar/sidebar-calendar-300.png`.
