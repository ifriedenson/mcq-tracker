# 1.256.1 — The record states the limits the test checks

Released Nov 4, 2026.

1.256.0 made the PDF editor record self-checking and described the engine's numbers in
its release notes, `plan.md` and `AGENTS.md`. Those lines said the record's limits equal
the code's constants, but the record itself only stated a few of them (2,000 pages, the
20-step/96 MB history, the dash lengths and the phase), so the sentence claimed more than
the document carried. This patch closes that gap instead of softening the sentence.

## What changed

- `docs/pdf-editor-mission.md` — a **Limits** paragraph now states every number the
  engine enforces: 80 MB and 2,000 pages on open; 500 pages added from another file at
  once; 500 links and 500 form fields, 60-character field names with 50 choices; 200
  bookmarks with 120-character titles at three levels; remote targets from page 1 to
  100,000; 1–8 dash lengths of at most 100 with a phase from 0 to 1,000; 100 split parts;
  and 20 undo steps within a 96 MB budget.
- `tests/pdf-editor-record.test.js` — the limits test now reads that sentence back
  alongside the constants, so a number edited in the record without a matching code
  change (or the reverse) fails the suite. The release list and the notes range now end
  at 1.256.1.
- `tests/study-status.test.js` — the two `plugin.filtered()` calls in the set/restore test
  now pass the fixed `today` the rest of the file already uses. The seven-day snooze they
  set from 2026-10-29 expired on Nov 5, so against the wall clock the test went red on a
  date with no code change behind it; the queue assertion is the same, only its day is
  fixed. This is a test repair, not a behaviour change.
- `docs/pdf-editor-mission.md`, `plan.md`, `AGENTS.md` — the 1.256.1 release is recorded
  and the notes range is extended.

## Verification

- `node --test tests/pdf-editor-record.test.js` → **5 pass / 0 fail**.
- Full suite **1932 pass / 0 fail**, no `not ok`; `npm run check` clean across **297
  source files**; `node scripts/build.js --check` reports `main.js` up to date across
  **298 modules** at **4,976,540 bytes** (unchanged, since no engine code changed);
  `git diff --check` clean.

## Limits

- No behaviour changed. The five refused gates are unchanged: XFA forms, encrypted
  files, rewording existing page text, unverified link targets, and the editor-owned
  dash-phase encoding, plus hierarchical field names and bookmark-view guessing.
