# 1.239.0 — Time-block subject colours

Released **Nov 4, 2026**. Optional **Time blocks** module; off by default.

## What changed

- A **Subject colours** disclosure in the Time blocks tab lists every course a block names,
  with its block count and planned minutes, a colour picker and **Clear**.
- A course colour tints that course's blocks in **Day** and **Week**. A block with no course
  colour keeps its project colour; a block with neither keeps the type colour.
- `normalizeSubjectColors` accepts only `#rrggbb`, keys courses case-insensitively, trims the
  name and keeps at most 40 entries. `subjectColorFor` resolves course → project → none, and
  `subjectColorRows` drives the picker list.
- The setting lives in `settings.timeBlocks.subjectColors`. It writes no note, reads no
  calendar and adds no dependency, network request or provider.

## Refusals

An unusable colour string clears the course colour instead of storing it, and an empty course
name is ignored. Nothing else in the planner changes.

## Verification

- `tests/time-blocks.test.js` covers bounded normalisation, the course/project precedence,
  the picker rows, the plugin setter (set, replace, clear, empty course) and the workspace
  render, including **Clear** leaving block tags alone.
- `main.js` is rebuilt from `src/`; the full suite and `npm run check` pass.
