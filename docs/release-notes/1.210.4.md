# MCQ Tracker 1.210.4

Adds copyable page deep links to the read-only **PDF annotations** index.

## What changed

- Each annotation row now offers **Copy page link**, which copies an
  Obsidian wikilink such as `[[Papers/biology.pdf#page=12]]` to the clipboard.
- **Open at page 12** opens the same PDF at that page instead of the first
  page.
- Only `.pdf` paths with a positive whole page number produce a link. A page
  below 1, a page above 100,000, a non-PDF path or an empty path returns an
  empty link, so the buttons are not shown at all.
- Characters that would break a wikilink (`|`, `#`, `[`, `]` and line breaks)
  are removed from the path before the link is built.

## Boundaries

- Building and copying a link reads nothing and writes nothing. The index is
  still read-only: no annotation is created, edited or deleted, and no PDF is
  opened until you press a button.
- No PDF renderer, no form engine and no rectangle or highlight coordinates
  are added; the plan's PDF++ row records that boundary.
