# 1.283.0 — A knowledge record for the concepts inside your notes

This release adds an opt-in knowledge record inspired by
[Grill](https://github.com/theadamdanielsson/grill) (MIT). The record is built
from note structure and the practice history MCQ Tracker already keeps; it does
not add a second scheduler and its UI is this plugin's own.

## What the record does

- **Concepts, not just notes.** Headings, bold terms, definition lines, display
  formulas and authored cards become stable concepts with source hashes. Generic
  headings, code, tables and link-only lines are skipped.
- **Coverage.** Each note shows known concepts, tested concepts and due concepts.
  Coverage uses the eight-concept target and 80% known band adapted from Grill,
  so a short note is not punished for having fewer headings.
- **Evidence from real practice.** A concept's counters, due date, last miss and
  error tags are projected from the questions whose `source_note` and
  `source_heading` point at it. `next_review` stays question-level.
- **Misconceptions.** Error tags are grouped across notes, with open misses
  ranked first and fixed ones kept visible.
- **A learner digest.** The Study agent can include a bounded (~3,000 character)
  digest of concept evidence, open misconceptions and due concepts. It is off by
  default.

## Where it lives

- **Insights → Concepts** adds a Knowledge record card above the existing
  concept-mastery list, using the existing `qt-ins-*` list and meter styles.
  Rebuild and Copy learner digest sit beside the totals.
- **Settings → AI → Knowledge record** turns the record on and rebuilds it.
  The separate **Study context → Knowledge record** toggle controls whether the
  digest may be sent to the Study agent.
- **Commands:** Open the knowledge record, Rebuild from notes, Copy learner digest.

The index is stored locally at `MCQ Tracker/knowledge-record.json`. It is
rebuildable, holds no study data that is not already in notes or question
history, and existing notes stay authoritative. After an attempt on a linked
question, only that source note's entry is rebuilt and saved on a short debounce.

## What was not copied

Grill's theme, home/chat/test-session UI, agentic chat loop, question-generation
formats, embedded PDF quizzes, knowledge graph, Excalidraw tests, TTS, semantic
embedding index, MCP servers, Grill Cloud and `grill-mcp` are not part of this
release. MCQ Tracker already has its own chat, test, card, PDF and generation
paths. This is a focused incorporation of Grill's record idea, not a claim of
line-for-line parity. See `plan.md` §5.27 and `NOTICES.md`.
