# MCQ Tracker 1.169.1

This is a directory-review patch. It removes the two behavior warnings and the two CSS warnings without changing your notes, cards or settings.

## No direct filesystem or shell access

- Removed the optional OpenCode auto-installer. The plugin no longer downloads, unpacks, starts, stops or updates OpenCode, and the shipped bundle no longer uses Node's `fs` or `child_process`.
- OpenCode chat and agent mode still work when you run OpenCode yourself: install it, run `opencode serve`, connect an AI provider in OpenCode, and enter the server URL under **Settings → MCQ Tracker → AI**.
- Existing OpenCode users now start the server manually. Provider keys are configured in OpenCode itself; the plugin keeps its server URL, optional username/password, model and agent settings.
- Direct API behavior is unchanged. Vault notes are still read and written only through Obsidian's vault API.

## CSS cleanup

- The phone layout keeps one `100vh` fallback rule and upgrades to `100dvh` in a separate rule, so the stylesheet no longer has a duplicate `height` declaration.
- The Pomodoro progress animation now takes its duration from a CSS custom property, so reduced-motion stops it with a normal `animation: none` instead of `!important`.

## Verification

**1,318 tests pass / 0 fail**; `npm run check` is clean; `main.js` is rebuilt from `src/`. A regression check confirms the bundle contains no `require("fs")`, `require("child_process")` or OpenCode installer, and the stylesheet contains no `!important` or duplicate phone-height declaration.

**Known gate:** the real Obsidian desktop, phone and light/dark visual pass is still manual.

## Upgrade note

Version **1.169.1** is the next patch after 1.169.0. OpenCode users should run `opencode serve` before using the OpenCode backend.
