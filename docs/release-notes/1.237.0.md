# MCQ Tracker 1.237.0

Released Nov 4, 2026.

## Advanced Tables: formulas and CSV export

The rendered-table toolbar now has eighteen actions: the existing eight row/column structure controls, eight formatting and alignment controls, **Σ** for formulas and **CSV** for export.

### Formulas

Formulas live in one or more HTML comments immediately after the table, using the org-mode-style `TBLFM` format that Advanced Tables documents:

```markdown
| Item | Grams |
| --- | --- |
| Whole Wheat Flour | 110 |
| Bread Flour | 748 |
| Warm Water | 691 |
| **Total** | |
<!-- TBLFM: @>$2=sum(@I..@-1) -->
```

Press **Σ** to recalculate the table. The pure evaluator in `src/table-formulas.js` supports:

- absolute row and column references (`@1`, `$2`), first and last (`@<`, `@>`, `$<`, `$>`), the first body row (`@I`), and relative references such as `@-1` and `$+2`;
- rectangular and single-axis ranges with `..`, including `@I..@-1`, `$2..$4` and `@2$2..@5$3`;
- `sum`, `mean`, `count`, `min`, `max`, arithmetic, comparisons, `if`, `round`, `abs`, `sqrt`, parentheses and the constants `pi`, `e` and `tau`;
- several formulas chained with `::` or written on consecutive comments, evaluated left to right;
- `;%.2f` and `;%d` result formatting.

A formula that is malformed, references a cell outside the table, uses a relative destination, has an unsupported function or format, or contains a formatting directive such as `;dt`/`;hm` is refused with a message and no write. Merged cells remain rejected. Formula comments are preserved, so **Σ** can run again after the data changes.

### CSV

Press **CSV** to copy the table's header and body to the clipboard. Commas, quotes and line breaks are quoted with doubled quotes, `\|` is restored to `|`, and a cell beginning with `=`, `+`, `@`, a tab or a carriage return gets a leading apostrophe so a spreadsheet cannot execute it as a formula. Export reads the table and never changes the note.

Both toolbar actions commit an in-progress cell edit first. Formula evaluation goes through the same `updateTableBlock` live-editor/`vault.modify` queue as cell edits and structural changes; CSV export is read-only.

Sorting and merged cells remain later parity slices.
