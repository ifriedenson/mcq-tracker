# 1.307.5 — Dim dark labels read clearly

## Why
1.307.4 fixed the first batch of Primary-dark contrast misses. Re-running the
same live audit on the released build surfaced three more of the plugin's own
secondary-text classes at 4.06:1 — quick-practice field labels, inline meta
lines, empty states and the paused-timer notice. This is the styles-only
follow-up, with a per-class pin so a new muted label cannot slip back.

## What changed
`styles.css` — the dark-only ink rule that already covered `.qt-hint` and
`.qt-count` now also covers `.qt-label`, `.qt-meta`, `.qt-empty` and
`.qt-paused`, all borrowing `--text-normal`. Light themes are untouched.

`tests/ui-tokens.test.js` — the dark-ink test asserts each class by name, so
removing one from the rule fails the suite.

## Evidence — Obsidian 1.15.1, Primary, released build
- Plugin reported `1.307.4` before this change and the fixed bundle after;
  `app.vault.config.cssTheme` = Primary, light and dark both measured.
- `tools/full-drive` on the released build: commands 242/242, views 20/20,
  settings 61/61, no failures (the only console line was the offline update
  check's 403).
- `tools/ui-audit`: hubs and practice 0 overflow, 0 contrast, 16 focus stops
  at 1280 light; plan hub and practice 0 overflow, 0 contrast at 1280 dark;
  Quick Practice's `Session length` label was the reported 4.06 and now
  passes, and the paused-timer line was the next 4.06 and now passes.
- Remaining single `touch` row is the 22px desktop resume icon button, which
  stays 22px by design (44px on coarse pointers) — recorded, not a regression.
