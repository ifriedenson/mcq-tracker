# 1.269.0 — PDF rectangle deep links open where the reader can see them

PDF++'s last recorded gap was rectangle/selection deep links: this plugin built
`[[file.pdf#page=3&rect=…]]` links but the reader ignored the rectangle, and
nothing opened such a link in the reader at all.

## What changed

- **The reader rings the selection.** `PdfInkModal` takes the link's `rect`,
  validates it as page fractions and draws the same dashed selection ring the
  annotation sidebar uses on that page. A rectangle off the page, a zero side or
  a non-number is dropped instead of guessed.
- **A rectangle link opens the reader.** `plugin.openPdfDeepLink(link)` parses the
  link, checks the PDF is in the vault, and opens the reader on its page with its
  annotation and rectangle. New command **PDF: open a copied deep link** reads the
  clipboard and calls it; a non-link or a missing PDF is refused with a notice and
  nothing opens.
- **Copied links carry the selection.** The quote path and **Copy page link** now
  pass the annotation's own areas through `unionRect`, so a multi-line selection
  produces one rectangle instead of one link per line, and `annotationLink` writes
  `rect=` whenever it has areas.

Everything stays local and pure: `src/pdf-deep-link.js` still has no Obsidian API,
no DOM and no write, and the reader only draws.

## Verification

- `tests/pdf-deep-link.test.js` (7 tests) covers the format/parse round trip, page
  links without a rectangle, every refusal (path, page, id, off-page rectangle,
  short rectangle, bad annotation), the union of a multi-line selection, the
  annotation link carrying its rectangle, `openPdfDeepLink` opening the reader and
  refusing a missing PDF or a non-link, and the reader keeping the validated rect.
- Full suite, `npm run check` and a rebuilt `main.js` are recorded in the release
  commit.

## Honest limits

- The link opens the plugin's own reader, not a third-party PDF viewer. A link
  clicked inside a note still opens the PDF file; run **PDF: open a copied deep
  link** to land on the selection.
- A rectangle is stored as four decimal fractions of the page, so a very small
  selection is rounded to six decimal places (about a millionth of the page).
