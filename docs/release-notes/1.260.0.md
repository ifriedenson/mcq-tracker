# MCQ Tracker 1.260.0

Released Nov 5, 2026.

## Advanced Tables reaches parity with the upstream plugin

The table editor began at 1.234.0 and grew a reading-view toolbar one increment at a time. That left the plugin's other half missing: everything the upstream **Advanced Tables** plugin exposes from the source editor, its docked panel, its settings and its CSV dialog. This release adds them.

**Twenty-six commands.** The command palette now has a `Tables:` group that acts on the table under the cursor in the normal Markdown editor: **go to the next cell**, **previous cell**, **next row**, **move the cursor out of the table**, **format the table under the cursor**, **format every table in this note**, **insert a row above** and **below**, **insert a column left** and **right**, **delete the row** and **the column**, **move the row up** and **down**, **move the column left** and **right**, **align the column left**, **center**, **right** and **clear its alignment**, **sort rows ascending** and **descending**, **transpose**, **evaluate formulas**, **export as CSV**, and **open the table controls panel**. Each one is check-gated on the cursor really being in a table, so it is absent from the palette otherwise. Every mutating action writes through the same serialized queue as the reading-view toolbar, with the same padding, alignment, escaping and `TBLFM` handling.

**Navigation without a keymap.** `nextCellTarget`, `previousCellTarget` and `nextRowTarget` map a line and character to the next cell using real character offsets, skipping the delimiter row, wrapping at the end of a row and, at the last cell, asking for one more row. `appendTableRow` adds that blank row, so a table can be extended entirely from the keyboard or the mobile toolbar. `escapeTableTarget` returns the line after the table and its `TBLFM` comments, and the command inserts a blank line when prose immediately follows the table. `rowCellSpans` reads the offsets of a row's cells without being fooled by `\|` escapes or code spans, and `cellAtLine` turns a cursor into a row and column.

**Formatting on demand.** `formatTableAt` re-renders one table with padded columns and a valid delimiter row and reports whether anything changed; `formatAllTables` does every table in a note from the bottom up, so earlier line numbers stay valid. With **Pad cell width using spaces** off, `renderTable(table, { pad: false })` writes minimal cells (`| A | Bee |`) with a delimiter row that still parses, matching the upstream WEAK format.

**Insert before, not only after.** The engine gains `row-insert-above` and `column-insert-left` beside the existing below/right actions. Inserting above row 0 installs a new blank header and pushes the old header into the body, so no text is lost; every insert keeps the table rectangular and refuses at the 500-row and 40-column limits.

**CSV with or without headers.** `tableCsvFromTable` (and `tableCsvAt`) take `{ header: false }`, and **Tables: export as CSV** opens `src/table-csv-modal.js`: the upstream **Include table headers** checkbox, a read-only preview and **Copy CSV**. The reading-view **CSV** button keeps its one-step copy with the header. Quoting and the spreadsheet formula guard are unchanged, and no path writes the note.

**Docked panel.** `src/table-controls-view.js` registers `question-tracker-table-controls`, a right-sidebar panel grouped **Align** / **Move** / **Edit** / **Sort and formulas** / **More**, with a status line naming the table under the cursor. Its buttons call the same `runTableAction` as the commands. A ribbon button and **Tables: open the table controls panel** open or reveal it.

**Settings on the tool page.** The **Advanced Tables** page already owned the module switch; it now also carries **Bind Tab to cell navigation**, **Bind Enter to row navigation**, **Pad cell width using spaces** and **Show the table controls button**. `normalizeTableEditorSettings` defaults all four to on and keeps `enabled` opt-in, so an existing `data.json` behaves exactly as before.

## Deliberate differences from upstream

Two differences are intentional and are recorded in `docs/installed-plugin-parity.md`. Formulas use the note's `TBLFM` comment syntax (`@`/`$` references, `sum`, `mean`, `count`, `min`, `max`, `if`, `round`, formatting) rather than the `md-advanced-tables` formula language. And Tab/Enter are intercepted in the rendered table, with the editor path provided by the navigation commands, instead of a CodeMirror keymap that would need a bundled CodeMirror dependency.

Merged cells remain out of scope in every release of this editor: finishing them still needs a decision between HTML tables, continuation markers and leaving them excluded.
