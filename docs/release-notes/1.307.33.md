# 1.307.33 (Nov 23, 2026)

Local transcription ships: record a voice memo or pick any audio file already
in the vault, run whisper.cpp on this computer, and get an editable transcript
note. The whole slice is off by default, desktop only, and uploads nothing.

**What changed.** Turning on **Local transcription (Whisper)** under
**Settings → Read aloud** adds one opt-in module. **Audio: set up local
transcription…** shows the pinned `ggml-org/whisper.cpp` `v1.8.6` asset, the
chosen model, both sizes and their SHA-256, and downloads nothing until the
owner confirms; the program and model land in the plugin's own data folder,
outside the vault, and a file that does not match its recorded hash is deleted
instead of run. A receipt records the tag, hashes and dates. **Audio:
transcribe a recording…** lists the audio files in the vault, and the voice
memo card gains **Transcribe the last recording**; both decode the recording
with the renderer's own decoder, downmix and resample it to the 16 kHz mono WAV
whisper.cpp requires, spawn `whisper-cli` once with a fixed argv and no shell,
show `mm:ss of mm:ss` progress with a Cancel button, and write the transcript.
**Audio: remove local transcription files** deletes the program, models and
receipt and leaves every recording and transcript alone.

**The note.** A transcript is `Recordings/Transcripts/<recording>.md` with
`type: transcript`, `audio`, `duration`, `language`, `transcribed_by:
whisper.cpp`, `model`, `transcribed_on`, and `course` when the recording sits in
a folder named after a course. The body opens with `## Transcript` and, with
timestamps on (the default), writes one `**[mm:ss]**` marker per spoken segment.
An existing transcript is never overwritten, and nothing is graded or sent to a
model.

**Pinned, not bundled.** The registry carries one Windows x64 asset
(`whisper-bin-x64.zip`, 4,093,849 bytes) and ten models from
`ggerganov/whisper.cpp`, each with its published SHA-256. `base.en-q5_1`
(57 MiB) is the default, with `tiny.en-q5_1`, `base.en-q8_0`, `base.en`,
`small.en-q5_1` and `small.en` beside it; an English-only file is swapped for
the multilingual file when the language is not `en` or is `auto`. macOS and
Linux have no official published build here, so those systems point at their
own `whisper-cli`; the installer says so instead of guessing. Mobile capture,
hosted transcription and pronunciation scoring stay out of scope.

**Six new settings keys.** `audioTranscription.enabled` (false),
`binaryPath`, `model`, `language`, `timestamps` (true) and `folder`; no
existing key changes. Three commands are added. `src/whisper-registry.js`,
`whisper-wav.js`, `whisper-run.js`, `whisper-note.js`, `whisper-install.js` and
`whisper-picker.js` are new, and only the registry is eager, so the startup gate
still holds. `NOTICES.md` gains the whisper.cpp MIT notice and
`docs/security-inventory.md` records the one new transport and the two new
files that reach Node's `fs` and `child_process` through lazy lookups.

Tests: **3,187 pass, 0 fail**; `npm run check` clean; `main.js` rebuilt at
4,390,412 bytes from 390 modules; inventory regenerated (474 groups, 3,337
exports, 255 commands). The real microphone, binary and model are the owner's
sheet in `docs/whisper-smoke-test.md`; they were not run here.
