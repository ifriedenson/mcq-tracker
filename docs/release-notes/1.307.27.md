# 1.307.27 (Nov 19, 2026)

The Quiz Generator was the one AI path that checked its work and then threw the
answer away. `generateQuizFromNotes` already ran `verifyDraftQuestions`, but the
drafts were written through `quickAddNote`, which builds frontmatter from a
fixed key list and never carried the verdict — so a draft the blind checker
answered differently, kept in **mark** mode, was written as a clean note with no
record that anything had disagreed. Import has always stamped that; generation
did not.

`quickAddNote` now stamps the check through the same helpers the importer uses
(`verificationFields`/`verificationBanner`): `verification`, `verified`,
`verified_by`, `verified_on`, `verified_answer`, `verification_method`, and
`needs_review: true` for a mismatch, error or review, plus the visible
`> [!warning] Answer check failed` banner directly under the frontmatter. The
draft's own key is kept, so a disputed question still shows what the generator
chose and what the checker chose.

The properties are written only when a draft arrives with a verification object,
so a block you paste into Quick add yourself writes exactly the note it wrote
before. Dropped drafts are still filtered before the write, as before.

The generator dialog no longer reports a silent outcome: the preview line names
how many independent checks ran, how many kept drafts disagreed and are marked
for review, and how many were dropped; the creation notice repeats the review
count. Tests: **3,097 pass, 0 fail**; `npm run check` clean. No note format,
setting key, review schedule or network default changed.
