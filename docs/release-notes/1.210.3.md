# MCQ Tracker 1.210.3

Adds an opt-in **Citations** module: a local BibTeX library that never leaves
the vault.

## What changed

- **Citations** is a new Study Workspace tab and its own switch under
  Settings, Global, Modules. It is off by default.
- **Import .bib** reads a BibTeX file already in the vault and stores the
  parsed entries in plugin data. Duplicate keys are skipped and reported; a
  malformed entry is skipped rather than guessed.
- Entries keep the citation key, type, title, authors, year, journal or
  book title, publisher, volume, issue, pages, DOI and URL. Authors are
  normalised from `Last, First` and `A and B` form, accents are kept and
  braces are dropped.
- Filter by author, title, journal or key. Each entry offers **Copy
  citation** in a plain-text form that includes a `https://doi.org/` link when
  a DOI exists.
- **Create note** writes a citation note with `type: citation` frontmatter, a
  formatted reference and a details table into the configured **Citation
  folder**. An existing file at that path is never overwritten, and **Open
  note** opens what was created.
- **Remove** deletes an entry from the local library only. Imported notes are
  not touched.

## Boundaries

- No reference-manager login, network request, Zotero database or CSL
  processor. Zotero-style sync stays out, as recorded in plan §5.24.
- Notes are written only when **Create note** is pressed; importing a `.bib`
  file changes no note.
