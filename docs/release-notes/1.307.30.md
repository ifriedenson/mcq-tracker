# 1.307.30 (Nov 19, 2026)

The plan-to-code review closes out the last PDF++ naming traces so "remove
PDF++" reads true everywhere, not just in the bundle.

**What changed.** The `pdf-plus` settings page id is gone from the
headless full-drive checklist (the page itself was removed in 1.307.29, so
the drive no longer looks for it). The remaining `PDF++` wording in source
comments now names the plugin's own surfaces: the backlink module, the deep
link parser and the provenance note say "PDF deep link", "PDF text
selection" and "PDF highlight colour" instead of the upstream brand. The
plan's reference tables (§3.6, §3.10, §5.13, the licence checklist and the
ingestion link list) mark the PDF++ row as removed in 1.307.29 with the
pointer at `docs/pdf-plus.md`; the shipped-behaviour row already said so
and is unchanged.

No behaviour changed: no setting key, note format, command, review
schedule or network default moved. `main.js` is rebuilt from 380 modules
at about 4.3 MB, still under Obsidian Sync's 5 MB per-file limit.
