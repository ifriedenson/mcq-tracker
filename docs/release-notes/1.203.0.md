# MCQ Tracker 1.203.0

Geometry transformations in the Reference Geometry tab.

## What changed

- The Geometry tab can transform any existing object with a translation,
  rotation about the origin, reflection across the x or y axis, or dilation
  about the origin.
- Transformations are dependent objects. They keep the source id and parameters
  and resolve whenever the drawing is painted, so a transformed segment, line,
  ray, circle or polygon follows changes to its source.
- Removing the source also removes the transformation. Invalid factors,
  unknown source ids and non-finite parameters report a readable error.
- The local model and painter remain in `src/geometry.js`; the tab methods stay
  in `src/geometry-panel.js`. No dependency, network request or eval was added.

## Verification

- `npm test` passes: **1,489 tests, 0 failures**.
- `npm run check` passes: no dynamic code and `main.js` matches `src/`.
- Focused coverage: translation, 90° rotation, x/y reflection, dilation,
  transformed segments, dependent removal, invalid parameters and the
  transformation UI path.

## Licence

No dependency was added and no third-party code was copied. The transformation
math is written locally.

Known limitations: rotations and dilations use the origin, and the tab has not
had a live Obsidian visual pass.
