# MCQ Tracker 1.210.5

Adds a read-only vault checklist index to the existing **Tasks** tab.

## What changed

- **Tasks** now ends with a **Vault checklist (read-only)** section. **Scan
  vault** lists every `- [ ]` and `- [x]` line in the Markdown notes, with the
  note path and the line number, so work written in any note is visible next to
  the local study tasks.
- Both `-`, `*` and `+` bullets and numbered `1. [ ]` items are recognised.
  Fenced code blocks are skipped, so an example inside a code block is not
  listed, and `#tags` on the line are shown with the row.
- **Vault filter** matches the line text, a tag or the note path.
- The scan is capped at 500 notes and 1,000 lines; the summary reports open,
  done and note counts and says when results were cut.

## Boundaries

- The index only reads with `cachedRead`. No note is edited, rewritten,
  reopened or moved, and the local study tasks are a separate list.
- No query language, no due-date parsing from another plugin's syntax and no
  checkboxes are toggled from this view: the row's only action is **Open note**.
