# MCQ Tracker 1.214.1

## Study agent reply rendering

This patch fixes a live-use failure in the right-sidebar **Study agent** added
in 1.214.0.

`ChatPanel` renders assistant Markdown through the owning view's `md` helper.
`AgentView` did not define one, so the first assistant reply would throw a
`TypeError` instead of appearing in the transcript. `AgentView.md` now delegates
to the plugin's existing `renderMarkdownInto` helper, the same renderer used by
Practice, Cards and the other Markdown views.

A new mounted-view test opens the real `AgentView`, renders an assistant reply
and confirms the **Insert into active note** action is present. The rest of the
1.214.0 behavior is unchanged.

## Verification

- Focused agent tests cover the mounted view, replies, insertion, retrieval,
