## A process note, recorded because it nearly produced a false claim

`/tmp` is shared with other chats on this VM. A first attempt at
`npm run check > /tmp/check.log` hit `Permission denied` on a log another chat
owned, and the `tail` that followed printed that chat's **stale 1.267.0** output
next to a non-zero exit code. The recorded run therefore used uniquely named log
files and read each gate's own exit code, never a pipe's. The numbers above come
from that second run; the first attempt is not evidence of anything and is not
relied on.
