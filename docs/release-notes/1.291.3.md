# 1.291.3 — Study agent suggestion deck verified in Obsidian

The suggestion deck now has evidence from a real, installed plugin rather than a
component harness. The 1.291.2 build (`main.js`, `manifest.json`, `styles.css`)
was copied into a throwaway vault and opened in Obsidian 1.15.0 under Xvfb at
2× device scale: a 296 px right sidebar and a 512 px main-area leaf, in light
and dark.

Captured states: first run with the seeded deck, a long suggestion title and
detail with a long draft, and the long state in the dark theme. The five
real-pane crops are committed in `docs/render/study-agent-ui/` as
`obsidian-empty-narrow-light.png`, `obsidian-long-narrow-light.png`,
`obsidian-long-narrow-dark.png`, `obsidian-empty-wide-light.png` and
`obsidian-long-wide-light.png`.

Measured from the live DOM:

- Empty copy: 238 × 70 px in the sidebar and 397 × 52 px in the leaf, with
  `scrollHeight` equal to `clientHeight` in both.
- Role and mode chips: **Private** at 68 px and **Tutor** at 44 px, fully
  visible.
- Long title: four unclamped lines (65 px) in the sidebar; the deck grows from
  116 to 162 px and the card from 104 to 150 px instead of clipping.
- Dots stay below the deck; the decorative back-card labels stay
  `visibility: hidden`.
- The controls row (404–434 px) clears the pinned composer (466 px+) at both
  widths.

No stylesheet, markup or bundle change was required. The production code is
identical to 1.291.2; this release records the real-window verification and the
committed captures. The drivers that produced them live in the gitignored
`artifacts/obsidian-test/` rig and are described in
`docs/render/study-agent-ui/README.md`.

Verification: `node --test` → **2,459 pass, 0 fail**; `npm run check` clean
across **344 source files**; `main.js` is **6,899,848 bytes** from **347
modules**. No schema, dependency, provider or network behaviour changed.
