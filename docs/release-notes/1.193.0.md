# MCQ Tracker 1.193.0

Print and paper output for the graph.

## What changed

- **Print graph** builds a paper-ready sheet from the graph tab: the drawn graph
  image, the window, every expression in list order, and the data table with all
  of its named columns. **Save print sheet** writes the same HTML document to
  `Exports` when the browser print window is unavailable (for example on mobile).
- The sheet reuses the existing canvas scene renderer, so the printed graph is
  the same scene as the screen and the PNG export. It is not redrawn by a second
  implementation.
- The sheet is self-contained and escaped: a black-on-white paper stylesheet with
  `@page` margins, print media rules, page-break control for the figure and
  tables, a caption for the graph, and the regression column pair when one is
  selected. Titles, bounds, expressions and table cells are HTML-escaped.
- The accessible summary announces the print sheet and what it contains; the new
  buttons and the polite print status line are labelled, so printing is not a
  visual-only action.
- No new setting was needed, and older saved graph settings load unchanged.

## Verification

- `npm test` passes: **1,459 tests, 0 failures**.
- `npm run check` passes: no dynamic code, and `main.js` matches `src/`.
- Focused coverage: escaping, the paper document, print styles, expression and
  table assembly, refusals for an empty graph, a missing image or a blank
  expression list, the summary wording, the labelled controls and live status,
  the offscreen scene reuse, the saved HTML path and content, the print fallback
  and the empty-graph Notice.

## Licence

No dependency was added and no third-party code was copied. The print layout and
stylesheet are written locally.

Known limitations: the graph tab has not had a live Obsidian hand pass, and no
real screen reader was available to hear the print announcement. The print
window path itself was exercised only through the saved-sheet fallback in tests.
