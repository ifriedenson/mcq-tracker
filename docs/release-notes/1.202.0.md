# MCQ Tracker 1.202.0

Dependent constructions in the local Geometry tab.

## What changed

- The Geometry form now creates midpoints, intersections, parallel and
  perpendicular lines, perpendicular bisectors, angle bisectors and the circle
  through three points, in addition to the primitives from 1.201.0.
- Constructions resolve from their source objects every time the drawing is
  painted, so moving a source point in the model updates the dependent point or
  line without storing a second copy.
- Intersections cover line/line, line/circle and circle/circle. Coincident or
  parallel inputs, tangent circles, collinear circumcircle points, a straight
  angle and missing sources report a readable error instead of throwing out of
  the tab.
- Removing a source object removes its dependants as well; stored constructions
  are restored with their source ids and parameters.

## Verification

- `npm test` passes: **1,487 tests, 0 failures**.
- `npm run check` passes: no dynamic code and `main.js` matches `src/`.
- Focused coverage: midpoint and intersection coordinates, parallel and
  perpendicular directions, perpendicular bisector placement, angle-bisector
  direction, circumcircle centre and radius, collinear refusal, dependent
  removal and the construction UI path.

## Licence

No dependency was added and no third-party code was copied. The construction
math is written locally.

Known limitations: intersections choose the first solution when two exist, the
viewport is still fixed at -10..10, and the tab has not had a live Obsidian
visual pass.
