# 1.281.0 — Mother cram: know it or loop it

## Two choices, every card

The Cards browse view now has a **Mother cram** button beside **Cram session**. It turns every card in the current deck and course into a loop, regardless of due date. Flip the card, then choose **Do not know** or **Know**; those are the only two rating buttons in this mode.

**Do not know** sends the card to the back of the queue, so it returns after the rest. **Know** removes it. The session ends when every card has been marked Know. The header shows `Known X / Y`, and the summary reports the known and Do not know totals with a **Mother cram again** button.

Keyboard: `1` = Do not know, `2` = Know.

## Practice only, on purpose

Mother cram writes no attempt, grade, review history, `next_review_at` or `next_review`. It does not change the card schedule or enter the offline outbox. The normal four-rating **Cram session** still uses its 3m / 5m / 10m / 1d intervals, and normal reviews keep the existing ladder, FSRS or SM-2 schedule.

Mother cram forces flip mode even for a card configured for typed or dictated answers. The typed/speech answer path and the AI grader remain available in the normal review flow; this mode deliberately does not use them.

### Limits

- **Session-only.** `Know` state is not saved; it ends with the session or when the view closes.
- **100-card cap.** The loop uses the existing queue cap and covers the first 100 cards in the current view.
- **No typed answer grading in this mode.** The two-choice loop is flip-only.
- The headless suite drives the UI through the fake DOM. The layout and a real Obsidian session have not been visually checked.
