# MCQ Tracker 1.183.0

An interactive viewport in the Reference **Graph** tab.

## Pan and zoom

- Drag anywhere on the canvas to pan. A drag moves the window; a pointer that does not move by more than three pixels is still a hover, so the trace readout keeps working.
- Scroll (or pinch on a trackpad) to zoom about the cursor position, not the canvas centre. The point under the pointer keeps its place while the window narrows or widens.
- The `+` and `−` buttons zoom about the current window centre. They are real buttons with accessible names, so they take focus and work from the keyboard.
- With the canvas focused, the arrow keys pan by a tenth of the window and `+`/`-` (or `=`) zoom. Nothing is bound globally, so typing in a row or elsewhere in the plugin is unaffected.

## One window for everything

- The viewport is a single object of numeric bounds owned by the graph view. The bounds fields, every row kind, the sampler that finds roots and extrema, the intersection search and the cursor trace all read that same object.
- That is why points of interest and the trace stay correct after a pan or zoom: they are recomputed against the drawn window rather than against a remembered one.

## Lock and reset

- **Lock view** pins the current window. While it is locked, dragging, scrolling, the zoom buttons, the arrow keys, the bounds fields and **Reset view** all leave the window alone and the readout says the viewport is locked.
- The lock and the window are saved with the graph settings and restored when the view reopens.
- **Reset view** auto-fits the window around everything the graph actually drew — samples, traced segments, markers, fill polygons and regions — with an 8% margin. On an empty graph it returns to the default -10..10 window.

## Default window

- Existing graphs keep their old behaviour: there is no stored window on first run, so the view opens at -10..10 exactly as before, and a stored window is honoured when present. Auto-fit happens only when **Reset view** is pressed; opening the view never silently rescales an expression you were reading.
- A stored window is clamped on load, so a hand-edited or corrupted setting falls back to the default instead of breaking the draw.

## Bounds

- The window span is bounded between 0.02 and 20,000 units on each axis. Zoom-in stops at the minimum so the sampler keeps enough resolution for roots and extrema, and zoom-out stops at the maximum so the canvas cannot drift into a meaningless scale. Both bounds are covered by tests.

No new dependency, no `eval`, no `Function` and no network request: the viewport arithmetic is local.
