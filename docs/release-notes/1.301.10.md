# 1.301.10 — Answers written in the Answer section count

## What changed
- **The Answer section is enough.** A note whose key is written only under
  `## Answer` (`**Correct Answer: C**`) is now an answered note. The import
  audit (`noteIssues`) and the vault scan (`cacheIssues`) read the key with
  `findAnswerKey`, the same reader practice uses, instead of looking only at the
  `answer` property.
- **The property is filled in.** `finalizeNote` promotes a section key into the
  `answer` property, so grading, checks and filters see it too.
- **Words and full choices work.** `Choice C`, `Option B`, the complete text of
  one of the choices, and `B.` / `(B)` / `B)` are all read as the letter.
- **Nothing is silently dropped.** An answer that is not a letter (for example a
  written sentence) is kept for self-grading instead of being cleared.
- **Free-response notes are not broken notes.** A question with no answer
  choices and a written model response (the two AP World a/b/c prompts) is
  self-graded, not listed as `No answer`. `No answer choices` is now added only
  when a letter key is left without its choices, so one note is one problem.

## Why
An AP World import created 27 correct notes, each with its key under
`## Answer`, and the summary reported all 27 as "have no answer, so you'll grade
those yourself", plus two "No answer choices" rows for its free-response
prompts. Nothing was wrong with the notes: the report was reading the wrong
place. Verification state was not the cause — an unverified AI answer is still
an answer.

## Verification
- `tests/import.test.js`: a section-only key becomes the `answer` property and
  is no longer reported; `Choice D`, a choice's full text and an unparseable
  answer each behave correctly; a free-response note with a model response
  reports no problems; a note with an empty Answer section still reports
  `No answer`.
- `tests/empty-state.test.js`: `cacheIssues` and `noteIssues` still agree, now
  under the new rule.
- Existing notes need no re-import: practice already read the section, and the
  report now matches it.
- No note format, setting key, review schedule or network default changed.
