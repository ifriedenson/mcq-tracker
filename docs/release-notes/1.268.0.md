# 1.268.0

## Time tracker parity in Time blocks

Time blocks now covers the document model and direct-manipulation workflow of a
full time tracker, so a separate time-tracking plugin is no longer needed.

This release republishes the Time blocks parity work first shipped in 1.267.0
under neutral naming. Plugin behaviour and the built bundle are unchanged; the
version, release notes and release metadata are updated.

### Direct manipulation

- **Day timeline.** Drag empty time to create a block, drag a block to move it,
  and drag its bottom edge to resize it. Mouse and touch share one 15-minute
  snap.
- **Four-state tasks.** Click cycles open → half-done → done, right-click
  cancels, and a 550 ms long-press cancels on touch.
- **Week drops.** Drag a block onto another day column to move it there, and
  drag a task onto a day to move it into that day's Unscheduled block.
- **Intensity.** Timeline shows a 14-day strip of planned minutes as levels 0–5.

### Projects, files and migration

- **Project and domain notes.** Markdown files under the configured folders carry
  project or domain tags, colour, course and a dated lifecycle history with
  intensity. Your body text is preserved on every write, and a previous time
  tracker's tags are accepted on import.
- **Status controls.** The Projects view records active, inactive and archived
  states with an optional 0–5 intensity for the selected day.
- **Write-back.** Routines.md and Backlog.md now write as well as import, with
  buttons in their views and three commands.
- **Settings import.** If you are moving from another time tracker, run the
  settings import command once to copy timeline hours, schedule heading,
  folders, file paths and routine/association switches into the local settings.
- **Guided tour.** A seven-step modal walks through the day, block, task,
  routine, backlog and Markdown basics, with **Open Day view** at the end.

### Rolled up from 1.265.0

1.265.0 was folded into this release, so upgrades from 1.264.0 also get the
document model:

- `## Schedule` parsing and writing, with task statuses, notes, associations and
  the `Unscheduled` block.
- Two-way sync of one day's Schedule section with its daily note.
- Carry-over of open and half-done tasks into today.
- `Routines.md` rules for daily, weekdays, weekends, day lists and monthly
  schedules, including routine tasks and regeneration.
- `Backlog.md` import, due-date resurfacing and write-back.
- Per-view commands for Day, Week, Grid, Backlog, Routines, Projects and
  Timeline.

### Remaining differences

Fit-days width, grid row lines and shading, follow-grid and
highlight-across-views remain cosmetic switches this planner does not offer. The
tour guides rather than detecting each gesture. Neither is a reason to keep a
separate time tracker.

### Verification

- **2,148 tests pass**; `npm run check` is clean.
- `main.js` is unchanged across **304 modules** at **5,145,606 bytes**.
- Pointer gestures are not unit-tested because the DOM test harness has no
  layout; their geometry and every plugin mutation are covered.

### Upgrading

Update the plugin. If you are moving from another time tracker, run the settings
import command once, then remove the old plugin. No new dependencies, accounts or
network access are required.
