# 1.293.2 — Practice can use the computer layout on a tablet

The Practice screen now has a **Mobile practice view** switch under **Practice
session** settings. An iPad reports itself as a mobile device, so its question
screen always used the phone tree even though the review and Settings already
used the desktop layout.

- **On (default)** — phones keep the mobile question and review screens; an iPad
  keeps the mobile question screen and the shared desktop review, exactly as in
  1.293.1.
- **Off** — an iPad or phone renders the desktop question and shared desktop
  review tree, so Practice can look like it does on a computer.
- **Desktop** — ignores the switch and always uses the computer layout.
- The preference is saved as `settings.mobilePracticeView`; changing it refreshes
  open Practice views immediately. It does not change the Settings navigation,
  notes, attempts, scheduling or distraction-free practice.

`src/practice-view.js`, `src/settings-tab.js`, `src/constants.js` and
`src/plugin.js` carry the change. `tests/mobile-practice.test.js`,
`tests/plugin.test.js` and `tests/settings-navigation.test.js` cover the iPad,
phone and desktop branches, the default and persisted off value, and the
rendered switch. The iPad branch is verified with Platform-driven tests; no
physical iPad was available for an in-app capture. No dependency, provider,
note schema, storage format or network path changed.
