# MCQ Tracker 1.210.13

Every Study Workspace tab is now driven by a test, and the audit's last
incomplete control is fixed.

## What changed

- **Seven tabs are mounted and exercised end to end:** Feynman, Recall, Topic
  planner, Courses, Annotations, Deep Notes and Quiz index. Each test fills the
  real form, presses the real button, asserts the persisted settings, reads the
  saved row, opens it, deletes it and checks the documented empty state.
- **Topic planner, Use exam topics:** pressing it when no exam matches used to
  set a message that nothing re-rendered, so the button looked dead. It now
  raises the view's existing `Notice`. The successful path announces the count
  it loaded, and the form keeps whatever was already typed because the refusal
  never rebuilds it.
- **The audit ledger** (`docs/study-workspace-audit.md`) now names, for every one
  of the 21 tools, the test that covers it and the release that introduced that
  test.

## Boundaries

- No new setting, dependency, provider or note write. The only product change is
  the missing feedback on one existing button.
- The tests use the existing fake vault and DOM helpers; `openLinkText` was added
  to that stub because the real Obsidian API has it and the annotation and quiz
  rows use it.
- §5.22.12 subject colours and event tags are untouched.

## Verification

Full suite and `npm run check` are clean; `main.js` is rebuilt from current
modules and the release assets are byte-identical to the committed files.
