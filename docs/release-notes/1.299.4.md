# 1.299.4 — Every field has a name

The accessible-name sweep is finished across the whole UI. Every input,
textarea, select and text-less button in `src/` now has a name that does not
depend on placeholder text.

## What changed

- **Card and deck surfaces.** The card editor (new deck, deck folder/course,
  course, front/back, expectations, part of speech, language), deck extraction
  (deck, course, seed), deck import (source, file or folder, fallback deck,
  course, duplicate handling, CSV mapping columns, header checkbox, save
  mapping, reviewed updates, export format) and image occlusion (deck, course,
  image path, prompt, masks) name their controls.
- **Practice and exams.** The exam builder names its section titles, question
  range, shuffle switch, pass score and written-response count; exam and FRQ
  answers, the FRQ photo picker, practice typed answers, notes, folder search
  and the adaptive-length switch are named too.
- **Study tooling.** Quick add, Quick Chat, the Quick Ask note toggle, study
  status search, lecture bulk add, reference element/formula/constant/codon
  searches, the SMILES field, the AP unit field and the WordNet file input
  carry names.
- **PDF and data surfaces.** The PDF editor's burn-annotations and flatten-form
  options, the table CSV header switch, the Anki target deck and inline quiz
  answers are named.
- **Buttons without text.** The practice explanation and AI toggles carry
  explicit names; every other text-less button was checked to receive visible
  child text or its own `aria-label`.
- **No behaviour change.** Labels are additive. No note format, review
  schedule, setting, data path, command or network request changed.

## Verification

`tests/helpers/a11y-audit.js` parses every `.createEl("input"|"textarea"|
"select")` and `.createEl("button")` call in `src/`, including multiline
options, and reports unnamed controls and text-less buttons.
`tests/a11y-labels.test.js` asserts both lists are empty, scans at least the
current source file count, and pins representative names so the audit cannot be
weakened silently.

The full suite passes **2,580 tests**, `npm run check` is clean across
**355 source files**, and `main.js` is current at **7,089,218 bytes** from
**358 modules**. Naming was proven statically and by the built bundle; no
Obsidian window or device was available, so nothing is claimed about visual or
screen-reader output.
