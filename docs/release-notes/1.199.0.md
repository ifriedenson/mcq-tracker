# MCQ Tracker 1.199.0

Complex arithmetic in the local Reference calculator.

## What changed

- The Calculator tab has an opt-in **complex** checkbox. With it on, the
  calculator accepts `i`, `pi`, `e`, `tau`, complex literals such as `2 + 3i`,
  implicit multiplication such as `2i` and `2(3+i)`, parentheses, powers,
  `sqrt`, `exp`, `ln`, `log`, `abs`, `arg`, `conj`, `re`, `im`, `sin`, `cos`,
  `tan`, `sinh`, `cosh` and `tanh`.
- Results are formatted as a real number, a pure imaginary number, or `a + bi`.
  Division by zero and non-finite results are reported instead of shown as a
  number.
- The parser lives in the pure `src/complex.js` module. It never calls `eval`,
  `Function` or the network, and it can compile an expression with a named
  variable for the upcoming complex graph mode.
- The choice is saved in Reference settings; older settings load with complex
  mode off, so ordinary calculator behaviour is unchanged.

## Verification

- `npm test` passes: **1,477 tests, 0 failures**.
- `npm run check` passes: no dynamic code and `main.js` matches `src/`.
- Focused coverage: arithmetic, division, conjugate, magnitude and argument,
  integer powers, square root, exponential, logarithm, formatting of real and
  imaginary results, implicit multiplication, named-variable compilation,
  invalid names and division by zero, the Calculator tab toggle, complex
  evaluation, ordinary real evaluation after toggling and persistence.

## Licence

No dependency was added and no third-party code was copied. The complex
arithmetic and parser are written locally.

Known limitations: the Calculator tab has not had a live Obsidian visual pass,
and general complex powers use the principal logarithm branch.
