# MCQ Tracker 1.209.1

Release-review patch for 1.209.0. Removes the optional JSXGraph presentation
adapter and its vendored runtime.

## What changed

- The Reference **Geometry** and **Vector field** tabs keep their local canvases,
  controls and persistence. The **Open JSXGraph board** action is removed.
- `src/jsxgraph-adapter.js`, `vendor/jsxgraph-core.js`, the board styles and the
  JSXGraph notice are removed.
- The 3D curve/LOD, PNG and print export, audio trace and vector-field features
  from 1.209.0 are unchanged.
- No note or settings migration is needed. Existing geometry and vector-field
  state loads in the local canvases.
- The OpenCode desktop installer path accepted in 1.205 is unchanged.

## Verification

- Full suite: **1,502 tests pass, 0 failures**.
- `npm run check`: no dynamic code in **254 source files**; `main.js` is current
  across **254 bundled modules**.
- The rebuilt bundle contains no JSXGraph runtime or adapter.
- `git diff --check` is clean.

The removed adapter was the new third-party runtime since 1.205 and added the
dynamic-code surface plus a false-positive ZIP/self-update signal. The local
Reference tools remain offline and dependency-free.
