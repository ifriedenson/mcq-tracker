# 1.301.13 — Three more checks by default, or two

## What changed
- **Three extra passes by default.** When the first independent answer check
  disagrees with a stored answer, three more blind checks now look the question
  over, so four passes vote in total. 1.301.12 ran two.
- **Two or three, in one control.** Settings → AI → Session pacing and checks →
  **Extra checks after a disagreement** is a dropdown: Off, Two more checks
  (three passes), Three more checks (four passes). Installs that saved the
  earlier on/off toggle are read as "three" unless they asked for two.
- **The majority rule is unchanged and now spans four votes.** The stored
  answer is verified only when most of the passes that answered agree with it,
  so 3 of 4 verifies and 2 of 4 does not. A panel that settles on one other
  answer flags the note and names that answer; a split keeps the first verdict
  and the note stays flagged.
- Extra requests still happen only for answers that already disagree; a clean
  match costs exactly one check.

The passes use the model chosen for **Check AI-written answers**, so choosing a
different model there makes them independent of the model that wrote the note.

## Why
The owner asked for disagreements to be looked over by two or three more AIs
rather than two, and to be able to pick between them. The setting now says
which, and the default takes the larger panel.

## Verification
- `tests/answer-verification.test.js`: with `verifyPanelSize` 2 the run makes
  three requests and verifies on 2 of 3; with the default of 3 it makes four
  requests, keeps a 2-of-4 split flagged, and verifies 3 of 4.
- `tests/ai-tools.test.js`: a single disagreeing reply now costs four checks in
  total before the note is written.
- No note format, setting key, review schedule or network default changed.
