# 1.301.9 — No time limit, and a one-press OpenCode check

## What changed
- **No time limit at all.** The 20-minute total-time cap is gone. A file now
  ends only when the agent finishes it, you press **Stop**, **Undo everything**
  or **Discard this file**, or OpenCode stops answering. A 100-page PDF is no
  longer at risk of being cut off however long it takes.
- **Check OpenCode, in one press.** A lost-contact failure shows a
  **Check OpenCode** button under the file list of the import summary. It
  restarts the plugin's own server when needed and answers in plain words:
  "OpenCode is running 1.19.5 and answering normally", "…but no AI provider is
  connected yet", or "it is not answering right now" with the next click.
- **Also a command.** **Check that OpenCode is running** in the command palette
  does the same at any time; when OpenCode is not running it offers to open
  AI settings.
- The lost-contact message no longer asks the user to know what a server is: it
  says the program that writes the notes stopped answering, that the files
  already imported are kept, and points at the button.

## Why
The user asked for the 20-minute cap to go, because long illustrated PDFs can
legitimately take longer, and asked for a check that someone without a strong
computer background can use. Both are now in the plugin itself rather than in
a log file or a terminal.

## Verification
- `tests/opencode-status.test.js`: healthy server, dead server and
  no-provider server each produce plain words with no error codes, and the
  summary shows the button only when a file lost contact.
- `tests/import-complete-details.test.js`: a quiet agent is polled all the way
  to its own finish with no cutoff, `agentMaxMs` no longer exists, and a
  lost-contact error names the Check OpenCode button.
- No note format, setting key, review schedule or network default changed.
