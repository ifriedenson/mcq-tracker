# 1.301.16 — Failure messages name what to do next

## What changed
- **Every remaining local failure path renders plain language.** Saving the
  simple-quiz result, the OpenCode setup and provider key, a schedule sync,
  card and practice reviews, imports and exports, restores, note inserts and
  table actions now report `Could not <operation>: <detail>. <What to check,
  then try again.>` instead of a bare runtime string such as
  `EACCES: permission denied, ...`.
- **One shared formatter.** `errorDetail` in `src/util.js` turns any thrown
  value (including non-`Error` throws, empty messages and object bodies) into
  readable text capped at 300 characters, so a notice can never render
  `undefined` or `[object Object]`.
- **A sweep guard keeps it that way.** `tests/notice-sweep.test.js` pins every
  fixed message and fails if any plugin notice ever interpolates a raw
  exception again; the only allow-listed raw notices sit on request paths
  (AI sends, calendar download, Text2Anki), whose upstream errors are already
  human-readable and which this pass deliberately does not touch.
- No note format, setting key, review schedule or network behaviour changed.

## Why
A failed save that shows only a runtime string leaves the user with no idea
what broke or what to do next; naming the operation and the next step fixes
that at the moment of failure.

## Verification
- New behavioural tests drive each reachable path to failure and assert the
  friendly message: `tests/settings-error-paths.test.js` (OpenCode setup,
  status check, provider key, schedule sync), `tests/simple-quiz.test.js`
  (result save), `tests/practice-keys.test.js` (review save),
  `tests/epub.test.js` (highlight, note, remove),
  `tests/error-message-paths.test.js` (service import, clipboard import,
  timed-test restore).
- Each fix was proven by reverting the messages, rebuilding, watching the new
  tests fail on the raw text, then restoring and watching them pass.
- `tests/notice-sweep.test.js` additionally pins the messages on paths the
  fake DOM cannot drive (modal forms) and fails on any reintroduced raw
  notice.
- No note format, other setting key, review schedule or network default changed.
