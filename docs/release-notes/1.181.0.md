# MCQ Tracker 1.181.0

The full function library in the Reference **Graph** tab.

## One-value functions

- Reciprocal trig: `sec`, `csc` and `cot`, with poles at the same places as their reciprocals.
- Hyperbolic: `sinh`, `cosh`, `tanh`, `csch`, `sech` and `coth`.
- Inverse hyperbolic: `asinh`, `acosh`, `atanh`, `acsch`, `asech` and `acoth` (the same `a` prefix the library already uses for `asin`/`acos`/`atan`; `arcsinh` and the other `arc` spellings are not accepted).
- Rounding and sign: `sign(x)` is -1, 0 or 1, and `round(x)` rounds to the nearest whole number with halves going away from zero (`round(2.5)` is 3 and `round(-2.5)` is -3).
- All of these keep the existing spellings for `sin`, `cos`, `tan`, `asin`, `acos`, `atan`, `sqrt`, `abs`, `ln`, `log`, `exp`, `floor` and `ceil`.

## Two-value functions

- `mod(a, b)` is the mathematical remainder with the sign of the divisor: `mod(7, 3)` is 1 and `mod(-1, 3)` is 2. `mod(a, 0)` has no value.
- `nthroot(x, n)` takes a whole root of 2 or more. An odd root accepts a negative radicand (`nthroot(-8, 3)` is -2) and an even root of a negative has no real value.
- `gcd(a, b)` and `lcm(a, b)` need whole numbers and use absolute values, so `gcd(-12, 18)` is 6; `lcm` of a zero pair is 0.
- `nCr(n, r)` and `nPr(n, r)` need whole numbers with `0 ≤ r ≤ n`: `nCr(5, 2)` is 10 and `nPr(5, 2)` is 20.
- A two-value function called with the wrong number of values reports that arity, e.g. `mod takes 2 values.`

## Constant

- `tau` is `2π`, alongside `pi` and `e`, so `sin(tau)` is 0 and `(pi, tau)` is a point.

## Domain gaps, not Infinity

- `sec`, `csc`, `cot` and `atanh` return no value at their poles instead of a huge finite number or Infinity, so the sampler leaves a gap and the canvas never draws an Infinity stroke. `acosh` below 1, `atanh` at or beyond ±1, `asech` outside `(0, 1]` and `acoth` inside `[-1, 1]` are gaps too.

## Errors

- Malformed literal input reports inline: `gcd(1.5, 2)` says `gcd needs whole numbers, like gcd(12, 18).`, `nCr(5, 6)` says `nCr needs whole numbers with 0 ≤ r ≤ n, like nCr(5, 2).`, `nthroot(8, 2.5)` says `nthroot needs a whole root of 2 or more, like nthroot(8, 3).`, and `sinh(1, 2)` says `sinh takes one value.`
- A non-literal invalid value, such as `gcd(x, 2)` at `x = 1.5`, yields no value, so the row reports that it has no real values in the window.
- Built-in names are reserved: a slider or definition called `tau`, `mod` or `sign` reports that the name is built in.

## Composition

- The new functions work in every shipped row kind: cartesian expressions, implicit relations, inequalities, restrictions and piecewise rows, slider parameters, polar rows, parametric curves and point coordinates. `a = 2` with `y = a sinh(x)`, `g(x) = nthroot(x, 3)`, `r = sec(theta)` and `(pi, tau)` all evaluate through the same sampler and canvas transform as before.

No new dependency, no `eval`, no `Function` and no network request: the functions are local implementations on `Math`.
