# MCQ Tracker 1.212.0

## PDF and Markdown card extraction

Use **Cards: extract cards from a PDF or Markdown file**. The importer reads a
vault PDF or `.md` file and extracts cards from Q/A labels, definition lines,
Markdown tables, `::` separators, headings and cloze marks.

- Local extraction is the default and sends nothing.
- Scanned PDFs with no text layer point to the existing OCR flow.
- The optional AI fallback runs only when local extraction finds no cards.
- Nothing is written until the preview is accepted.
