# MCQ Tracker 1.169.0

This release ships the full close-out of the core-values review. It connects data that already lived on your device, adds the missing safeguards around AI-generated practice, and makes Insights a single dashboard. Existing notes, cards and settings remain readable; every new field is optional.

## One Insights dashboard

- Insights now opens on **Overview**. The new **At a glance** row combines **Grades**, **Course health**, **FSRS depth**, **Due load** and **Readiness**.
- **Courses to watch** lists only courses with a warning and names the check: missing grade items, no lectures or absences, attendance below your threshold, overdue course tasks, or an exam inside the warning window.
- The detailed grade snapshot, 12-week heatmap, confidence calibration, retention trend, skill/domain/difficulty breakdowns, study time by course, skips, assignments and next-exam plan remain below.

## Courses, exams and readings

- The calendar course registry is now the shared identity for subjects, the course dashboard, course health, assignments and exam lookups. Renaming a course preserves its old name and code as aliases.
- Exams merge calendar events, manual exam assignments and Topic-planner dates, with optional topics, time and weight. Every reader uses the merged list, and manual exams now get the same graduated review cap as calendar exams.
- Study plans cover every exam in the configured window, not just the next one, and include lectures, readings, planner passes and assignments as work items.
- Readings can carry a course and due date; Today, the course overview and plans show pages remaining and pages behind.
- Class-note attendance is idempotent, lecture rows show whether their compiled note exists, and the course overview combines exams, topics, lectures, readings, assignments, tasks and grades with a source path for each row.

## Practice, grades and memory

- Partial credit is stored in history as a 0–100 score and feeds accuracy, retention, calibration, mastery, dashboards and CSV. Older notes still load.
- FRQ attempts are part of the combined knowledge picture, with course bands and an Insights section.
- Calibration now reports attempts with no confidence rating instead of silently dropping them.
- Study statistics add an answer-time histogram, median and slow-answer list.
- Exam review pressure ramps T-14 → T-7 → T-3 → T-1, skips a checkpoint that is already today, and releases the cap after the exam.
- The due queue has a daily cap that holds overflow without moving review dates.
- SM-2 Hard lowers ease, and the FSRS same-day clamp is stated in Scheduler settings.
- Per-deck retention fitting recommends a 0.85–0.95 target from that deck's review counters after 20 reviews; the 21 FSRS weights stay fixed at the shipped defaults.
- Mastered requires current FSRS recall of at least 90%, so a stale perfect score is held at Strong.

## AI practice safeguards

- Generated questions are blind-verified across multiple-choice, multi-select, True/False and numeric answers, including Quiz Generator and chat-created questions.
- A per-feature verification model can differ from the generation model.
- Deterministic distractor checks reject empty or duplicate choices, all/none-of-the-above filler and conspicuous correct-answer lengths.
- New AI questions skip duplicates already in the vault or repeated in the same batch.
- Fresh AI limits are 100 requests per day and 20 per run; an explicit 0 remains unlimited. Retryable failures use capped backoff that counts against the budget.
- Quick add enforces the allowed write roots and journals writes for undo. Selected-note context is ranked locally with BM25-style retrieval and an optional Focus topic instead of prompt-stuffed note text.

## Data and performance

- Note history is capped at 500 rows by default, configurable from 100 to 5000, keeping the newest rows and reporting pruning.
- Capped data stores warn when they drop the oldest entry instead of silently overflowing.
- Reading progress uses a stable title key with an explicit `id:` option.
- Derived dashboards and study statistics reuse a bounded snapshot cache, interval previews cache one replay per card, Today's 60-second tick no longer rebuilds the whole DOM, and selected-note retrieval stays local.

## Verification

**1,325 tests pass / 0 fail**; `npm run check` is clean across 230 files; `main.js` is rebuilt from `src/`. The release workflow publishes `main.js`, `manifest.json` and `styles.css`.

**Known gate:** the real Obsidian desktop, phone and light/dark visual pass is still manual. Unit tests cover the DOM and CSS contracts, not native layout, font fallback, safe-area insets or live theme switching.

A few findings remain intentionally out of scope because they need a new schema or provider contract: syllabus prose parsing, whole-vault AI retrieval, pre-send cost estimates, sub-day FSRS scheduling and training the 21 FSRS weights.
