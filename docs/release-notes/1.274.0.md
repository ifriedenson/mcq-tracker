# 1.274.0 — Parity audit: all 23 plugin rows accounted for

Importer's 1.273.0 close-out left no row Partial, but the audit record still had
stale lines: two release cells said 1.268.1 and 1.269.0, and "Importer depth"
still described the local export-file importers as a separate path to build rather
than work that had shipped. This release re-audits every installed-plugin row
against the code and the suite, and makes the record honest at the current
version. No plugin behaviour changed.

## The audit

`docs/installed-plugin-parity.md` has 23 plugin rows (the later table is Advanced
Tables' upstream feature map). The re-check found:

| Status | Rows |
|---|---|
| Covered | 9 — Advanced Tables, Annotator, Deadline, Importer, Kairos, Markmind, Omnisearch, pdf-to-md, PDF++ |
| Boundary | 8 — Code Runner, Download Pulse, Excalidraw, Folder Sty1es, Hider, Minimal Theme Settings, Notebook Navigator, Recent Files |
| Boundary / Covered | 2 — Copilot (workflow), Desmos (idea) |
| This plugin | 1 — MCQ Tracker |
| Added | 3 — Tally Counter, Text Block Timer, WordNet Dictionary |

No row is Partial or Uncovered.

- Every Covered row was matched to the `src/` modules it names and to test files
  that run in the full suite: `table-editor`/`table-formulas`/`table-controls-view`
  with the table tests, the PDF/EPUB annotation modules with `pdf-annotator`,
  `pdf-ink`, `pdf-deep-link` and `epub`, the `calendar-*`/`pomodoro`/`assignments`/
  `study-plan`/`os-notifications` modules with their tests, `service-import` with
  `service-import`, `time-blocks` with the three time-block suites, `mindmap` with
  `mindmap-edit`, `vault-search` with `vault-search`, `pdf-latex` with `pdf-latex`
  and `pdf-deep-link` with `pdf-deep-link`.
- Every Boundary row keeps the reason it has always had: Code Runner stays behind
  the plan's §11 no-execution gate, Copilot (AGPL-3.0) and Desmos (GPL-3.0) cannot
  be copied into this MIT codebase, and the download/analytics and
  theme/navigation plugins are not study state. Nothing in the code claims them.

## What changed

- The header records the Nov 5, 2026 re-check at 1.274.0 and the no-Partial result.
- The MCQ Tracker row and the "Added" legend now name **1.274.0** instead of
  1.268.1 and 1.269.0.
- "Importer depth" now states that the local export-file importers shipped in
  1.273.0 for Evernote, Keep, Airtable, Notion, Bear and Roam, and that live cloud
  importer clients (sign in and sync) remain an owner decision.

## Tests

Documentation only, so no test was added or changed. The full suite is green:
**2,192 tests, 2,192 pass, 0 fail** (`node --test`, exit 0), including the
capability and security inventory checks (**17 pass**) against the current bundle.
`node scripts/build.js --check` reports `main.js` up to date, so the published
bundle is byte-identical to 1.273.0.

## Limits

The Boundary rows are unchanged and still wait on their owners: a Code Runner
sandbox and language allow-list, and licence decisions for Copilot and Desmos.
Apple Notes, OneNote, Bear bundles and the Notion ZIP remain unsupported for the
reasons in the 1.273.0 notes. No dependency, provider, account or network request
was added.
