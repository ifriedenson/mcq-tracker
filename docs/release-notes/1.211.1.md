# MCQ Tracker 1.211.1

Fixed the **Anki package (.apkg)** importer dropping all but the first card of a
note.

- Reversed notes now import both directions.
- Notes with multiple card rows keep every card, with distinct Anki card IDs,
  schedules and import keys.
- Single-card notes keep their previous `apkg:...` key, so duplicate detection
  and update behavior are unchanged.

## Verification

- The focused `tests/apkg.test.js` suite passes.
- Full suite and `npm run check` results are recorded at the release commit.
