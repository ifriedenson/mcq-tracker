# 1.263.0 — Advanced Tables: merged cells, tab-joined export, upstream ordering and notices

Released Nov 5, 2026. No dependency, provider or network request was added.

## What changed

- **Merged cells.** A cell holding exactly `^` joins the run on its left (colspan)
  and a cell holding exactly `"` joins the cell above (rowspan). `tableMerges` in
  `src/table-editor.js` turns the markers into spans and hidden cells; the
  reading-view decorator sets `colspan`/`rowspan` on the surviving cell, makes the
  marker cells uneditable and hides them, so Tab never lands on one. The markers
  stay in the source, so formatting, sorting, transposing and every other write
  path round-trip the layout. A marker with nothing to join — a `^` in the first
  column, a `"` in the header row — refuses with a message instead of guessing.
  Upstream has no merged cells, so this is an extension, not parity.
- **Tab-joined export.** `tableCsvFromTable` takes a `delimiter` (`,` or `\t`) and
  quotes against the delimiter it is using, and the copy dialog gains
  **Separate with tabs**, matching upstream's `exportCSV`, which joins rows with
  tabs. Comma output is byte-identical to 1.262.0.
- **Blank ordering in sorts.** Upstream treats an empty cell as the smallest
  value, so a blank now leads an ascending sort and trails a descending one,
  with equal values still in source order.
- **Double-action notices.** The **Tables: go to the next cell**, **go to the
  previous cell** and **go to the next row** commands now show upstream's notice
  when the matching Tab or Enter binding is also on, and stay quiet on mobile.
  The key handler itself is unchanged, so no extra notice appears while typing.
