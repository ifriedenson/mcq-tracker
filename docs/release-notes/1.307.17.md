# 1.307.17 — QR codes stay out of your questions

Released November 17, 2026. Obsidian 1.15.1.

## Why

Exam and textbook PDFs are full of QR codes: a distributor's "scan to open on the web" block, a
publisher's answer-key link, a source citation. They are not figures a question needs, but the import
treated them as any other ink on the page. With page pictures on, the code was cropped and written into
the vault as `…-p04-fig2.png` and the note carried `[FIGURE page 4: ![[…]]]` in the middle of a
question; and the caption beside it ("Scan to open on Studocu", a bare `https://…` line) reached the
model as if it were part of the document, where it can leak into a question, a source line or a card.

## What changed

- **A printed symbol is recognised and skipped.** `qrSignature` in `src/pdf.js` reads the rendered
  pixels of each candidate figure: the patch must be near-square, larger than an icon and smaller than
  half the page, made almost entirely of near-black and near-white pixels (mid-grey below a fifth, so
  photos, shaded maps and gradients are excluded), with a dark share between 22% and 78%, and it must
  change colour many times along its own middle row and column the way a module grid does. Nothing
  matching that is cropped into the vault, so no QR image reaches a note.
- **The caption goes with it.** `isQrScaffoldLine` drops a "scan … to open/view/download/…" caption, a
  bare "scan me", and a line that is only a URL. `withoutQrScaffold` applies it to both the reading-order
  lines and the table lines `readPdfPages` returns, so the AI prompt, the page text and the Quizlet table
  reader all see the same cleaned page.
- **Real figures are untouched.** The test suite pins a photograph on the same page still being
  captured, a solid logo still being captured, and a wide bar-code strip (not square) still being
  captured.

## Evidence

- `tests/pdf-qr.test.js`: a 25-module symbol with its finder patterns is recognised and produces no
  figure; a photograph beside it is still captured with its own box; a solid logo and a bar-code strip
  are not symbols; a symbol with a printed quiet zone is still recognised; the caption filter keeps every
  question and answer-choice line; and `readPdfPages` returns a page whose text holds the question and
  neither the caption nor the link.
- `node --test`: see the count in `plan.md` (`npm run plan:status`). `npm run check`: clean.

No note format, setting key, review schedule or network default changed.
