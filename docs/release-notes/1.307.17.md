# 1.307.17 — The import window says how much is left

Released November 18, 2026.

## Why

A long import showed activity without a sense of time: the AI-reading line counted
batches, and note creation said `Created 3 of 12...`, but neither said how long the
rest would take. The review screen also asked you to tick questions without saying
how many notes would be added out of how many were found.

## What changed

- **The review screen states the selection.** A line under the hint reads
  `Add 4 of 9 questions.` and follows every tick, untick, **Select all** and
  **Select none**; the **Create N notes** button keeps saying the same number.
- **AI reading shows a time left.** After each measured batch, the status line
  appends an estimate computed from this import's own elapsed time per finished
  batch, e.g. `about 2 minutes left`.
- **Note creation shows a time left.** The progress line now reads
  `Created 3 of 12... about 40 seconds left`, measured from that run's own pace
  and refreshed after every note is written.
- **The estimate stays quiet when it cannot know.** Nothing is shown before the
  first batch or note finishes, and nothing is shown at completion, so the line
  never invents a number. The format is `less than 10 seconds left`,
  `about N seconds left` or `about N minute(s) left`.

## Evidence

- `tests/import-real-pdf.test.js` drives the real import modal with a real
  extracted-text PDF. The review count starts at `Add 2 of 2 questions.`, falls to
  `Add 0 of 2 questions.` after **Select none**, and returns after **Select all**;
  the note-creation line is caught mid-run at `Created 1 of 2...` with an estimate.
- `node --test`: **3,015 pass, 0 fail**. `npm run check`: clean.
- `main.js`: **7,561,771 bytes** on disk from **375 modules**.
- Two task-date tests now derive their expected Tuesday from the current date
  instead of hard-coding November 17, 2026, and `docs/capability-inventory.md`
  cites them for `util`.

The import window was driven through the headless test harness only; it was not
viewed in a real Obsidian window in this environment.

No note format, setting key, review schedule or network default changed.
