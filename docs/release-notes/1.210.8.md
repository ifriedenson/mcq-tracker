# MCQ Tracker 1.210.8

The Kairos planner now lives inside the university **Calendar**.

## What changed

- With **Time blocks** on, the Calendar's day section (Month and Day modes)
  gains a **Study plan** card: the day's planned blocks with their times,
  course, duration and a **Remove** action, plus a line reading what is
  planned, what is in class and what is still free.
- **Free slots** inside an 08:00–22:00 planning window are listed as chips,
  each showing its length and, where there is a later class, the class it
  leads into. Clicking one plans a study block for exactly that span, titled
  `Study: <next class>` and stored in the existing Time blocks data.
- **After a class** lists one chip per class; clicking it plans a 45-minute
  review block that starts when the class ends, bounded by the window.
- Blocks that overlap a class are marked in red with "overlaps a class", so a
  double booking is visible without opening the planner.
- **Open Time blocks** jumps to the full Day/Week/Grid/Timeline planner.

## Boundaries

- Classes, event notes and `.ics` feeds stay read-only. Nothing is written back
  to the calendar, no event is moved or copied, and no second timetable exists:
  every button calls the existing `addTimeBlock`.
- The card only appears while Time blocks is on; with it off the calendar is
  unchanged.
- No dependency, network request or new setting was added.
