# MCQ Tracker 1.210.11

The Retention tab's per-deck fit card now does what it says.

## What was wrong

The card was titled **Per-deck retention fit** and explained that a target is
fitted from each deck's own review history, but it rendered no data — only a
hint and a button to Settings. The fitting logic, the per-deck report, the Apply
and the Reset already existed and were used from Settings, so the workspace
surface was a stub rather than a missing feature.

## What it does now

- Lists every deck with its review count, card count and current target.
- Shows the observation behind each suggestion ("Observed recall 100% across 30
  reviews. Target 0.90 → 0.95. Weights stay fixed."), or what is still missing
  ("Needs at least 20 reviews; 4 recorded so far.").
- Offers **Apply 0.95** only when a fit is accepted, and **Reset** only when the
  deck carries a custom target. Both call the same validated plugin methods the
  Settings page uses.
- Appears as soon as there is a deck or card to fit, without waiting for **Scan
  cards**, because it reads the review counters rather than the due forecast.
- Stays hidden while there are no cards at all, so a first run shows no empty
  fit card.

## Boundaries

- One deck's target only: other decks, the global target and all 21 FSRS weights
  are untouched, and nothing changes until Apply is pressed.
- No note is read or written, no dependency or provider was added, and the
  Settings → Scheduler controls are unchanged.
