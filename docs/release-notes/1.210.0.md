# MCQ Tracker 1.210.0

Adaptive practice is now mastery-based. The existing **Adaptive mastery** mode
uses the learner's whole question history and the properties already stored on
question notes to choose a weak area, then gives a different question from that
area instead of repeating the exact missed item.

## What changed

- Adaptive practice ranks course, unit, skill, topic, test, exam and tag facets
  from recorded accuracy, partial credit, pace, skips and recency. Small
  subgroups borrow a prior from the same facet across the whole vault, so one
  unlucky attempt does not define a weakness.
- The next question must share the selected weak facet but is a different note,
  with a preference for a different difficulty and an unattempted or
  long-unattempted item. Exact questions are excluded for the session and for
  seven days after an attempt.
- The selector is local and read-only. It makes no network request, writes no
  note or schedule, and leaves the FSRS due-review path unchanged.
- The Practice setup explains the behavior when Adaptive mastery is selected.
