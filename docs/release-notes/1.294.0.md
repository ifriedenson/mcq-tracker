# 1.294.0 — A one-screen start

The first run now opens on one **Start here** screen. It gives a new user three
plain steps, a real example question, an optional desktop OpenCode installer,
feedback links and a short mobile note. The optional module chooser and workflow
guide are still one click away.

## What changed

- **Try the example question** writes one ordinary note to
  `Questions/Getting started example.md`, enables MCQ Tracker if it was off, and
  opens Practice limited to that note. If the name is taken, it uses the next
  free number instead of overwriting a note.
- **Install OpenCode** runs the existing desktop installer from the welcome
  screen. It reuses an existing compatible program, shows download progress,
  and leaves the AI settings unchanged if the install fails. The button then
  says **Try again**.
- On mobile, the same section explains that OpenCode is desktop-only and points
  to a Direct API provider key instead. The desktop install button is not shown.
- **Help and feedback** links open the GitHub issue form and the quick-start
  guide. Nothing opens or is submitted until you click.
- The guide can be reopened from the command palette or **Settings → Global →
  About**.

The example is a normal question note: you can edit, move or delete it like any
other note. It uses the same Quick add format, question ID and review schedule
as the rest of the vault.
