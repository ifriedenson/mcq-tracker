# 1.291.0 — PDF++ is part of MCQ Tracker

PDF++ was already bundled in `main.js`; this release removes the last separate-plugin surface from Settings. The embedded host captures PDF++'s own settings tab instead of adding it as a second top-level plugin tab. **Settings → App & documents → PDF++** now owns the on/off switch, status and all vendor controls. PDF++'s internal **Customize...** links and `obsidian://pdf-plus` settings links open that page and scroll the visible embedded controls.

No separate download or install is needed. If the standalone PDF++ plugin is enabled, the embedded copy still refuses to run until it is disabled; this guard prevents two patchers on the native PDF viewer.

Verification: `node --test` → 2,431 pass, 0 fail; `npm run check` clean; `main.js` is 6,847,319 bytes. The PDF++ boot test asserts that the vendor tab is captured and never appears as a top-level plugin tab, and the settings-navigation test asserts that PDF++'s settings entry points open MCQ's page. No schema, dependency, provider or PDF++ vendor code changed.
