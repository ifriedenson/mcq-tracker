# 1.307.11 — The drawer above the conversation

Released November 16, 2026. Obsidian 1.15.1, Primary theme.

## Why

1.307.10's four destructive paths were proven by state, then screenshotted in the live app. The
screenshots showed what the assertions could not.

## What changed

- **The library clears the composer.** The drawer used to open underneath the sticky composer and
  the chat surface had no scroll, so the bottom conversations and their row actions could not be
  reached. `.qt-agent-chat` now scrolls and the composer returns to the flow while the drawer is open
  (`.qt-chat-tab-panel.is-library-open`).
- **Row actions read as chips.** Pin / Export / Archive / Delete were stretching across the row;
  they are compact and right-aligned, and `Remove project` no longer stretches either.
- **Long titles truncate.** The row's open button is a block with an ellipsis, so a long conversation
  name can no longer run into its timestamp.
- **Measured contrast in both themes.** Archived rows lost their 0.7 opacity (3.89:1) for normal ink
  (8.37:1 light, 9.08:1 dark); Delete moved from 4.49:1 to 4.88:1 in light (4.59:1 in dark) by mixing
  `--text-error` toward `--text-normal`; the drawer hint moved from 4.11:1 to 5.53:1 (9.08:1 dark).
  The shared notice stays 4.84:1 light and 5.63:1 dark with its Undo at 58×32.
- **One notice per removal.** Removing a chat project raised its own `Removed the project` notice on
  top of the shared Undo notice; the shared one is now the only one.
- **Narrow panes wrap whole fields.** `This chat:` and `Filter:` keep their label and select together
  when the pane is 378px wide.
- **A busy reply disables the row Delete**, with a title explaining why.
- **What's New scrolls.** The 1.307.10 dialog is taller than the window and clipped its fourth card
  with no way to scroll; it is capped at 86vh with a scrolling content area.

## Verification

Primary light and dark at 1024×800, plus a 378px pane with both sidebars open. Every contrast
figure above was measured from the live computed colours, not eyeballed. Screenshots:
`artifacts/ui-quality/runs/undo/` (chat library default / hover / focus-visible / disabled / narrow,
all four Undo notices in both themes, the 1.307.10 What's New card top and bottom, and the calendar
day plan with six planned blocks).

`node --test`: **3,000 pass, 0 fail**. `npm run check`: clean.

No setting key, note format, command, review schedule or network default changed.
