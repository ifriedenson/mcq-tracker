# 1.307.12 — Pixels, not assertions

Released November 16, 2026. Obsidian 1.15.1, Primary theme, fresh private Xvfb session.

## Why

1.307.11 fixed the drawer from screenshots of the previous session. This pass brought up a new session
on the shipped build and looked again. Three defects survived, all of them outside what the state
tests and the CSS pins could see.

## What changed

- **A cut title is marked.** Titles are stored up to 80 characters; a longer one ended mid-word with
  no ellipsis (`…explained step by`). `clipTitle` now keeps room for `…` when storing, listing and
  renaming, so the row reads as truncated; the row's CSS ellipsis still handles a narrow pane.
- **The search row fills the drawer.** `Search conversations` grew from a fixed 220px to the full
  width and `Show archived` now matches its 32px height instead of standing 40px beside it.
- **Two project fields, one column.** `This chat` / `Filter` measured 375/396 at 963px and, after a
  0-basis experiment, collapsed to 85px each at 380px with overlapping labels. A 190px basis plus a
  full-width select gives 383/383 at 963px and two stacked 308px fields at 380px, keeping every
  label with its select and `Remove project` compact.
